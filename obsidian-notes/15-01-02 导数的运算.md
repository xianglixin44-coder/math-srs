# 导数的运算
**教材**: 人教版选择性必修第二册第五章 5.2 节

## 知识深度笔记

### 现象

* **【情境锚定：从"手动极限"到"算子工厂"的效率飞跃】**：
    * **起因（背景与任务）**：在 $5.1$ 节中，我们已经掌握了通过导数定义（极限法）求解瞬时变化率的方法。然而，面对实际科研中复杂的函数，如 $f(x) = x^3 e^x$ 或 $y = \ln(2x-1)$，若每次都回到定义进行"差、比、极限"的运算，过程将极其繁琐。
    * **冲突（瓶颈与矛盾）**：手动推导极限不仅计算量大，且容易在代数变形中出错；旧有的"定义法"在处理复合结构或分式结构时，逻辑链条过长，无法满足大规模、高精度的工业计算需求。
    * **指向（概念诞生）**：通过建立**导数运算法则协议（Calculation Rules Protocol）**，数学家将常用函数固化为"基本公式"，并提炼出四则运算及复合函数求导的"逻辑指令"，标志着微积分进入了"算子化、自动化"的成熟阶段。

### 原因

* **形成机制**：基于**极限运算法则的代数迁移**。
    1. **公式固化**：对常数、幂、指、对、三角函数分别执行定义式推导，获得基本初等函数导数表。
    2. **结构分解**：利用极限的线性性质（和差）、乘法与除法性质，推导出导数的四则运算法则。
    3. **链式传动**：通过中间变量 $u$ 的中转，将复合结构拆解为局部导数的乘积（链式法则），实现"层层剥茧"。
* **条件剖析**：导数运算法则生效的前提是参与运算的各部分函数在对应点处均可导。
    * *反例*：在求 $y = \frac{f(x)}{g(x)}$ 的导数时，若 $g(x) = 0$，则商的求导算子立即失效。

### 结果

* **【核心公式提取（Formulas）】**：
    * **基本初等函数算子**：
        *   $(c)' = 0$；$(x^\alpha)' = \alpha x^{\alpha-1}$。
        *   $(\sin x)' = \cos x$；$(\cos x)' = -\sin x$。
        *   $(a^x)' = a^x \ln a$；$(e^x)' = e^x$。
        *   $(\log_a x)' = \frac{1}{x \ln a}$；$(\ln x)' = \frac{1}{x}$。
    * **四则运算算子**：$(u \pm v)' = u' \pm v'$；$(uv)' = u'v + uv'$；$(\frac{u}{v})' = \frac{u'v - uv'}{v^2}$。
    * **复合函数（链式）算子**：$y'_x = y'_u \cdot u'_x$。
* **【重要性质归纳（Properties）】**：
    1. **常数提取性**：$[c f(x)]' = c f'(x)$。
    2. **局部反映性**：导数值的变化快慢由其绝对值大小决定，绝对值越大，图象越"陡峭"。
    3. **物理加速度协议**：速度函数的导数即为瞬时加速度。
* **【核心特点剖析（Characteristics）】**：
    * **代数结构特征**：算子具有高度的递归性。复合函数求导如"剥洋葱"，由外向内逐层展开。
    * **几何图像特征**：导数运算结果确定了切线斜率函数的解析式。
    * **符号特征**：注意 $(\cos x)'$ 符号为负；商的求导公式分子符号为"减"且顺序不可逆。
* **【要素拆解】**：
    * 【适用前提】：函数由基本初等函数复合、运算而成。
    * 【核心结论】：任意复杂的可导函数均可通过有限次算子应用得出导数。
    * 【适用范围/边界】：注意分母不为 $0$ 及复合函数中间变量的定义域匹配。

### 应用

* **学科内应用**：求复杂曲线切线方程、分析复合函数单调性、研究变力做功的功率。
* **跨学科/实际应用**：**水净化成本优化**。利用 $C(x) = \frac{5284}{100-x}$ 及其导数分析，判定随着纯净度提升，净化费用的瞬时变化率如何呈指数级激增，从而决策最优处理节点。

### 本质

* **数学思想方法**：**化归转化**（复杂函数分解为简单函数）、**算子思想**（运算逻辑标准化）。
* **高观点视域**：本节展示了微分算子 $D$ 在函数环上的线性映射特性及 Leibniz 法则（乘法规则）。复合求导体现了流形上的切空间映射，是线性逼近理论的延伸。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

* **解题策略**：执行"结构识别 $\rightarrow$ 法则选型 $\rightarrow$ 逐层拆解"的 SOP。涉及复合函数时，强制执行"中间变量 $u$ 显化"，严禁跳步造成嵌套漏算。
* **标准操作步骤（SOP）**：
    * **步骤 $1$：[结构识别]** 观察解析式是"和、差、积、商"中的哪一种，还是复合结构。
    * **步骤 $2$：[法则匹配]** 选取对应的四则运算法则或链式法则。
    * **步骤 $3$：[公式套用]** 对应基本初等函数表写出各部分原导数。
    * **步骤 $4$：[代数简化]** 合并同类项，若有复合变量 $u$ 则必须回代 $x$。

### 典型例题

#### 例题1（基础示范题）：
**题目**：求函数 $f(x) = x^3 e^x$ 的导数。

1. **【结构与特征分析】**：形视识别入口为"幂函数与指数函数的乘积"。适用乘法求导算子 $(uv)' = u'v + uv'$。
2. **【解题决策逻辑流（思维推演）】**：
    起点（源头）：识别 $u = x^3$，$v = e^x$ ➔ 
    分支（决策）：套用乘法法则，分别计算 $u'$ 和 $v'$ ➔ 
    终点（收敛）：将分块结果代入法则骨架，提取公因式完成收敛。
3. **【解析（对照 SOP 步骤）】**：
    * [步骤 $1$ [识别]]：识别为积函数结构 $x^3 \cdot e^x$。
    * [步骤 $2$ [匹配]]：使用公式 $(uv)' = u'v + uv'$。
    * [步骤 $3$ [执行]]：$f'(x) = (x^3)' e^x + x^3 (e^x)' = 3x^2 e^x + x^3 e^x$。
    * [步骤 $4$ [简化]]：$f'(x) = (3x^2 + x^3) e^x$。
4. **【避坑提示】**：不要错记成 $(uv)' = u'v'$，这是新手最常见的代数逻辑错误。
**结论**：$f'(x) = (3x^2 + x^3) e^x$。

#### 例题2（综合变式题）：
**题目**：求函数 $y = \ln(2x - 1)$ 的导数。

1. **【结构与特征分析】**：形视识别入口为"对数函数嵌套一次函数"。特征是需要建立中间变量 $u = 2x-1$ 的链式传动。
2. **【解题决策逻辑流（思维推演）】**：
    起点（源头）：复合函数定义 $y = f(g(x))$ ➔ 
    分支（决策）：设 $u = 2x-1$ 为桥梁，将原式拆解为外层 $y = \ln u$ 和内层 $u = 2x-1$ ➔ 
    决策（算子）：应用链式法则 $y'_x = y'_u \cdot u'_x$ ➔ 
    终点（收敛）：求出分段导数并连乘，回代 $u = 2x-1$ 完成收敛。
3. **【解析（对照 SOP 步骤）】**：
    * [步骤 $1$ [设变量]]：设 $u = 2x - 1$，则 $y = \ln u$。
    * [步骤 $2$ [求分导]]：$y'_u = (\ln u)' = \frac{1}{u}$；$u'_x = (2x - 1)' = 2$。
    * [步骤 $3$ [链式乘]]：$y'_x = y'_u \cdot u'_x = \frac{1}{u} \cdot 2 = \frac{2}{u}$。
    * [步骤 $4$ [回代]]：将 $u = 2x - 1$ 代入，得 $y' = \frac{2}{2x - 1}$。
4. **【避坑提示】**：求复合导数时，切记不要漏乘内层函数 $g(x)$ 的导数（即本题中的 $2$）。
**结论**：$y' = \frac{2}{2x - 1}$。

### 巩固习题

##### 梯度一：基础达标
1. **题 $1$ **：求 $y = 3^x - \log_2 x$ 的导数。
    * **答案**：$y' = 3^x \ln 3 - \frac{1}{x \ln 2}$。步骤：直接套用和差及基本公式。
2. **题 $2$ **：函数 $y = \sin x + \cos x$ 的导数是 ____。
    * **答案**：$\cos x - \sin x$。步骤：$(\sin x)' + (\cos x)' = \cos x + (-\sin x)$。

##### 梯度二：高考中档
3. **题 $3$ **：求曲线 $y = \frac{\ln x}{x}$ 在点 $(1, 0)$ 处的切线方程。
    * **详细解析**：$y' = \frac{(\ln x)' x - (\ln x) x'}{x^2} = \frac{1 - \ln x}{x^2}$。在 $x=1$ 处，$k = 1$。切线方程为 $x - y - 1 = 0$。
4. **题 $4$ **：求 $y = e^{-2x+1}$ 的导数。
    * **详细解析**：复合函数。设 $u = -2x+1$，则 $y = e^u$。$y' = e^u \cdot (-2) = -2e^{-2x+1}$。

##### 梯度三：能力拔高
5. **题 $5$ **：已知函数 $f(x) = f'(\frac{\pi}{4}) \sin x - \cos x$，求 $f'(\frac{\pi}{4})$ 的值。
    * **思维破局**：方程法。将 $f'(\frac{\pi}{4})$ 视为一个待定常数 $A$。对等式两侧求导，再代入 $x = \frac{\pi}{4}$ 建立关于 $A$ 的方程。
    * **解析**：$f'(x) = f'(\frac{\pi}{4}) \cos x + \sin x$。令 $x = \frac{\pi}{4}$，得 $A = A \cdot \frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2}$。解得 $A = \sqrt{2} + 1$。
