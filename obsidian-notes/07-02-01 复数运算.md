# 复数的四则运算
**教材**: 人教版必修第二册第七章 7.2 节

## 知识深度笔记

### 现象
*   **【情境锚定：从"静态坐标"到"动态算法"的结构跃迁】**：
    *   **起因（背景与任务）**：在 $7.1$ 节中，我们为复数建立了复平面的几何坐标表示。现在的任务是：如何让这些"数"像实数一样动起来，通过加、减、乘、除运算解决更复杂的代数问题。
    *   **冲突（瓶颈与矛盾）**：复数包含实部与虚部，具有二维特征。传统的实数运算法则无法直接处理虚数单位 $i$ 的交互，特别是在乘除法中，如何安置 $i^2$ 以及如何消除分母中的虚数，成为了逻辑上的新瓶颈。
    *   **指向（概念诞生）**：通过建立**复数运算法则协议（Complex Arithmetic Protocol）**，类比多项式运算并强加 $i^2 = -1$ 的归算律，实现了数系扩充后代数结构的逻辑闭环。

### 原因
*   **形成机制**：基于**分量独立加减与多项式乘法逻辑**。
    1.  **线性叠加逻辑**：加减法遵循"实部对实部，虚部对虚部"的原则，这与向量坐标的线性叠加在逻辑上是完全同构的。
    2.  **乘法归算逻辑**：将复数看作以 $i$ 为变量的多项式进行展开，再利用 $i^2 = -1$ 将二次项坍缩回实数项。
    3.  **除法实数化逻辑**：利用共轭复数的自积 $z \cdot \bar{z} = |z|^2$ 为实数的特性，通过分子分母同乘分母的共轭复数，实现分母"脱虚"。
*   **条件剖析**：除法运算中，除数 $c + di$ 必须为非零复数（即 $c^2 + d^2 \neq 0$）。
    *   *反例*：若分母实虚部均为 $0$，则无法通过共轭变换消除虚部，导致运算无意义。

### 结果
*   **【核心公式提取（Formulas）】**：
    *   **加减算子**：$(a + bi) \pm (c + di) = (a \pm c) + (b \pm d)i$。
    *   **乘法算子**：$(a + bi)(c + di) = (ac - bd) + (ad + bc)i$。
    *   **除法算子**：$\frac{a + bi}{c + di} = \frac{ac + bd}{c^2 + d^2} + \frac{bc - ad}{c^2 + d^2}i$。
*   **【重要性质归纳（Properties）】**：
    1.  **运算律兼容性**：复数运算完全满足交换律、结合律和乘法对加法的分配律。
    2.  **共轭乘积律**：$z \cdot \bar{z} = |z|^2 = a^2 + b^2$（实数化核心）。
    3.  **$i$ 的周期性**：$i^1 = i, i^2 = -1, i^3 = -i, i^4 = 1$（周期为 $4$）。
*   **【核心特点剖析（Characteristics）】**：
    *   **代数结构特征**：乘法体现了"模长相乘，辐角相加"的几何直觉。
    *   **几何图像特征**：加减法对应复平面内向量的合成与分解。
*   **【要素拆解】**：
    *   【适用前提】：所有参与运算的对象需化为 $a + bi$ 标准型。
    *   【核心结论】：复数系对四则运算（除零外）是完备且封闭的。

### 应用
*   **学科内应用**：在复数范围内求解判别式 $\Delta < 0$ 的一元二次方程，补全代数基本定理。
*   **跨学科/实际应用**：**雷达信号处理**。通过复数乘法（相位旋转）对接收到的微波信号进行滤波与移位，实现对目标物体的精确测速。

### 本质
*   **数学思想方法**：**化归思想**（复数运算→多项式运算）、**数形结合**（代数代换↔平面旋转）。
*   **高观点视域**：复数乘法本质上是复平面上的**伸缩旋转变换**。它揭示了代数运算中蕴含的几何变换属性。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤
*   **解题策略**：执行"一展（按多项式法则展开）、二换（见 $i^2$ 换 $-1$）、三并（合并实虚部）、四化（分母共轭实数化）"的 SOP。
*   **标准操作步骤（SOP）**：
    *   **步骤 $1$ [算子展开]**：像处理 $(a+bx)(c+dx)$ 一样展开乘积项。
    *   **步骤 $2$ [降幂归算]**：将所有 $i^n$ 转化为 $i, -1, -i, 1$ 之一。
    *   **步骤 $3$ [共轭实化]**：处理除法时，分子分母同乘分母的 $\bar{z}$。
    *   **步骤 $4$ [标准输出]**：整理为 $A + Bi$ 的最终形态。

### 典型例题
#### 例题1（混合运算与标准型转化）：
**题目**：计算 $\frac{(1 + 2i)(3 - 4i)}{-i}$ 并求其模长。

1.  **【结构与特征分析】**：形视识别入口为"分式复数"。分子是乘法结构，分母是单项虚数。
2.  **【解题决策逻辑流（思维推演）】**：
    *   分子：$(1+2i)(3-4i) = 3-4i+6i-8i^2 = 11+2i$ ➔
    *   除法：$\frac{11+2i}{-i} \cdot \frac{i}{i} = \frac{11i+2i^2}{1} = -2+11i$ ➔
    *   模长：$|z| = \sqrt{4+121} = 5\sqrt{5}$。
3.  **【解析（对照 SOP 步骤）】**：$-2+11i$，模长 $5\sqrt{5}$。
4.  **【避坑提示】**：$-i \cdot i = -i^2 = 1$，符号极易出错。
**结论**：$-2+11i, |z|=5\sqrt{5}$。

#### 例题2（复数域方程求解）：
**题目**：在复数范围内解方程 $x^2 + x + 1 = 0$。

1.  **【结构与特征分析】**：形视识别入口为"负判别式二次方程"。$\Delta = -3 < 0$。
2.  **【解题决策逻辑流（思维推演）】**：
    *   $\Delta = 1-4 = -3 \implies \sqrt{\Delta} = \sqrt{3}i$ ➔
    *   $x = (-1 \pm \sqrt{3}i)/2$。
3.  **【解析（对照 SOP 步骤）】**：$x = -1/2 \pm \sqrt{3}i/2$。
4.  **【避坑提示】**：结果必须写成 $\pm$ 的形式，且确保 $i$ 不在根号内。
**结论**：$x = -\frac{1}{2} \pm \frac{\sqrt{3}}{2}i$。

### 巩固习题
##### 梯度一：基础达标
1.  **题 $1$ **：$(1+i)^2+(1-i)^2 = (2i)+(-2i) = 0$。
2.  **题 $2$ **：$z=1+i$ → $1/z = (1-i)/(2) = 1/2 - i/2$。

##### 梯度二：高考中档
3.  **题 $3$ **：$(a+bi)i = 1+2i \implies ai - b = 1+2i \implies b=-1, a=2 \implies a+b=1$。
4.  **题 $4$ **：$i + i^2 + \dots + i^{2026} = i^{2025}+i^{2026} = i - 1$（周期为 $4$）。

##### 梯度三：能力拔高
5.  **题 $5$ **：$z$ 纯虚数，$(z+2)/(1-i)$ 为实数。设 $z=ki$，化简得 $(2-k)/2 + (2+k)i/2$。虚部为 $0 \implies k=-2 \implies z=-2i$。
