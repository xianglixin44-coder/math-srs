# 单调性与最大（小）值
**教材**: 人教版必修第一册第三章 3.2.1 节

## 知识深度笔记

### 现象

*   **【情境锚定：从"曲线走势"到"数值量级"的动态监控】**：
    *   **起因（背景与任务）**：观察二次函数 $f(x) = x^2$ 的图象，我们能直观看到图象在 $y$ 轴左侧"下降"，在右侧"上升"。
    *   **冲突（瓶颈与矛盾）**：直观的"上升"或"下降"属于描述性语言，无法进行精确的代数逻辑推导。在处理复杂函数（如 $f(x) = x + \frac{1}{x}$）或实际物理规律（如玻意耳定律 $P = \frac{k}{V}$）时，需要一种严密的数学协议来锁定这种"随自变量增大而变化"的确定趋势。
    *   **指向（概念诞生）**：通过建立**单调性协议（Monotonicity Protocol）**，利用自变量 $x$ 的大小顺序与函数值 $f(x)$ 大小顺序的保持（或反转）关系，实现了对函数动态趋势的静态量化刻画。

### 原因

*   **形成机制**：基于**增量比对逻辑**。
    1.  **结构定义**：在区间 $I$ 内任取两个自变量 $x_1, x_2$，若 $x_1 < x_2$ 始终导致 $f(x_1) < f(x_2)$，则为单调递增；反之则为单调递减。
    2.  **极值逻辑**：当单调性在某点发生"切换"（由减变增或由增变减）时，该点往往成为图象的最低点（最小值）或最高点（最大值）。
*   **条件剖析**：必须强调"任意性"与"属于同一区间"。
    *   *反例*：对于 $f(x) = \frac{1}{x}$，虽然在 $(-\infty, 0)$ 和 $(0, +\infty)$ 上各自递减，但不能说它在定义域上递减，因为取 $x_1 = -1, x_2 = 1$，满足 $x_1 < x_2$ 但 $f(x_1) < f(x_2)$，违反了全域递减协议。

### 结果

*   **【核心公式提取（Formulas）】**：
    *   **增函数算子**：$\forall x_1, x_2 \in I, x_1 < x_2 \implies f(x_1) < f(x_2)$。
    *   **减函数算子**：$\forall x_1, x_2 \in I, x_1 < x_2 \implies f(x_1) > f(x_2)$。
    *   **最大值协议**：$\forall x \in D, f(x) \le M$，且 $\exists x_0 \in D, f(x_0) = M$。
*   **【重要性质归纳（Properties）】**：
    1.  **区间局部性**：单调性是针对定义域内某个子区间的属性。
    2.  **图象联动性**：增函数图象"自左向右上升"，减函数图象"自左向右下降"。
    3.  **最值存在性**：在闭区间 $[a, b]$ 上的连续函数必有最大值与最小值。
*   **【核心特点剖析（Characteristics）】**：
    *   **代数结构特征**：通过研究差值 $f(x_1) - f(x_2)$ 的符号来判定趋势。
    *   **几何图像特征**：单调区间是图象"波动"的最小单位。
*   **【要素拆解】**：
    *   【适用前提】：函数在指定区间内连续且有定义。
    *   【核心结论】：单调性反映了函数的"稳定性"，最值反映了函数的"边界"。
    *   【适用范围】：函数的一切动态分析，包括不等式证明与值域求解。

### 应用

*   **学科内应用**：求值域、解不等式、判定方程根的唯一性。
*   **跨学科/实际应用**：**烟花爆裂时刻计算**。利用二次函数最值模型确定烟花达到最高点（最大高度）的物理时刻。

### 本质

*   **数学思想方法**：**数形结合**（由图象趋势推代数式）、**化归思想**（将动态变化化归为差值符号判断）。
*   **高观点视域**：单调性是导数概念的离散前身。它揭示了函数作为"映射"对序关系的保持程度。在更深层，这体现了数学对客观世界"因果演进方向"的精确描述。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

*   **解题策略**：执行"取值—作差—变形—定号—结论"的五步法。在求最值时，遵循"单调性优先"原则，即先判定区间单调性，再取端点值。
*   **标准操作步骤（SOP）**：
    *   **步骤 $1$ [变量假设]**：设 $x_1, x_2$ 是区间 $I$ 内的任意两个值，且 $x_1 < x_2$。
    *   **步骤 $2$ [结构作差]**：构造差值 $\Delta y = f(x_1) - f(x_2)$。
    *   **步骤 $3$ [代数变形]**：通过因式分解、通分、配方等手段化简差值。
    *   **步骤 $4$ [正负判定]**：根据 $x$ 的范围判定每个因式的符号。
    *   **步骤 $5$ [逻辑产出]**：根据 $\Delta y$ 的符号锁定增减方向。

### 典型例题

#### 例题1（基础示范题）：
**题目**：证明函数 $f(x) = 3x + 2$ 是 $R$ 上的增函数。

1.  **【结构与特征分析】**：形视识别入口为"一次函数"。系数 $3 > 0$，预判为增函数。
2.  **【解题决策逻辑流（思维推演）】**：
    *   起点（源头）：单调递增定义协议 ➔
    *   分支（决策）：作差法剥离出自变量的增数 $(x_1 - x_2)$ ➔
    *   终点（收敛）：观察剩余常数因子的符号，判定整体差值的正负。
3.  **【解析（对照 SOP 步骤）】**：
    *   [步骤 $1$ [取值]]：任取 $x_1, x_2 \in R$，且 $x_1 < x_2$。
    *   [步骤 $2$ [作差]]：$f(x_1) - f(x_2) = 3(x_1 - x_2)$。
    *   [步骤 $3$ [定号]]：由于 $x_1 < x_2$，$3(x_1 - x_2) < 0$，即 $f(x_1) < f(x_2)$。
    *   [步骤 $4$ [结论]]：函数在 $R$ 上单调递增。
4.  **【避坑提示】**：证明题必须写"任取"，不能用具体的数字代入。
**结论**：$f(x)$ 是增函数。

#### 例题2（综合变式题）：
**题目**：已知函数 $f(x) = \frac{2}{x-1}$，求其在区间 $[2, 6]$ 上的最大值和最小值。

1.  **【结构与特征分析】**：形视识别入口为"简单分式函数"。在闭区间上求最值，第一步必须判定其单调性。
2.  **【解题决策逻辑流（思维推演）】**：
    *   起点（源头）：闭区间最值判定协议 ➔
    *   分支（决策）：先执行单调性 SOP ➔ 发现函数在区间内单调递减 ➔
    *   决策（映射）：最大值在左端点，最小值在右端点 ➔
    *   终点（收敛）：计算端点函数值完成收敛。
3.  **【解析（对照 SOP 步骤）】**：
    *   [步骤 $1$ [单调判定]]：作差得 $f(x_1) - f(x_2) = \frac{2(x_2 - x_1)}{(x_1-1)(x_2-1)} > 0$，故单调递减。
    *   [步骤 $2$ [最值]]：$f(2) = 2$（最大值），$f(6) = 0.4$（最小值）。
4.  **【避坑提示】**：求最值前若不声明单调性，逻辑链条是不完整的。
**结论**：最大值为 $2$，最小值为 $0.4$。

### 巩固习题

##### 梯度一：基础达标
1.  **题 $1$ **：已知 $f(x) = -x^2 + 1$，在 $[0, +\infty)$ 上的单调性是 ____。
    *   **答案**：单调递减。步骤：$f(x_1)-f(x_2) = x_2^2 - x_1^2 > 0$。
2.  **题 $2$ **：函数 $f(x) = \frac{1}{x}$ 在 $[1,6]$ 上的最小值是 ____。
    *   **答案**：$\frac{1}{6}$。正半轴单调递减，右端点取极小值。

##### 梯度二：高考中档
3.  **题 $3$ **：证明函数 $f(x) = 1 - \frac{1}{x}$ 在 $(-\infty, 0)$ 上是增函数。
    *   **详细解析**：作差 $f(x_1) - f(x_2) = \frac{x_1 - x_2}{x_1 x_2}$。由于 $x_1 - x_2 < 0$ 且 $x_1 x_2 > 0$，差值 $< 0$，$f(x_1) < f(x_2)$。
4.  **题 $4$ **：若 $f(x)$ 在 $[-6, -2]$ 上递减，在 $[-2, 11]$ 上递增，则 $f(-2)$ 是函数的（ ）。
    *   **详细解析**：最小值。由减转增的转折点即为最低点。

##### 梯度三：能力拔高
5.  **题 $5$ **：探究 $f(x) = x + \frac{1}{x}$ 在 $(1, +\infty)$ 上的单调性。
    *   **思维破局**：作差后因式分解暴露出 $(x_1x_2 - 1)$ 关键因子。
    *   **解析**：$f(x_1) - f(x_2) = \frac{(x_1 - x_2)(x_1 x_2 - 1)}{x_1 x_2}$。$x_1x_2 > 1$ 故因子为正，差值 $< 0$。函数单调递增。
