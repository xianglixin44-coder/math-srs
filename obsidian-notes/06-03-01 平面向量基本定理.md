# 平面向量基本定理
**教材**: 人教版必修第二册第六章 6.3.1 节

## 知识深度笔记

### 现象

*   **【情境锚定：从"合力生成"到"维度拆解"的逆向工程】**：
    *   **起因（背景与任务）**：在物理学中，我们已知两个分力可以合成一个合力。但在工程力学中，往往面临相反的任务：已知一个斜向上的力 $\vec{F}$，需要知道它在水平和垂直方向上分别产生了多大的作用。
    *   **冲突（瓶颈与矛盾）**：向量加法法则（平行四边形法则）是"二合一"的。如果不加约束，一个向量可以被分解为无数对分向量。这种"分解的随意性"导致数学表达无法标准化。
    *   **指向（概念诞生）**：通过建立**基底协议（Basis Protocol）**，规定只要选定两个互不平行的向量作为参考，平面内任何一个向量都可被唯一地"投影"到这两个方向上。

### 原因

*   **形成机制**：基于**线性组合的唯一性逻辑**。
    1.  **构造映射**：在平面内任取一点 $O$，作 $\vec{OA}=\vec{e}_1$ 和 $\vec{OB}=\vec{e}_2$（$\vec{e}_1,\vec{e}_2$ 不共线）。
    2.  **数乘驱动**：利用共线向量定理，存在唯一实数对 $(\lambda_1,\lambda_2)$ 使得 $\vec{OM}=\lambda_1\vec{e}_1, \vec{ON}=\lambda_2\vec{e}_2$。
    3.  **合成统一**：$\vec{a} = \lambda_1\vec{e}_1 + \lambda_2\vec{e}_2$。
*   **条件剖析**：基底 $\vec{e}_1, \vec{e}_2$ 必须**不共线**。
    *   *反例*：若 $\vec{e}_1 \parallel \vec{e}_2$，则它们的线性组合只能覆盖一条直线，导致"维度塌陷"。

### 结果

*   **【核心公式提取（Formulas）】**：
    *   **基本定理算子**：$\vec{a} = \lambda_1\vec{e}_1 + \lambda_2\vec{e}_2$（其中 $\lambda_1, \lambda_2$ 唯一）。
*   **【重要性质归纳（Properties）】**：
    1.  **基底契约**：不共线的向量集 $\{ \vec{e}_1, \vec{e}_2 \}$ 称为平面内的一组基底。
    2.  **唯一性契约**：对于给定的基底，向量 $\vec{a}$ 与实数对 $(\lambda_1, \lambda_2)$ 是一一对应的。
    3.  **零向量表示**：$\vec{0} = 0\vec{e}_1 + 0\vec{e}_2$（系数全为 $0$）。
*   **【核心特点剖析（Characteristics）】**：
    *   **代数结构特征**：建立了向量与有序实数对的同构映射。
    *   **几何图像特征**：通过网格化的方式，将平面内任意点定位化。
*   **【要素拆解】**：
    *   【适用前提】：基底向量非零且不共线。
    *   【核心结论】：平面内任一向量都可由基底线性表出。

### 应用

*   **学科内应用**：作为建立平面直角坐标系、引入向量坐标运算的理论根基。
*   **跨学科/实际应用**：**计算机图形学（骨骼动画）**。通过设定骨骼关节的基底向量，计算各个节点相对于基底的线性组合系数。

### 本质

*   **数学思想方法**：**化归转化**（几何→代数）、**分解与合成**（整体→局部）。
*   **高观点视域**：平面向量基本定理揭示了二维线性空间的"维数"本质。基底是该空间的生成元。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

*   **解题策略**：执行"一选基（确定两不共线向量）、二建路（寻找目标向量与基底的路径）、三转化（应用加减法及数乘法则）"的 SOP。
*   **标准操作步骤（SOP）**：
    *   **步骤 $1$：[基底识别]** 观察题目给定的参考向量，若无则选取有公共起点的两条边。
    *   **步骤 $2$：[路径解析]** 利用向量加法将目标向量拆解为基底所在直线的边。
    *   **步骤 $3$：[系数映射]** 利用分点比例或共线定理，将路径段转化为基底的数乘形式。

### 典型例题

#### 例题1（基础表示）：
**题目**：在 $\triangle ABC$ 中，$D$ 为 $AB$ 的中点，取 $\{ \vec{CA}, \vec{CB} \}$ 为基底，用基底表示中线 $\vec{CD}$。

1.  **【结构与特征分析】**：形视识别入口为"中线向量"。
2.  **【解题决策逻辑流（思维推演）】**：
    *   $\vec{CD} = \vec{CA} + \vec{AD}$ ➔
    *   $\vec{AD} = \frac{1}{2}\vec{AB} = \frac{1}{2}(\vec{CB} - \vec{CA})$ ➔
    *   $\vec{CD} = \vec{CA} + \frac{1}{2}(\vec{CB}-\vec{CA}) = \frac{1}{2}\vec{CA} + \frac{1}{2}\vec{CB}$。
3.  **【解析（对照 SOP 步骤）】**：$\vec{CD} = \frac{1}{2}\vec{CA} + \frac{1}{2}\vec{CB}$。
4.  **【避坑提示】**：$\vec{AB}$ 的减法方向必须是"终点减起点"。
**结论**：$\frac{1}{2}\vec{CA} + \frac{1}{2}\vec{CB}$。

#### 例题2（定比分点）：
**题目**：$\vec{OA}, \vec{OB}$ 不共线，$\vec{AP} = t\vec{AB}$，用 $\vec{OA}, \vec{OB}$ 表示 $\vec{OP}$。

1.  **【结构与特征分析】**：形视识别入口为"定比分点向量"。
2.  **【解题决策逻辑流（思维推演）】**：
    *   $\vec{OP} = \vec{OA} + t\vec{AB} = \vec{OA} + t(\vec{OB}-\vec{OA}) = (1-t)\vec{OA} + t\vec{OB}$。
3.  **【解析（对照 SOP 步骤）】**：$\vec{OP} = (1-t)\vec{OA} + t\vec{OB}$。
4.  **【避坑提示】**：系数之和 $(1-t)+t=1$，这是点 $P$ 在直线 $AB$ 上的代数特征，可用于逆向校验。
**结论**：$(1-t)\vec{OA} + t\vec{OB}$。

### 巩固习题

##### 梯度一：基础达标
1.  **题 $1$ **：平行四边形 $ABCD$ 中，$\vec{AC} = \vec{a}+\vec{b}$，$\vec{DB} = \vec{a}-\vec{b}$。
2.  **题 $2$ **：$\vec{a}=2\vec{e}_1+3\vec{e}_2, \vec{b}=\vec{e}_1-\vec{e}_2$，$2\vec{a}-3\vec{b} = \vec{e}_1+9\vec{e}_2$。

##### 梯度二：高考中档
3.  **题 $3$ **：$\triangle ABC$ 中 $AN=\frac{1}{3}NC$，$P$ 为 $BN$ 中点。$\vec{AP} = \frac{1}{2}\vec{AB} + \frac{1}{8}\vec{AC}$ → $m=1/2, n=1/8$。
4.  **题 $4$ **：$\vec{a}=\vec{e}_1+2\vec{e}_2, \vec{b}=2\vec{e}_1+k\vec{e}_2$，$\vec{a}\parallel\vec{b}$ → $1/2=2/k \implies k=4$。

##### 梯度三：能力拔高
5.  **题 $5$ **：$\vec{OA}+\vec{OB}+\vec{OC}=\vec{0}$ → $O$ 是 $\triangle ABC$ 的重心。
