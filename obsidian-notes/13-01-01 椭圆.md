# 椭圆
**教材**: 人教版选择性必修第一册第三章 3.1 节

## 知识深度笔记

### 现象
* **【情境锚定：从"单点圆规"到"双钉拉位移"的几何拓扑】**：
  1. **起因（背景与任务）**：在研究圆的绘制时，我们通过固定一个中心点来锁定轨迹。但当我们将这一物理约束扩展，尝试用一根细绳两端固定在两个定点 $F_1, F_2$ 上，套上铅笔拉紧移动，会得到一种全新的闭合曲线。
  2. **冲突（瓶颈与矛盾）**：圆的"单中心"逻辑无法描述这种具有"扁平度"的图形。在描述行星轨道或放映机反光镜面时，旧的圆方程算子因缺乏轴长差异的调节能力而失效。
  3. **指向（概念诞生）**：通过建立**椭圆协议（Ellipse Protocol）**，数学家将几何条件定义为"到两个定点的距离之和等于常数"，标志着圆锥曲线研究由"圆"向"椭"的逻辑进化。

### 原因
* **形成机制**：基于**距离之和的代数守恒**。设动点为 $M$，定点为 $F_1, F_2$，满足 $|MF_1| + |MF_2| = 2a$。通过建立直角坐标系并利用双根式化简技术（移项、平方、再平方），将几何约束转化为二次方程。
* **条件剖析**：必须满足 $2a > |F_1F_2|$（即 $a > c$）。
    * *反例*：若 $2a = |F_1F_2|$，轨迹退化为线段 $F_1F_2$；若 $2a < |F_1F_2|$，根据三角形两边之和大于第三边的性质，此时轨迹为空集。

### 结果
* **【核心公式提取（Formulas）】**：
  * **标准方程算子**：
    * 焦点在 $x$ 轴：$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \ (a > b > 0)$。
    * 焦点在 $y$ 轴：$\frac{y^2}{a^2} + \frac{x^2}{b^2} = 1 \ (a > b > 0)$。
  * **基本量关系**：$c^2 = a^2 - b^2$。
* **【重要性质归纳（Properties）】**：
  1. **对称性协议**：关于 $x$ 轴、$y$ 轴对称，关于原点中心对称。
  2. **范围限制**：焦点在 $x$ 轴时，$x \in [-a, a], y \in [-b, b]$。
  3. **离心率算子**：$e = \frac{c}{a} \in (0, 1)$。$e$ 越接近 $1$ 越扁平，$e$ 越接近 $0$ 越圆。
* **【核心特点剖析（Characteristics）】**：
  * *代数结构特征*：二次项系数不同但同号。
  * *几何图像特征*：具有长轴 $2a$ 和短轴 $2b$ 的闭合光滑曲线。
  * *符号特征*：分母大的对应轴即为焦点所在的轴。
* **【要素拆解】**：
  * 【适用前提】：平面内到两定点距离之和为常数且大于焦距。
  * 【核心结论】：椭圆是圆在特定方向上的仿射压缩（或拉伸）。
  * 【适用范围/边界】：当 $a=b$ 时，椭圆特例化为圆。

### 应用
* **学科内应用**：求点的轨迹方程（相关点法）、解决直线与椭圆的交切问题。
* **跨学科/实际应用**：**电影放映灯反射镜设计**。利用椭圆的光学性质（从一焦点发出的光经反射后汇聚于另一焦点）实现聚光。

### 本质
* **数学思想方法**：**分类讨论**（焦点位置）、**化归思想**（双根式消元）、**数形结合**。
* **高观点视域**：椭圆是偏心率 $e < 1$ 的圆锥截线。它展示了二阶代数曲线在欧几里得平面的有限域稳定性。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤
* **解题策略**：执行"一判（焦点位置）、二定（$a, b, c$ 关系）、三写（标准方程）"的 SOP。
* **标准操作步骤（SOP）**：
  * **步骤 $1$ [选型]**：根据焦点位置或对称性选择对应的标准方程模板。
  * **步骤 $2$ [列式]**：由定义或性质建立关于 $a, b, c$ 的方程组（注意 $a^2=b^2+c^2$ 始终成立）。
  * **步骤 $3$ [求解]**：解方程组锁定参数，代回模板完成方程重构。

---

### 典型例题
#### 例题1（基础示范题）：
1. **题目**：已知椭圆的两个焦点坐标分别是 $F_1(-2, 0), F_2(2, 0)$，并且经过点 $P(\frac{5}{2}, -\frac{3}{2})$，求其标准方程。
2. **【结构与特征分析】**：形视识别入口为"已知焦点在 $x$ 轴上的定点定义题"。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：根据焦点坐标锁定半焦距 $c=2$ 及焦点轴向（$x$ 轴） ➔ 选定方程模板。
   * *决策*：利用定义 $|PF_1| + |PF_2| = 2a$ 计算 $a$ 的数值。
   * *分支*：根据 $b^2 = a^2 - c^2$ 锁定短半轴平方。
   * *终点*：代入模板收敛。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [选型]]：焦点在 $x$ 轴，设为 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$。
   * [步骤 $2$ [定义计算]]：$|PF_1| = \sqrt{(\frac{5}{2}+2)^2 + (-\frac{3}{2})^2} = \frac{3\sqrt{10}}{2}$；$|PF_2| = \frac{\sqrt{10}}{2}$。
   * [步骤 $3$ [参数锁定]]：$2a = 2\sqrt{10} \implies a = \sqrt{10}, a^2 = 10$。$b^2 = 10 - 4 = 6$。
5. **【避坑提示】**：求距离时注意分数平方的准确性；不要忘记检验 $a > b$ 的一致性。
6. **结论**：$\frac{x^2}{10} + \frac{y^2}{6} = 1$。

#### 例题2（综合变式题）：
1. **题目**：设 $A, B$ 两点的坐标分别为 $(-5, 0), (5, 0)$。直线 $AM, BM$ 相交于点 $M$，且它们的斜率之积是 $-\frac{4}{9}$，求点 $M$ 的轨迹方程。
2. **【结构与特征分析】**：考查"动点轨迹的相关点法"。形视识别入口为"斜率乘积算子"。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：设动点 $M(x, y)$。
   * *决策*：分别表示 $k_{AM}$ 和 $k_{BM}$ 的代数式 ➔ 建立乘积等于 $-\frac{4}{9}$ 的等式。
   * *分支*：化简分式方程 ➔ 整理为标准曲线形式。
   * *收敛*：进行"剪枝"操作（排除使斜率不存在的点）。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [列式]]：$\frac{y}{x+5} \cdot \frac{y}{x-5} = -\frac{4}{9} \ (x \neq \pm 5)$。
   * [步骤 $2$ [化简]]：$\frac{y^2}{x^2-25} = -\frac{4}{9} \implies 9y^2 = -4x^2 + 100 \implies 4x^2 + 9y^2 = 100$。
   * [步骤 $3$ [标准化]]：等式两边除以 $100$ 得 $\frac{x^2}{25} + \frac{y^2}{100/9} = 1$。
5. **【避坑提示】**：分母 $x \pm 5 \neq 0$ 决定了轨迹必须去掉顶点 $(\pm 5, 0)$。
6. **结论**：$\frac{x^2}{25} + \frac{9y^2}{100} = 1 \ (x \neq \pm 5)$。

### 巩固习题
##### 梯度一：基础达标
1. **题 $1$ **：椭圆 $\frac{x^2}{100} + \frac{y^2}{36} = 1$ 上一点 $P$ 与焦点 $F_1$ 的距离为 $6$，求点 $P$ 与另一个焦点 $F_2$ 的距离。
   *   **答案**：$14$。解析：$2a = 20$，距离为 $20-6=14$。
2. **题 $2$ **：求焦点在 $x$ 轴上，$a=4, b=1$ 的椭圆标准方程。
   *   **答案**：$\frac{x^2}{16} + y^2 = 1$。

##### 梯度二：高考中档
3. **题 $3$ **：求离心率 $e = \frac{3}{5}$，长轴长等于 $20$ 的椭圆标准方程。
   *   **详细解析**：$a=10, c = ae = 6 \implies b^2 = 100-36=64$。分类讨论焦点在 $x$ 轴或 $y$ 轴，方程为 $\frac{x^2}{100} + \frac{y^2}{64} = 1$ 或 $\frac{y^2}{100} + \frac{x^2}{64} = 1$。
4. **题 $4$ **：已知 $P$ 是椭圆 $\frac{x^2}{5} + \frac{y^2}{4} = 1$ 上的一点，且以 $P$ 及焦点 $F_1, F_2$ 为顶点的三角形面积等于 $1$，求 $P$ 的纵坐标。
   *   **详细解析**：$c = \sqrt{5-4}=1 \implies |F_1F_2| = 2$。$S = \frac{1}{2} \cdot 2 \cdot |y_P| = 1 \implies |y_P| = 1 \implies y_P = \pm 1$。

##### 梯度三：能力拔高
5. **题 $5$ **：动点 $M$ 与定点 $F(4, 0)$ 的距离和它到定直线 $l: x = \frac{25}{4}$ 的距离的比是常数 $\frac{4}{5}$，证明点 $M$ 的轨迹是椭圆。
   *   **思维破局**：利用轨迹定义式列出 $\frac{\sqrt{(x-4)^2+y^2}}{|x-25/4|} = \frac{4}{5}$。
   *   **解析**：平方化简得 $25[(x-4)^2+y^2] = 16(x-\frac{25}{4})^2 \implies 9x^2+25y^2=225 \implies \frac{x^2}{25}+\frac{y^2}{9}=1$。符合椭圆定义。
