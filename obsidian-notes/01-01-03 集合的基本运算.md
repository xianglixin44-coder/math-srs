# 集合的基本运算
**教材**: 人教版必修第一册第一章 1.3 节

## 知识深度笔记

### 现象

这个知识研究的是**"数学地盘的合并、重叠与剔除"*。它试图解决如何描述多个条件同时满足、至少满足其一或排除特定范围的逻辑需求。

*   **【情境锚定：从"单兵作战"到"协同筛选"的演构】**：
    1.  *起因（背景与任务）**：掌握了集合的定义后，数学家需要处理更复杂的分类任务。例如，在学校选科统计中，需要确定"既选了物理又选了化学"的人群，以及"至少选了理科三门中一门"的总人数。
    2.  *冲突（瓶颈与矛盾）**：自然语言中的"且"、"或"、"非"虽然能描述需求，但在数学运算中缺乏对应的代数符号。我们不能简单地将选课人数相加，因为存在"重复计算"的问题（如两科都选的人会被算两次）。
    3.  *指向（概念的诞生）**：为了打破这个瓶颈，数学家类比实数的加减运算，建立了集合的"算术体系"——并集、交集与补集。这套运算将逻辑连接词具象化为几何空间的操作，实现了对数学边界的精确控制。

### 原因

集合运算的设计是为了将*布尔逻辑**（逻辑运算）转化为*几何投影**（空间运算）。

*   *形成机制**：交集对应逻辑"且"，并集对应逻辑"或"，补集对应逻辑"非"。通过这种映射，抽象的逻辑推导可以转化为直观的图形成像。
*   *条件剖析**：
    *   *全集（$U$）的约束**：定义补集 $\complement_U A$ 时，必须先指定讨论的"宇宙"范围 $U$。如果没有全集，那么"不属于 $A$ 的元素"将无限蔓延，导致逻辑失去边界。

### 结果

*   **【核心公式提取（Formulas）】**：
    1.  *并集 (Union)**：$A \cup B = \{x | x \in A \text{ 或 } x \in B\}$。
    2.  *交集 (Inter$\sec $tion)**：$A \cap B = \{x | x \in A \text{ 且 } x \in B\}$。
    3.  *补集 (Complement)**：$\complement_U A = \{x | x \in U \text{ 且 } x \notin A\}$。

*   **【重要性质归纳（Properties）】**：
    *   *容斥原理**：$card(A \cup B) = card(A) + card(B) - card(A \cap B)$。
    *   *德·摩根定律**：$\complement_U(A \cup B) = (\complement_U A) \cap (\complement_U B)$；$\complement_U(A \cap B) = (\complement_U A) \cup (\complement_U B)$。

*   **【核心特点剖析（Characteristics）】**：
    *   *代数结构特点**：交集运算使集合"变小或不变"，并集运算使集合"变大或不变"。
    *   *几何图形特点**：Venn 图中的"重叠部分"是交，"总覆盖面积"是并，"阴影以外"是补。

*   **【要素拆解（Elements Disassembly）】**：
    *   【适用前提】：参与运算的对象必须是集合。
    *   【适用边界】：若 $A \cap B = \emptyset$，则称 $A$ 与 $B$ 互斥。

### 应用

*   *学科内应用**：它是*联立方程组/不等式组*的本质。方程组的解集即为各个方程解集的"交集"。
*   *跨学科应用**：*搜索引擎逻辑*。当你搜索"北京 AND 奥运"时，系统正在执行两个关键词索引集合的交集运算。

### 本质

*   *数学思想方法**：*数形结合思想*。通过数轴和 Venn 图将不可见的逻辑关系可视化。
*   *高观点视域**：集合运算建立了*格论 (Lattice Theory)** 的原型，揭示了数学对象在合并与提取公共部分时遵循的代数结构。

## 方法、例题与解题训练

### 方法与步骤

*   *解题策略**：**"离散看图（Venn），连续看轴（数轴）"*。
*   *标准操作步骤（SOP）**：
    *   *步骤 1 [化简集合]**：解不等式或方程，将描述法转化为具体的元素或区间。
    *   *步骤 2 [视觉映射]**：在数轴上标出区间（注意实心与空心点）或画出 Venn 图。
    *   *步骤 3 [执行运算]**：交集找重叠区域；并集找所有覆盖区域；补集找全集内被"挖去"后的剩余区域。

### 典型例题

*例题 1（基础示范题）**：设 $A = \{x | -2 \le x \le 5\}$，$B = \{x | x^2 - x - 6 > 0\}$，求 $A \cap B$。

*   *解析（对照 SOP）**：
    1.  *步骤 1**：解析 $B$。解 $x^2 - x - 6 > 0 \implies (x-3)(x+2) > 0$，得 $B = (-\infty, -2) \cup (3, +\infty)$。
    2.  *步骤 2**：数轴定位。标出 $A = [-2, 5]$ 和 $B$ 的两个区间。
    3.  *步骤 3**：寻找重叠。$-2$ 在 $A$ 中但在 $B$ 外，不属于交集；$3$ 亦然。重叠区域为 $(3, 5]$。
*   *结论**：$A \cap B = \{x | 3 < x \le 5\}$。

*例题 2（综合变式题）**：某班 50 人，答对 $A$ 题 30 人，答对 $B$ 题 28 人，两题都错的 7 人，求两题都对的人数。

*   *解析**：
    1.  两题都错即 $\complement_U (A \cup B)$。
    2.  答对至少一题：$card(A \cup B) = 50 - 7 = 43$。
    3.  容斥原理：$43 = 30 + 28 - card(A \cap B)$，解得 $card(A \cap B) = 15$。
*   *结论**：15 人。

### 巩固习题

*梯度一：基础达标*1. 若 $U = \{1, 2, 3, 4, 5\}$，$A = \{2, 4\}$，$B = \{1, 3, 5\}$，求 $A \cap B$ 和 $\complement_U A$。
   *   答案：$\emptyset, \{1, 3, 5\}$。*

*梯度二：高考中档*2. 已知 $M = \{x | x^2 - 16 < 0\}$，$N = \{x | x^2 - 4x + 3 > 0\}$，求 $M \cup N$。
   *   解析：$M = (-4, 4)$，$N = (-\infty, 1) \cup (3, +\infty)$。并集覆盖整个实数集 $\mathbb{R}$。*

*梯度三：能力拔高*3. 已知 $A \cap B = \{2\}$，$A \cap (\complement_U B) = \{4\}$，$(\complement_U A) \cap B = \{6\}$，求 $A \cup B$。
   *   解析：利用 Venn 图，目标是各不相交区域的并。答案为 $\{2, 4, 6\}$。
