# 抛物线
**教材**: 人教版选择性必修第一册第三章 3.3 节

## 知识深度笔记

### 现象

* **【情境锚定：从"比例偏转"到"等距平衡"的逻辑归一】**：
  1. **起因（背景与任务）**：在研究完椭圆（离心率 $e < 1$）和双曲线（$e > 1$）后，一个自然的问题产生了：如果动点到定点的距离与其到定直线的距离"完全相等"（即 $e = 1$）时，会形成怎样的轨迹？
  2. **冲突（瓶颈与矛盾）**：传统的二次函数图象 $y = ax^2$ 虽然在视觉上呈现这种曲线，但缺乏基于"焦点"与"准线"定义的几何原理解析，无法解释为何手电筒反光镜或卫星天线必须采用这种特定形状。
  3. **指向（概念诞生）**：通过建立**抛物线协议（Parabola Protocol）**，数学家将几何条件定义为"平面内到定点 $F$ 和定直线 $l$ 距离相等的点的轨迹"，标志着人类掌握了聚集能量（光、波）的几何终极算子。

### 原因

* **形成机制**：基于**距离守恒逻辑**。设焦点 $F$ 到准线 $l$ 的距离为 $p$（$p > 0$）。建立直角坐标系，利用两点距离公式 $\sqrt{(x - p/2)^2 + y^2} = x + p/2$，平方化简得到最简代数约束 $y^2 = 2px$。
* **条件剖析**：定点 $F$ 不在定直线 $l$ 上。
    * *反例*：若点 $F$ 在直线 $l$ 上，则到点与到直线的距离相等的轨迹将退化为过点 $F$ 且垂直于 $l$ 的一条直线。

### 结果

* **【核心公式提取（Formulas）】**：
  * **标准方程四协议**：
    1. 右开口：$y^2 = 2px$，焦点 $(\frac{p}{2}, 0)$，准线 $x = -\frac{p}{2}$。
    2. 左开口：$y^2 = -2px$，焦点 $(-\frac{p}{2}, 0)$，准线 $x = \frac{p}{2}$。
    3. 上开口：$x^2 = 2py$，焦点 $(0, \frac{p}{2})$，准线 $y = -\frac{p}{2}$。
    4. 下开口：$x^2 = -2py$，焦点 $(0, -\frac{p}{2})$，准线 $y = \frac{p}{2}$。
* **【重要性质归纳（Properties）】**：
  1. **顶点与轴**：顶点恒为 $(0, 0)$，对称轴为一次项变量所在的轴。
  2. **焦半径算子**：对 $y^2 = 2px$ 上的点 $P(x, y)$，其焦半径 $|PF| = x + \frac{p}{2}$。
  3. **离心率恒定性**：抛物线的离心率 $e$ 恒等于 $1$。
* **【核心特点剖析（Characteristics）】**：
  * *代数结构特征*：一个变量二次，另一个变量一次（非对称性）。
  * *几何图像特征*：开口向无穷远处无限延伸的开放曲线。
  * *符号特征*：一次项前的系数 $2p$ 决定了开口的宽窄，$p$ 越大开口越开阔。
* **【要素拆解】**：
  * 【适用前提】：点到定点与定直线距离相等。
  * 【核心结论】：抛物线是能量聚集与平行转化的几何基础。
  * 【适用范围/边界】：注意焦点坐标与准线方程中 $p$ 的正负号及 $1/2$ 关系。

### 应用

* **学科内应用**：求解抛物线弦长、切线及与直线的交点问题。
* **跨学科/实际应用**：**卫星接收天线**。平行于轴射入的卫星波束经抛物面反射后精确聚集于焦点处。

### 本质

* **数学思想方法**：**待定系数法**（确定 $p$ 值）、**化归思想**（焦半径转化为到准线距离）。
* **高观点视域**：抛物线是圆锥截线在偏心率 $e \to 1$ 时的临界状态。它揭示了二阶代数曲线在欧几里得测度下的曲率平衡点。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

* **解题策略**：执行"一判（开口方向）、二求（参数 $p$）、三写（标准方程）"的 SOP。涉及距离问题时，强制利用抛物线定义执行"焦半径 $\leftrightarrow$ 准线距"的等价代换。
* **标准操作步骤（SOP）**：
  * **步骤 $1$ [选型锁定]**：根据焦点位置或准线方程判定开口方向，设定标准模板。
  * **步骤 $2$ [参数提取]**：利用已知点坐标或焦距关系解出 $p$ 值。
  * **步骤 $3$ [几何翻译]**：应用定义或性质（如 $|PF| = x + p/2$）进行度量计算。

---

### 典型例题

#### 例题1（基础示范题）：
1. **题目**：已知抛物线的焦点坐标是 $F(0, -2)$，求它的标准方程。
2. **【结构与特征分析】**：形视识别入口为"焦点在 $y$ 轴负半轴上"。公式骨架对应 $x^2 = -2py$。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：观察焦点坐标 $(0, -2)$。
   * *决策*：判定开口向下 ➔ 匹配方程模板 $x^2 = -2py$。
   * *分支*：根据焦点坐标公式 $(0, -p/2)$ 提取 $p$ 的数值。
   * *终点*：代入模板完成方程重构。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [选型]]：焦点在 $y$ 轴负半轴，设方程为 $x^2 = -2py$。
   * [步骤 $2$ [求 $p$]]：由 $\frac{p}{2} = 2$ 得 $p = 4$。
   * [步骤 $3$ [输出]]：标准方程为 $x^2 = -8y$。
5. **【避坑提示】**：注意焦点坐标的分母是 $2$，计算时极易将 $p$ 误计为 $2$。
6. **结论**：$x^2 = -8y$。

#### 例题2（综合变式题）：
1. **题目**：斜率为 $1$ 的直线 $l$ 经过抛物线 $y^2 = 4x$ 的焦点 $F$，且与抛物线相交于 $A, B$ 两点，求线段 $AB$ 的长。
2. **【结构与特征分析】**：考查"抛物线焦点弦长"。形视识别入口为"定义转换法"。核心在于利用 $|AB| = x_1 + x_2 + p$。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：提取参数 $p = 2$，焦点 $F(1, 0)$。
   * *决策*：根据抛物线定义，将弦长 $|AB|$ 转化为点 $A, B$ 到准线的距离之和。
   * *分支*：联立直线方程 $y = x - 1$ 与 $y^2 = 4x$ ➔ 提取根与系数的关系 $x_1 + x_2$。
   * *收敛*：应用算子 $|AB| = x_1 + x_2 + 2$ 计算结果。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [联立方程]]：将 $y = x - 1$ 代入 $y^2 = 4x$ 得 $(x-1)^2 = 4x \implies x^2 - 6x + 1 = 0$。
   * [步骤 $2$ [提取和]]：由韦达定理得 $x_1 + x_2 = 6$。
   * [步骤 $3$ [定义计算]]：$|AB| = x_1 + x_2 + p = 6 + 2 = 8$。
5. **【避坑提示】**：求弦长时尽量避开两点距离公式，利用定义法（$x_1 + x_2 + p$）计算量最小且不易出错。
6. **结论**：线段 $AB$ 的长是 $8$。

### 巩固习题

##### 梯度一：基础达标
1. **题 $1$ **：求抛物线 $x^2 = \frac{1}{2}y$ 的焦点坐标和准线方程。
   * **答案**：$(0, \frac{1}{8})$；$y = -\frac{1}{8}$。解析：$2p = 1/2 \implies p = 1/4$。
2. **题 $2$ **：抛物线 $y^2 = 12x$ 上与焦点的距离等于 $9$ 的点的横坐标是 ____。
   * **答案**：$6$。解析：$x + 3 = 9 \implies x = 6$。

##### 梯度二：高考中档
3. **题 $3$ **：已知抛物线的顶点在原点，对称轴为 $x$ 轴，且经过点 $M(5, -4)$，求其方程。
   * **详细解析**：设 $y^2 = 2px$。代入得 $16 = 10p \implies 2p = 3.2$。方程为 $y^2 = 3.2x$。
4. **题 $4$ **：垂直于 $x$ 轴的直线交抛物线 $y^2 = 4x$ 于 $A, B$ 两点，且 $|AB| = 4\sqrt{3}$，求直线方程。
   * **详细解析**：设 $A(x_0, y_0)$，则 $2|y_0| = 4\sqrt{3} \implies y_0^2 = 12$。代入得 $12 = 4x_0 \implies x_0 = 3$。方程为 $x = 3$。

##### 梯度三：能力拔高
5. **题 $5$ **：设抛物线 $y^2 = 2px$ ($p > 0$) 的焦点为 $F$，过点 $M(-p, 0)$ 的直线 $l$ 与抛物线相交于 $A, B$ 两点。证明：$\overrightarrow{FA} \cdot \overrightarrow{FB}$ 为定值。
   * **思维破局**：建立坐标系，联立直线 $y = k(x + p)$。利用数量积坐标运算及韦达定理消元。
   * **解析**：经计算 $\vec{FA} \cdot \vec{FB} = (x_1 - p/2)(x_2 - p/2) + y_1y_2$。代入消元后得定值 $\frac{3}{4}p^2$。
