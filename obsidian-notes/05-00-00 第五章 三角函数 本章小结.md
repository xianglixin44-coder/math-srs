# 第五章 三角函数 本章小结
**教材**: 人教版必修第一册第五章

## 知识深度笔记

### 现象
*   **【情境锚定：从"圆周旋转"到"实数映射"的度量闭环】**：
    *   **起因（背景与任务）**：自然界中充满了如潮汐、交变电流、摩天轮旋转等周而复始的周期性现象。
    *   **冲突（瓶颈与矛盾）**：初中几何角受限于 $0^{\circ} \sim 360^{\circ}$，且角度制与实数无法直接运算（如 $60^{\circ} + \sin 60^{\circ}$ 逻辑错配），导致数学模型无法精确描述连续且无限延伸的波动过程。
    *   **指向（概念诞生）**：通过建立**单位圆协议（Unit Circle Protocol）**与**弧度制**，将角从几何图形升维为实数，并利用圆的旋转对称性定义三角函数，实现了对一切周期现象的标准化数学编码。

### 原因
*   **形成机制**：基于**单位圆对称性与坐标映射逻辑**。
    1.  **度量统一**：弧度制利用弧长与半径的比值定义角，使自变量与函数值均实数化。
    2.  **坐标映射**：将角 $\alpha$ 的终边与单位圆交点 $P(x, y)$ 绑定，使 $\sin \alpha = y, \cos \alpha = x$。
    3.  **结构衍生**：利用旋转变换推导和差角公式，进而演化出倍角与诱导公式。
*   **条件剖析**：所有变换必须在定义域安全区执行。
    *   *反例*：在应用 $\tan \alpha$ 相关公式时，若角 $\alpha$ 落在 $k\pi + \frac{\pi}{2}$，则正切算子因分母为零而失效。

### 结果
*   **【核心公式提取（Formulas）】**：
    *   **同角基本关系**：$\sin^2 \alpha + \cos^2 \alpha = 1$；$\tan \alpha = \frac{\sin \alpha}{\cos \alpha}$。
    *   **和差角协议**：$\cos(\alpha \mp \beta) = \cos \alpha \cos \beta \pm \sin \alpha \sin \beta$。
    *   **倍角算子**：$\sin 2\alpha = 2\sin \alpha \cos \alpha$；$\cos 2\alpha = 2\cos^2 \alpha - 1$。
*   **【重要性质归纳（Properties）】**：
    1.  **周期与对称契约**：正/余弦最小正周期为 $2\pi$；正弦关于原点奇对称，余弦关于 $y$ 轴偶对称。
    2.  **变换核能**：利用辅助角公式 $a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\phi)$ 实现多名向单名的坍缩。
*   **【核心特点剖析（Characteristics）】**：
    *   **代数结构特征**：呈现出极强的对称性与周期重复性。
    *   **几何图像特征**：波浪状曲线，具有无数个对称轴与对称中心。
*   **【要素拆解】**：
    *   【适用前提】：弧度制环境，定义域合法。
    *   【核心结论】：三角函数是单位圆在坐标轴上的投影演化。

### 应用
*   **学科内应用**：作为解三角形、复数运算及后续导数研究的核心算子。
*   **跨学科/实际应用**：**信号处理（傅里叶分析基础）**。任何复杂的周期信号均可视为一系列 $y = A\sin(\omega x + \phi)$ 简谐波的叠加。

### 本质
*   **数学思想方法**：**数形结合**（单位圆几何 ↔ 坐标代数）、**化归转化**（复角 → 单角、异名 → 同名）。
*   **高观点视域**：三角函数本质上是复数域旋转算子 $e^{i\theta}$ 的实部与虚部。它揭示了线性平移与圆周旋转在拓扑结构上的统一。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤
*   **解题策略**：执行"一核（角的关系）、二统（函数名统一）、三简（结构最简）"的变换 SOP。
*   **标准操作步骤（SOP）**：
    *   **步骤 $1$：[角变换]** 分析已知角与目标角的关系（如 $2\alpha$、$15^{\circ}=45^{\circ}-30^{\circ}$）。
    *   **步骤 $2$：[名统一]** 利用同角关系或诱导公式将异名函数化为同名（通常"切化弦"或"化一"）。
    *   **步骤 $3$：[值/性判定]** 结合象限符号协议完成求值或性质分析。

---

### 典型例题
#### 例题1（综合恒等变换示范）：
**题目**：已知 $\frac{\sin \alpha + \cos \alpha}{\sin \alpha - \cos \alpha} = \frac{1}{2}$，求 $\sin 2\alpha$ 的值。

1.  **【结构与特征分析】**：形视识别入口为"齐次分式结构"。可"弦化切"；目标为倍角正弦。
2.  **【解题决策逻辑流（思维推演）】**：
    *   起点（源头）：分子分母同除 $\cos \alpha$ → $\frac{\tan \alpha + 1}{\tan \alpha - 1} = \frac{1}{2}$ → $\tan \alpha = -3$ ➔
    *   决策（构造）：$\sin 2\alpha = \frac{2\tan \alpha}{\tan^2 \alpha + 1}$ ➔
    *   终点（收敛）：$= -6/10 = -0.6$。
3.  **【解析（对照 SOP 步骤）】**：$\sin 2\alpha = -0.6$。
4.  **【避坑提示】**：不要忘记分母隐藏的 $1$（即 $\sin^2 + \cos^2$）。
**结论**：$-0.6$。

#### 例题2（综合性质判定变式）：
**题目**：$f(x) = \sin \omega x + \sqrt{3}\cos \omega x$ ($\omega>0$)，相邻对称轴间距 $\pi/2$，求单调递增区间。

1.  **【结构与特征分析】**：形视识别入口为"异名一次叠加"。需辅助角坍缩+周期反求参数。
2.  **【解题决策逻辑流（思维推演）】**：
    *   起点（源头）：辅助角：$f(x) = 2\sin(\omega x + \pi/3)$ ➔
    *   $T/2 = \pi/2 \implies T = \pi \implies \omega = 2$ ➔
    *   $2\sin(2x + \pi/3)$，令 $2k\pi - \pi/2 \le 2x + \pi/3 \le 2k\pi + \pi/2$ ➔
    *   终点（收敛）：$k\pi - 5\pi/12 \le x \le k\pi + \pi/12$。
3.  **【解析（对照 SOP 步骤）】**：递增区间 $[k\pi - 5\pi/12, k\pi + \pi/12]$。
4.  **【避坑提示】**：相邻对称轴是半周期，相邻对称中心与对称轴是四分之一周期。
**结论**：$[k\pi - 5\pi/12, k\pi + \pi/12], k \in \mathbb{Z}$。

1.  **题 $1$ **：$\sin \alpha = 3/5, \alpha \in (\pi/2, \pi)$ → $\cos \alpha = -4/5, \tan \alpha = -3/4$。
2.  **题 $2$ **：$\frac{\sin(\pi+\alpha)\cos(-\alpha)}{\sin(\pi/2-\alpha)\tan(\pi-\alpha)} = \sin\alpha/\tan\alpha$。

##### 梯度二：高考中档
3.  **题 $3$ **：$\frac{1-\tan^2 15^{\circ}}{1+\tan^2 15^{\circ}} = \cos 30^{\circ} = \sqrt{3}/2$。
4.  **题 $4$ **：$\sin A = \sqrt{5}/5, \sin B = \sqrt{10}/10$，$A,B$ 锐角 → $A+B = \pi/4$。

5.  **题 $5$ **：$f(x) = \sin^2 x + \sqrt{3}\sin x\cos x + 2\cos^2 x = \sin(2x+\pi/6) + 3/2$。对称中心 $(\frac{k\pi}{2} - \frac{\pi}{12}, 3/2)$。
