# 平面向量的正交分解及坐标表示
**教材**: 人教版必修第二册第六章 6.3.2 节

## 知识深度笔记

### 现象
*   **【情境锚定：从"随意拆解"到"标准化网格"的协议统一】**：
    *   **起因（背景与任务）**：平面向量基本定理允许我们选取任意两个不共线向量作为基底。但在物理力学中，研究重力在斜面上的分解时，我们更习惯于沿"平行斜面"和"垂直斜面"这两个相互垂直的方向进行拆分。
    *   **冲突（瓶颈与矛盾）**：虽然任意基底都能表示向量，但如果每个人选取的基底角度、模长都不同，向量的运算将退化为繁琐的几何作图，无法实现像实数加减那样高效的"算术化"。
    *   **指向（概念诞生）**：通过建立**正交分解协议（Orthogonal Decomposition Protocol）**，选取相互垂直的单位向量 $\vec{i}, \vec{j}$ 作为全球统一的基底，将向量映射为有序实数对 $(x, y)$，实现了向量从"几何实体"向"代数坐标"的数字化迁移。

### 原因
*   **形成机制**：基于**笛卡儿坐标系与正交投影逻辑**。
    1.  **基底标准化**：在平面直角坐标系中，取与 $x$ 轴、$y$ 轴方向相同的单位向量 $\vec{i}, \vec{j}$ 作为基底。
    2.  **唯一性分解**：根据基本定理，平面内任一向量 $\vec{a}$ 可唯一表示为 $\vec{a} = x\vec{i} + y\vec{j}$。
    3.  **坐标映射**：将系数对 $(x, y)$ 定义为向量的坐标。当向量起点位于原点 $O$ 时，向量坐标等于终点 $A$ 的坐标。
*   **条件剖析**：基底必须满足 $|\vec{i}| = |\vec{j}| = 1$ 且 $\vec{i} \perp \vec{j}$。
    *   *反例*：若选取的两个垂直向量模长不为 $1$，则坐标数值将失去度量意义。

### 结果
*   **【核心公式提取（Formulas）】**：
    *   **坐标表示算子**：$\vec{a} = (x, y)$，等价于 $\vec{a} = x\vec{i} + y\vec{j}$。
    *   **特殊向量坐标**：$\vec{i} = (1, 0), \vec{j} = (0, 1), \vec{0} = (0, 0)$。
*   **【重要性质归纳（Properties）】**：
    1.  **点矢同构性**：若 $\vec{OA} = \vec{a}$，则点 $A$ 的坐标即为向量 $\vec{a}$ 的坐标。
    2.  **自由性保持**：相等的向量在坐标系中具有完全相同的坐标 $(x, y)$，无论其起点处于何处。
*   **【核心特点剖析（Characteristics）】**：
    *   **代数结构特征**：将二维空间的指向性转化为两个独立的一维数值维度。
    *   **几何图像特征**：通过坐标，将向量的"头"精准定位在笛卡儿网格点上。
*   **【要素拆解】**：
    *   【适用前提】：建立平面直角坐标系。
    *   【核心结论】：向量运算可完全转化为坐标的数值运算。

### 应用
*   **学科内应用**：作为后续向量加减、数乘、数量积坐标运算的"操作系统"。
*   **跨学科/实际应用**：**数控机床（CNC）编程**。通过设定刀具路径的向量坐标 $(x, y)$，控制步进电机在 $X$ 轴和 $Y$ 轴上的脉冲数，实现零件的精确加工。

### 本质
*   **数学思想方法**：**数形结合**（向量几何 ↔ 代数坐标）、**解析法**。
*   **高观点视域**：正交分解本质上是内积空间中的傅里叶展开（最简单形式）。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤
*   **解题策略**：执行"一画轴（确定分量方向）、二投影（分解至轴上）、三读数（提取系数对）"的坐标化 SOP。
*   **标准操作步骤（SOP）**：
    *   **步骤 $1$ [分量映射]**：将向量 $\vec{a}$ 沿 $x$ 轴和 $y$ 轴方向进行正交分解。
    *   **步骤 $2$ [系数提取]**：测量或计算水平分量长度 $x$ 和垂直分量长度 $y$。
    *   **步骤 $3$ [格式输出]**：写成 $(x, y)$ 形式并标注基底关系。

---

### 典型例题
#### 例题1（基础图象识别）：
**题目**：用基底 $\vec{i}, \vec{j}$ 表示向量 $\vec{a}, \vec{b}, \vec{c}, \vec{d}$，并求出它们的坐标。

1.  **【结构与特征分析】**：形视识别入口为"已知终点位置求向量坐标"。起点在原点。
2.  **【解题决策逻辑流（思维推演）】**：
    *   $\vec{a} = 2\vec{i} + 3\vec{j} \implies (2, 3)$ ➔
    *   $\vec{b} = -2\vec{i} + 3\vec{j} \implies (-2, 3)$ ➔
    *   $\vec{c} = -2\vec{i} - 3\vec{j} \implies (-2, -3)$ ➔
    *   $\vec{d} = 2\vec{i} - 3\vec{j} \implies (2, -3)$。
3.  **【解析（对照 SOP 步骤）】**：$\vec{a}=(2,3), \vec{b}=(-2,3), \vec{c}=(-2,-3), \vec{d}=(2,-3)$。
4.  **【避坑提示】**：注意区分点坐标与向量坐标，数值相同但须用向量符号表示。
**结论**：$\vec{a}=(2,3), \vec{b}=(-2,3), \vec{c}=(-2,-3), \vec{d}=(2,-3)$。

#### 例题2（物理情境建模）：
**题目**：重为 $G = 100N$ 的物体放在倾角为 $30^{\circ}$ 的光滑斜面上，将重力 $\vec{G}$ 进行正交分解。

1.  **【结构与特征分析】**：形视识别入口为"力学正交分解"。
2.  **【解题决策逻辑流（思维推演）】**：
    *   沿斜面：$|\vec{F}_1| = G \sin 30^{\circ} = 50N$ ➔
    *   垂直斜面：$|\vec{F}_2| = G \cos 30^{\circ} \approx 86.6N$。
3.  **【解析（对照 SOP 步骤）】**：平行分力 $50N$，垂直分力约 $86.6N$。
4.  **【避坑提示】**：两分量方向必须成 $90^{\circ}$。
**结论**：$50N$ 和 $86.6N$。
