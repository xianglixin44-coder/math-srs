# 第1章 空间向量与立体几何 本章小结
**教材**: 人教版选择性必修第一册第一章本章小结

## 知识深度笔记

### 现象
* **【情境锚定：从"平面限制"到"空间全景"的协议进化】**：
  1. **起因（背景与任务）**：在滑翔伞运动或建筑结构分析中，物体受到的力（如绳索拉力、风力、重力）通常不在同一个平面内。
  2. **冲突（瓶颈与矛盾）**：传统的平面向量工具无法描述非共面对象的相互作用。单纯的综合几何方法（立体几何初步）过度依赖空间想象和复杂的辅助线，难以实现精确的量化度量。
  3. **指向（概念诞生）**：通过将向量从二维平面推广到三维空间，数学家建立了**空间向量协议**。它让几何量带上了方向，并用统一的代数符号表示，标志着立体几何研究进入了"运算化"时代。

### 原因
* **形成机制**：空间向量的逻辑地基是**空间向量基本定理**。由于空间中任意三个不共面的向量 $\{\vec{a}, \vec{b}, \vec{c}\}$ 均可构成基底，空间中任一向量 $\vec{p}$ 均可被唯一拆解为 $\vec{p} = x\vec{a} + y\vec{b} + z\vec{c}$。
* **条件剖析**：向量线性运算和数量积运算在空间与平面中具有一致性，因为任意两个空间向量总能平移至同一平面。
    * *反例*：若选取的三个向量共面，则无法表示平面外的向量，导致三维空间的描述力丧失。

### 结果
* **【核心公式提取（Formulas）】**：
  * **坐标算子**：$\vec{a} = (x, y, z)$，将几何指向转化为三元有序实数对。
  * **数量积度量**：$\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\langle \vec{a}, \vec{b} \rangle = a_1b_1 + a_2b_2 + a_3b_3$。
* **【重要性质归纳（Properties）】**：
  1. **位置协议**：$\vec{a} \parallel \vec{b} \iff \vec{a} = \lambda \vec{b}$；$\vec{a} \perp \vec{b} \iff \vec{a} \cdot \vec{b} = 0$。
  2. **法向量工具**：平面 $\alpha$ 的位置由点 $A$ 及其法向量 $\vec{n}$ 唯一确定，满足 $\vec{n} \cdot \overrightarrow{AP} = 0$。
* **【核心特点剖析（Characteristics）】**：
  * *代数结构特征*：线性组合结构 $x\vec{a} + y\vec{b} + z\vec{c}$，实现了从"形"到"数"的完整映射。
  * *几何图像特征*：平行六面体法则。
  * *符号特征*：$\vec{a}^2 = |\vec{a}|^2$。
* **【要素拆解】**：
  * 【适用前提】：研究对象具备大小与方向属性，且处于三维欧几里得空间。
  * 【核心结论】：空间关系可通过向量运算（线性、数量积）实现自动化判定。
  * 【适用范围/边界】：零向量 $\vec{0}$ 的方向不确定，但与任何向量平行。

### 应用
* **学科内应用**：证明空间直线与平面的平行、垂直，计算二面角、线面角及点面距离。
* **跨学科/实际应用**：**电影放映灯反射镜面设计**。利用旋转椭圆面的光学性质（从一焦点发出的光经反射后汇聚于另一焦点）优化照明。

### 本质
* **数学思想方法**：**类比思想**（从平面到空间）、**化归思想**（几何问题代数化）以及**坐标法**。
* **高观点视域**：本章是线性代数的物理化实践。它证明了物理空间的拓扑关系可以被线性算子语言完全覆盖，是"数学机械化"思想在几何领域的典型体现。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤
* **解题策略**：执行**"向量法三步曲"**：**向量化**（表述点、线、面） $\to$ **运算化**（计算位置与度量） $\to$ **翻译化**（得出几何结论）。
* **标准操作步骤（SOP）**：
  * **步骤 $1$ [建系/定基]**：建立空间直角坐标系（坐标法）或选取不共面基底（基底法）。
  * **步骤 $2$ [表示]**：求出直线的方向向量、平面的法向量坐标。
  * **步骤 $3$ [计算与翻译]**：应用夹角公式 $\cos\theta = \frac{|\vec{u} \cdot \vec{v}|}{|\vec{u}||\vec{v}|}$ 或距离公式进行代数求解并还原几何意义。

---

### 典型例题
#### 例题1（基础示范题）：
1. **题目**：已知向量 $\vec{a} = (x, 2, 2)$，$\vec{b} = (2, -3, 1)$。若 $\vec{a} \perp \vec{b}$，求 $x$ 的值。
2. **【结构与特征分析】**：形视识别入口为"空间向量垂直的坐标判定"。公式骨架对应数量积为 $0$。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：提取垂直的充要条件 ➔ 数量积等于 $0$。
   * *分支*：代入分量坐标。
   * *终点*：解一元一次方程收敛。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [算子提取]]：$\vec{a} \cdot \vec{b} = 2x + 2 \times (-3) + 2 \times 1$。
   * [步骤 $2$ [解方程]]：$2x - 6 + 2 = 0 \implies 2x = 4 \implies x = 2$。
5. **【避坑提示】**：注意 $y$ 分量中 $-3$ 的正负号计算。
6. **结论**：$x = 2$。

#### 例题2（综合变式题）：
1. **题目**：在正方体 $ABCD-A_1B_1C_1D_1$ 中，利用向量法证明：$A_1C \perp$ 平面 $BC_1D$。
2. **【结构与特征分析】**：形视识别入口为"线面垂直的向量化证明"。核心逻辑是证明直线的方向向量与平面内两条相交直线的方向向量均垂直。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：建立空间直角坐标系。
   * *决策*：写出 $A_1, C, B, C_1, D$ 各点坐标。
   * *分支*：求得方向向量 $\overrightarrow{A_1C}, \overrightarrow{BC_1}, \overrightarrow{BD}$ ➔ 分别执行数量积运算。
   * *收敛*：证明两个积均为 $0$ ➔ 根据线面垂直判定定理翻译结果。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [建系]]：以 $D$ 为原点，棱长为 $1$。$A_1(1, 0, 1), C(0, 1, 0), B(1, 1, 0), C_1(0, 1, 1)$。
   * [步骤 $2$ [表示]]：$\overrightarrow{A_1C} = (-1, 1, -1)$，$\overrightarrow{BC_1} = (-1, 0, 1)$，$\overrightarrow{BD} = (-1, -1, 0)$。
   * [步骤 $3$ [运算]]：$\overrightarrow{A_1C} \cdot \overrightarrow{BC_1} = 1 + 0 - 1 = 0$；$\overrightarrow{A_1C} \cdot \overrightarrow{BD} = 1 - 1 + 0 = 0$。
5. **【避坑提示】**：证明线面垂直必须找平面内两条"相交"直线。
6. **结论**：得证 $A_1C \perp$ 平面 $BC_1D$。

### 巩固习题
##### 梯度一：基础达标
1. **题 $1$ **：若 $\vec{a}=(1, 2, -2)$，则 $|\vec{a}|=$ ____。
   *   **答案**：$3$。解析：$\sqrt{1^2 + 2^2 + (-2)^2} = 3$。
2. **题 $2$ **：判断：三向量共面的充要条件是它们模长相等。
   *   **答案**：错误。解析：共面充要条件是 $\vec{p} = x\vec{a} + y\vec{b}$。

##### 梯度二：高考中档
3. **题 $3$ **：已知平面 $\alpha$ 的法向量为 $\vec{n} = (1, 0, 1)$，点 $A(1, 1, 1)$ 在 $\alpha$ 内，求点 $P(2, 3, 4)$ 到 $\alpha$ 的距离。
   *   **详细解析**：$\overrightarrow{AP} = (1, 2, 3)$。距离 $d = \frac{|\overrightarrow{AP} \cdot \vec{n}|}{|\vec{n}|} = \frac{|1+0+3|}{\sqrt{2}} = 2\sqrt{2}$。
4. **题 $4$ **：求向量 $\vec{a}=(1, 1, 0)$ 与 $\vec{b}=(0, 1, 1)$ 夹角的余弦值。
   *   **详细解析**：$\cos\theta = \frac{1}{\sqrt{2} \times \sqrt{2}} = 0.5$。结果为 $0.5$。

##### 梯度三：能力拔高
5. **题 $5$ **：设 $\{\vec{e_1}, \vec{e_2}, \vec{e_3}\}$ 是空间单位正交基底，若 $\vec{a} = \vec{e_1} + \vec{e_2}$，$\vec{b} = \vec{e_2} + \vec{e_3}$，求 $|\vec{a} - 2\vec{b}|$ 的值。
   *   **思维破局**：将基底线性组合转化为坐标运算 $(1, 1, 0) - 2(0, 1, 1) = (1, -1, -2)$。
   *   **解析**：结果为 $\sqrt{1^2 + (-1)^2 + (-2)^2} = \sqrt{6}$。
