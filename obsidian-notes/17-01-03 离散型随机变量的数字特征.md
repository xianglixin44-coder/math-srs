# 离散型随机变量的数字特征
**教材**: 人教版选择性必修第三册第七章 7.3 节

## 知识深度笔记

### 现象

*   **【情境锚定：从"分布全景"到"指标压缩"的决策提炼】**：
    *   **起因（背景与任务）**：在体育竞技（如射箭选拔）中，面临对比甲、乙两名运动员优劣的任务。虽然已知他们的环数分布列，但在瞬息万变的赛场上，教练需要一个具体的数值来判定"谁的平均水平更高"以及"谁的表现更稳定"。
    *   **冲突（瓶颈与矛盾）**：分布列虽然全面，但数据过于离散，无法直观给出量化的优劣位序。当两人的平均环数（均值）相等时，旧有的直观观察法失效，无法测度两者在"质量波动"上的本质差异。
    *   **指向（概念诞生）**：通过提取分布列中的关键统计算子，建立了**均值（数学期望）协议**与**方差/标准差协议**，标志着随机现象的研究由"全量描述"进阶为"特征刻画"。

### 原因

*   **形成机制**：基于**物理重心逻辑**与**离散度算法**。
    1.  **均值（期望）**：以概率为权数，将随机变量的所有取值进行加权求和，其物理本质是分布的"重心"，代表长期试验的平均结果。
    2.  **方差**：计算各取值与"重心"偏差平方的加权平均，通过平方操作消除正负抵消，从而精准锁定量化的波动幅度。
*   **条件剖析**：均值存在的前提是分布列满足规范性 $\sum p_i = 1$。
    *   *反例*：在有限取值的离散协议下，均值总是确定的；但在某些理论上的无限取值模型中，若级数不收敛，则期望不存在，导致决策逻辑崩塌。

### 结果

*   **【核心公式提取（Formulas）】**：
    *   **均值算子**：$$E(X) = \sum_{i=1}^{n} x_i p_i$$。
    *   **方差算子**：$$D(X) = \sum_{i=1}^{n} (x_i - E(X))^2 p_i = \sum_{i=1}^{n} x_i^2 p_i - [E(X)]^2$$。
    *   **线性变换协议**：$$E(aX + b) = aE(X) + b$$ ； $$D(aX + b) = a^2 D(X)$$。
*   **【重要性质归纳（Properties）】**：
    1.  **集中趋势**：均值反映了变量取值的平均水平。
    2.  **波动特性**：方差越小，数据越集中；方差越大，数据越离散。
    3.  **标准差算子**：$\sigma(X) = \sqrt{D(X)}$，用于恢复量纲以进行实际物理量比对。
*   **【核心特点剖析（Characteristics）】**：
    *   **代数结构特征**：期望是线性泛函（满足分配律）；方差是二次型算子（对平移不敏感，对缩放呈平方响应）。
    *   **符号特征**：$E$ 为 Expectation，$D$ 为 Variance。
*   **【要素拆解】**：
    *   【适用前提】：离散型随机变量及其分布列已知。
    *   【核心结论】：均值定"高下"（水平），方差定"稳健"（质量）。

### 应用

*   **学科内应用**：作为评估二项分布与超几何分布性能的终极判据。
*   **跨学科/实际应用**：**投资风险决策**。金融分析师通过比较不同股票收益的 $E(X)$（预期回报）与 $D(X)$（风险波动），在收益相近时优先选择方差较小的资产组合。

### 本质

*   **数学思想方法**：**数学抽象**、**化归思想**（将复杂分布归结为单点指标）。
*   **高观点视域**：均值是一阶原点矩，方差是二阶中心矩。它们是概率分布在低维空间的"特征投影"，体现了统计学从描述静态样本向推断系统演化规律的逻辑飞跃。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

*   **解题策略**：执行"一列（分布列）、二算（期望）、三求（方差）、四推（决策）"的 SOP。涉及线性变换时，强制调用变换算子，严禁重复列表。
*   **标准操作步骤（SOP）**：
    *   **步骤 $1$：[分布重组]** 求出变量 $X$ 的分布列并验证和为 $1$。
    *   **步骤 $2$：[重心定位]** 代入 $\sum x_i p_i$ 计算均值。
    *   **步骤 $3$：[离散测度]** 代入 $\sum x_i^2 p_i - [E(X)]^2$ 快速计算方差。
    *   **步骤 $4$：[性质迁移]** 若涉及 $aX+b$，直接利用系数进行转换。

---

### 典型例题

#### 例题1（基础示范题）：
**题目**：已知随机变量 $X$ 的分布列为 $P(X=0)=0.2, P(X=1)=0.5, P(X=2)=0.3$，求 $E(X), D(X)$ 及 $Y = 3X + 2$ 的期望与方差。

1. **【结构与特征分析】**：形视识别入口为"已知有限点分布列求特征"。核心考查基本算子及线性性质。
2. **【解题决策逻辑流（思维推演）】**：
    *   起点：期望定义算子 ➔
    *   分支：先计算 $E(X)$ ➔ 计算 $E(X^2)$ ➔ 差值法求 $D(X)$ ➔
    *   决策：调用线性变换协议 ➔ 终点：代数计算收敛。
3. **【解析（对照 SOP 步骤）】**：
    * [步骤 2 [均值]]：$E(X) = 0 \times 0.2 + 1 \times 0.5 + 2 \times 0.3 = 1.1$。
    * [步骤 3 [方差]]：$E(X^2) = 0^2 \times 0.2 + 1^2 \times 0.5 + 2^2 \times 0.3 = 1.7$。$D(X) = 1.7 - 1.1^2 = 0.49$。
    * [步骤 4 [变换]]：$E(Y) = 3 \times 1.1 + 2 = 5.3$；$D(Y) = 3^2 \times 0.49 = 4.41$。
4. **【避坑提示】**：求 $D(X)$ 时务必减去期望的平方，不要只算到 $E(X^2)$。
**结论**：$E(X)=1.1, D(X)=0.49, E(Y)=5.3, D(Y)=4.41$。

#### 例题2（综合变式题）：
**题目**：某地区近期有小洪水的概率为 $0.25$，有大洪水的概率为 $0.01$。工地上有台设备，大洪水损失 $60000$ 元，小洪水损失 $10000$ 元。方案 A 为运走设备（费 $3800$ 元），方案 B 为建围墙（费 $2000$ 元，仅防小洪水）。哪种方案最优？

1. **【结构与特征分析】**：形视识别入口为"期望损失最小化模型"。
2. **【解题决策逻辑流（思维推演）】**：
    *   起点：理性决策准则（期望总损失最小） ➔
    *   分支（方案 A）：全量损失为常数 $3800$ ➔
    *   分支（方案 B）：大洪水损失 $62000$（建设费+设备），非大洪水损失 $2000$ ➔
    *   终点：比较期望值。
3. **【解析（对照 SOP 步骤）】**：
    * [步骤 1 [建模]]：$E(X_A) = 3800$。
    * [步骤 2 [计算 B]]：$E(X_B) = 62000 \times 0.01 + 2000 \times 0.99 = 2600$。
    * [步骤 3 [比较]]：$2600 < 3800$，方案 B 最优。
4. **【避坑提示】**：建设费（投入）也是损失的一部分，必须计入变量值中。
**结论**：选方案 B（建围墙）。

### 巩固习题

##### 梯度一：基础达标
1.  **题 $1$ **：若随机变量 $X$ 服从两点分布，且 $P(X=1) = 0.3$，则 $E(X) = $ ____，$D(X) = $ ____。
    *   **答案**：$0.3$；$0.21$。步骤：$E(X)=p=0.3$，$D(X)=p(1-p)=0.21$。
2.  **题 $2$ **：已知 $E(X) = 2, D(X) = 1$，则 $E(2X-1) = $ ____，$D(2X-1) = $ ____。
    *   **答案**：$3$；$4$。步骤：$2 \times 2 - 1 = 3$，$2^2 \times 1 = 4$。

##### 梯度二：高考中档
3.  **题 $3$ **：已知 $P(X=k) = k/a (k=1,2,3)$，求 $D(X)$。
    *   **详细解析**：$a=6$。$E(X)=7/3$，$E(X^2)=6$，$D(X)=6-49/9=5/9$。
4.  **题 $4$ **：某投资项目收益 $X$（万元）分布列 $P(X=-1)=0.4, P(X=2)=0.6$，求 $\sigma(X)$。
    *   **详细解析**：$E(X)=0.8$，$E(X^2)=2.8$，$D(X)=2.16$，$\sigma(X)\approx1.47$。

##### 梯度三：能力拔高
5.  **题 $5$ **：$P(X=k) = C_3^k p^k (1-p)^{3-k} (k=0,1,2,3)$。若 $E(X)=1.2$，求 $D(X)$。
    *   **思维破局**：识别为二项分布 $B(3, p)$ 骨架。
    *   **解析**：$E(X)=np=3p=1.2 \implies p=0.4$。$D(X)=np(1-p)=3 \times 0.4 \times 0.6 = 0.72$。
