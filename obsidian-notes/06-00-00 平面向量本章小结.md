# 第六章 平面向量及其应用 本章小结
**教材**: 人教版必修第二册第六章

## 知识深度笔记

### 现象

*   **【情境锚定：从"点位固定"到"自由平移"的代数升维】**：
    *   **起因（背景与任务）**：自然界中存在大量既有大小又有方向的量，如小船的位移、力的合成与分解、风速的修正等。
    *   **冲突（瓶颈与矛盾）**：初中几何主要研究图形的静态位置，实数运算仅能处理标量。面对如"向东走 $3km$ 再向北走 $4km$"这种非线性累加任务，传统的代数加法（$3+4=7$）与位移效果（$5km$）产生逻辑断层。
    *   **指向（概念诞生）**：通过建立**平面向量协议（Planar Vector Protocol）**，引入有向线段作为载体，将几何关系转化为可运算的代数对象，实现了从"静态图形描述"向"动态矢量合成"的质变。

### 原因

*   **形成机制**：基于**线性空间分解与内积度量逻辑**。
    1.  **自由平移契约**：向量定义不依赖于起点，允许在空间中自由平移。
    2.  **基底投影逻辑**：利用平面向量基本定理，通过选定两个不共线向量作为坐标框架，将任意位移分解为数值对 $(x, y)$。
    3.  **度量化转换**：通过数量积将几何上的角度与长度通过代数乘法进行耦合。
*   **条件剖析**：向量相等必须满足"模等"且"向同"双重安检。
    *   *反例*：在正方形 $ABCD$ 中，$\vec{AB}$ 与 $\vec{CD}$ 虽模相等且平行，但因方向相反而不能判定为相等向量。

### 结果

*   **【核心公式提取（Formulas）】**：
    *   **线性运算算子**：$\vec{a} \pm \vec{b} = (x_1 \pm x_2, y_1 \pm y_2)$；$\lambda \vec{a} = (\lambda x, \lambda y)$。
    *   **数量积算子**：$\vec{a} \cdot \vec{b} = |\vec{a}| |\vec{b}| \cos \theta = x_1x_2 + y_1y_2$。
    *   **解三角形协议**：正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$；余弦定理 $a^2 = b^2 + c^2 - 2bc \cos A$。
*   **【重要性质归纳（Properties）】**：
    1.  **共线判定**：$\vec{a} \parallel \vec{b} \iff x_1y_2 - x_2y_1 = 0$。
    2.  **垂直判定**：$\vec{a} \perp \vec{b} \iff x_1x_2 + y_1y_2 = 0$。
    3.  **模长与夹角**：$|\vec{a}| = \sqrt{x^2+y^2}$；$\cos \theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}| |\vec{b}|}$。
*   **【核心特点剖析（Characteristics）】**：
    *   **代数结构特征**：建立了向量与有序实数对的同构映射，使几何问题可程序化解算。
    *   **几何图像特征**：通过平行四边形与三角形法则，实现了图形叠加的直观化。
*   **【要素拆解】**：
    *   【适用前提】：共面向量系统。
    *   【核心结论】：向量加法是平移合成，数量积是投影度量。

### 应用

*   **学科内应用**：作为解析几何、立体向量以及复数运算的底层支撑协议。
*   **跨学科/实际应用**：**物理力学与航海**。利用正交分解计算斜面受力平衡，或通过速度合成修正船只航线偏角。

### 本质

*   **数学思想方法**：**化归转化**（几何 ↔ 向量 ↔ 坐标）、**数形结合**。
*   **高观点视域**：本章是线性代数的二维特例。向量加法体现了线性空间的叠加性，数量积赋予了空间度量结构。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

*   **解题策略**：执行"一建（选基或建系）、二转（几何关系向量化）、三算（线性运算或数量积）、四译（结果回归几何）"的向量三步曲 SOP。
*   **标准操作步骤（SOP）**：
    *   **步骤 $1$：[骨架搭建]** 选取正交单位向量为基底建立直角坐标系。
    *   **步骤 $2$：[元素映射]** 将几何点坐标化，并表示目标向量。
    *   **步骤 $3$：[算子求值]** 调用数量积或共线公式执行数值结算。

---

### 典型例题

#### 例题1（综合性质判定）：
**题目**：已知向量 $\vec{a} = (1, 2), \vec{b} = (k, 1)$。若 $(\vec{a} + 2\vec{b}) \perp (\vec{a} - \vec{b})$，求实数 $k$。

1.  **【结构与特征分析】**：形视识别入口为"向量组合垂直"。核心逻辑开关是"数量积等于 $0$"。
2.  **【解题决策逻辑流（思维推演）】**：
    *   $\vec{a} + 2\vec{b} = (1+2k, 4)$；$\vec{a} - \vec{b} = (1-k, 1)$ ➔
    *   $(1+2k)(1-k) + 4 = 0 \implies 2k^2 - k - 5 = 0 \implies k = (1 \pm \sqrt{41})/4$。
3.  **【解析（对照 SOP 步骤）】**：$k = (1 \pm \sqrt{41})/4$。
4.  **【避坑提示】**：数量积结果是实数，不是向量。
**结论**：$k = (1 \pm \sqrt{41})/4$。

#### 例题2（解三角形综合）：
**题目**：在 $\triangle ABC$ 中，$a=2, b=\sqrt{2}, A=45^\circ$，解该三角形。

1.  **【结构与特征分析】**：形视识别入口为"$SSA$ 模型"。
2.  **【解题决策逻辑流（思维推演）】**：
    *   $\sin B = b\sin A/a = 0.5 \implies B = 30^\circ$ 或 $150^\circ$ ➔
    *   $a > b \implies A > B$，故 $B = 30^\circ$（$150^\circ$ 舍去）➔
    *   $C = 105^\circ, c = \sqrt{3}+1$。
3.  **【解析（对照 SOP 步骤）】**：$B=30^\circ, C=105^\circ, c=\sqrt{3}+1$。
4.  **【避坑提示】**：$SSA$ 型必须依据边的大小关系过滤。
**结论**：$B=30^\circ, C=105^\circ, c=\sqrt{3}+1$。

1.  **题 $1$**：$\vec{a}=(3,4), \vec{b}=(x,-2)$，$\vec{a}\parallel\vec{b} \implies 3\times(-2)-4x=0 \implies x=-1.5$。
