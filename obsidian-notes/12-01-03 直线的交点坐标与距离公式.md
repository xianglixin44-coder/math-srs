# 直线的交点坐标与距离公式
**教材**: 人教版选择性必修第一册第二章 2.3 节

## 知识深度笔记

### 现象

* **【情境锚定：从"位置关系"到"精密测距"的逻辑量化】**：
  1. **起因（背景与任务）**：在平面几何中，我们通过观察判定两条直线是否相交或平行。但在建筑设计或航迹追踪中，仅知道"相交"是不够的，必须精确锁定交点的"坐标"。
  2. **冲突（瓶颈与矛盾）**：定性的描述无法计算两点间的航程，也无法确定一个基站到航线的最小防御半径，传统的尺规作图法精度极低且无法参与代数运算。
  3. **指向（概念诞生）**：通过建立**交点与距离协议**（两点距离、点线距离、线线距离），将几何图形的拓扑关系彻底转化为实数运算，标志着平面研究由"定性观察"跨入"精密数值控制"时代。

### 原因

* **形成机制**：基于**方程解的唯一性**。由于直线是方程的解集，两条直线的公共点（交点）必须同时满足两个方程，因此求交点等价于求二元一次方程组的解。距离公式则基于**勾股定理的坐标化**与**向量投影算子**的简化。
* **条件剖析**：点到直线距离公式的前提是直线方程必须化为**一般式** $Ax + By + C = 0$。
    * *反例*：若直线方程为 $y = kx + b$ 形式直接代入距离公式，极易混淆系数 $A, B$，导致计算结果逻辑崩溃。

### 结果

* **【核心公式提取（Formulas）】**：
  * **交点定位算子**：解方程组 $\begin{cases} A_1x + B_1y + C_1 = 0 \\ A_2x + B_2y + C_2 = 0 \end{cases}$。
  * **两点距离算子**：$|P_1P_2| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$。
  * **点线距离算子**：$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$。
  * **平行线距离算子**：$d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$。
* **【重要性质归纳（Properties）】**：
  1. **解数对应性**：方程组有唯一解 $\iff$ 相交；无解 $\iff$ 平行；无数解 $\iff$ 重合。
  2. **距离标量性**：距离 $d$ 永远是非负实数，公式分子带有绝对值符号以确保测度的正定性。
* **【核心特点剖析（Characteristics）】**：
  * *代数结构特征*：分母为法向量的模 $\sqrt{A^2 + B^2}$，分子为点代入后的偏差值。
  * *几何图像特征*：点线距离对应垂线段长度，平行线距离对应公垂线段长度。
  * *符号特征*：注意平行线距离公式中，两条直线的 $A, B$ 系数必须预先化为一致。
* **【要素拆解】**：
  * 【适用前提】：涉及直线位置判定及长度度量。
  * 【核心结论】：距离是坐标偏差在算子映射下的标量化产物。
  * 【适用范围/边界】：当 $B = 0$ 时，点线距离退化为横坐标之差的绝对值。

### 应用

* **学科内应用**：求解三角形的面积（底乘高）、判定直线与圆的位置关系（比较 $d$ 与 $r$）。
* **跨学科/实际应用**：**雷达盲区监测**。通过计算监测站坐标到航线（直线方程）的距离，判定飞机是否进入雷达覆盖的有效半径。

### 本质

* **数学思想方法**：**方程思想**（交点即解）与**化归转化**（形数互换）。
* **高观点视域**：本节是欧几里得测度论（Euclidean Metric）在解析几何中的具象。它证明了在内积空间中，流形的距离可以通过其对偶向量（法向量）的线性泛函完全刻画。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

* **解题策略**：执行"化一般式 $\rightarrow$ 套用算子 $\rightarrow$ 几何翻译"的 SOP。涉及面积问题时，优先利用距离公式求高。
* **标准操作步骤（SOP）**：
  * **步骤 $1$ [算子环境构建]**：将直线方程全部转化为 $Ax + By + C = 0$ 形式。
  * **步骤 $2$ [目标锚定]**：识别是求"点线距"、"点点距"还是"线线距"。
  * **步骤 $3$ [代数执行]**：代入对应公式，通过分母有理化得出最终标量。

---

### 典型例题

#### 例题1（基础示范题）：
1. **题目**：求两条直线 $l_1: 3x + 4y - 2 = 0$ 与 $l_2: 2x + y + 2 = 0$ 的交点 $M$ 的坐标，并计算原点 $O$ 到直线 $l_1$ 的距离。
2. **【结构与特征分析】**：形视识别入口为"二元一次方程组"与"点到直线距离标准算子"。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：联立两条直线的代数约束。
   * *分支*：执行消元法求得解组 $(x, y)$ ➔ 锁定交点。
   * *决策*：针对直线 $l_1$ 套用 $d = \frac{|C|}{\sqrt{A^2+B^2}}$ 公式（因原点横纵坐标为 $0$）。
   * *终点*：输出坐标与标量距离。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [联立求解]]：解方程组 $\begin{cases} 3x + 4y - 2 = 0 \\ 2x + y + 2 = 0 \end{cases}$，消去 $y$ 得 $x = -2$，代入得 $y = 2$。
   * [步骤 $2$ [距离套用]]：锁定 $A=3, B=4, C=-2$，原点为 $(0, 0)$。
   * [步骤 $3$ [代数运算]]：$d = \frac{|3\times0 + 4\times0 - 2|}{\sqrt{3^2 + 4^2}} = \frac{2}{5} = 0.4$。
5. **【避坑提示】**：求距离时，分子一定要加绝对值符号。
6. **结论**：交点为 $M(-2, 2)$，距离为 $0.4$。

#### 例题2（综合变式题）：
1. **题目**：已知两条平行直线 $l_1: 3x - 4y + 6 = 0$ 与 $l_2: 6x - 8y + C = 0$ 之间的距离为 $3$，求实数 $C$ 的取值。
2. **【结构与特征分析】**：形视识别入口为"平行线距离逆向求解"。特征点在于两直线系数不成 1:1，需先进行"齐次化"处理。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：观察 $l_1$ 与 $l_2$ 的 $A, B$ 系数倍数关系。
   * *决策*：将 $l_1$ 扩倍或将 $l_2$ 缩倍，使 $x, y$ 前的系数完全对等。
   * *分支*：建立方程 $\frac{|C_1 - C_2|}{\sqrt{A^2+B^2}} = 3$ ➔ 解绝对值方程。
   * *收敛*：得出 $C$ 的两个可能值。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [齐次化]]：将 $l_1$ 方程乘以 $2$，得 $6x - 8y + 12 = 0$。
   * [步骤 $2$ [公式套用]]：$A=6, B=-8, C_1=12, C_2=C$。距离 $d = \frac{|12 - C|}{\sqrt{6^2 + (-8)^2}} = \frac{|12 - C|}{10}$。
   * [步骤 $3$ [代数运算]]：令 $\frac{|12 - C|}{10} = 3 \implies |12 - C| = 30 \implies 12 - C = 30$ 或 $12 - C = -30$。
   * [步骤 $4$ [解得]]：$C = -18$ 或 $C = 42$。
5. **【避坑提示】**：绝对不能直接用 $l_1$ 中的 $C=6$ 与 $l_2$ 中的 $C$ 进行作差，必须先统一 $A, B$ 系数。
6. **结论**：$C = -18$ 或 $C = 42$。

### 巩固习题

##### 梯度一：基础达标
1. **题 $1$ **：求直线 $x + y - 1 = 0$ 与 $x - y + 3 = 0$ 的交点坐标。
   *   **答案**：$(-1, 2)$。步骤：两式相加得 $2x + 2 = 0 \implies x = -1$，代入得 $y = 2$。
2. **题 $2$ **：求点 $P(1, 2)$ 到直线 $3x + 4y - 10 = 0$ 的距离。
   *   **答案**：$0.2$。步骤：$d = \frac{|3\times1 + 4\times2 - 10|}{\sqrt{3^2 + 4^2}} = \frac{1}{5}$。

##### 梯度二：高考中档
3. **题 $3$ **：已知三角形三个顶点 $A(1, 3), B(3, 1), C(-1, 0)$，求三角形 $ABC$ 的面积。
   *   **详细解析**：$|AB| = \sqrt{(3-1)^2 + (1-3)^2} = 2\sqrt{2}$。直线 $AB$ 方程为 $x + y - 4 = 0$。点 $C$ 到 $AB$ 的距离 $h = \frac{|-1 + 0 - 4|}{\sqrt{1^2 + 1^2}} = \frac{5}{\sqrt{2}}$。面积 $S = \frac{1}{2} \times 2\sqrt{2} \times \frac{5}{\sqrt{2}} = 5$。
4. **题 $4$ **：求经过两条直线 $2x - 3y + 10 = 0$ 和 $3x + 4y - 2 = 0$ 的交点，且垂直于直线 $3x - 2y + 4 = 0$ 的直线方程。
   *   **详细解析**：交点为 $(-2, 2)$；目标直线斜率为 $-\frac{2}{3}$。方程为 $y - 2 = -\frac{2}{3}(x + 2) \implies 2x + 3y - 2 = 0$。

##### 梯度三：能力拔高
5. **题 $5$ **：已知实数 $x, y$ 满足 $x^2 + y^2 = 1$，求 $x + y + 3$ 的取值范围。
   *   **思维破局**：将问题转化为单位圆上的点到直线 $x + y + 3 = 0$ 的距离关系。
   *   **解析**：设 $x + y + 3 = k$，则直线 $l: x + y + (3 - k) = 0$ 与圆 $x^2 + y^2 = 1$ 有公共点。原点到直线 $l$ 的距离 $d = \frac{|3-k|}{\sqrt{2}} \le 1$。解得 $3-\sqrt{2} \le k \le 3+\sqrt{2}$。
