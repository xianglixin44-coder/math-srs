# 空间向量基本定理
**教材**: 人教版选择性必修第一册第一章 1.2 节

## 知识深度笔记

### 现象

* **【情境锚定：从"平面坐标"到"空间导航"的逻辑升维】**：
  1. **起因（背景与任务）**：在平面内，我们只需两个不共线的基向量即可定位任何位置。但当面对三维空间（如无人机在空中的坐标锁定或晶体结构分析）时，二维基底显得捉襟见肘。
  2. **冲突（瓶颈与矛盾）**：两个非零向量只能张成一个平面，无法表达平面外的"纵深"维度，导致空间中任意方向的位移无法被唯一分解。
  3. **指向（概念诞生）**：通过将基准向量增加到三个（不共面），数学家建立了**空间基底协议**，标志着空间中任意向量都可以被"标准化、唯一化"地拆解为三个分量。

### 原因

* **形成机制**：基于**空间分解逻辑**。任意空间向量 $\vec{p}$，通过平移与基点 $O$ 重合，先在由 $\vec{a}, \vec{b}$ 确定的平面上寻找投影向量 $\vec{OQ} = x\vec{a} + y\vec{b}$，再利用剩余的纵向分量 $z\vec{c}$ 完成闭环：$\vec{p} = x\vec{a} + y\vec{b} + z\vec{c}$。
* **条件剖析**：基底成立的钢铁前提是**"不共面"**。
    * *反例*：若三个基向量 $\vec{a}, \vec{b}, \vec{c}$ 共面，则它们生成的线性组合永远无法表达该平面之外的向量，逻辑坍塌为二维。

### 结果

* **【核心公式提取（Formulas）】**：
  * **基本定理算子**：若 $\vec{a}, \vec{b}, \vec{c}$ 不共面，则 $\forall \vec{p} \in V^3, \exists! (x, y, z) \in \mathbb{R}^3$，使得：
  $$\vec{p} = x\vec{a} + y\vec{b} + z\vec{c}$$
* **【重要性质归纳（Properties）】**：
  1. **唯一性**：对应系数 $x, y, z$ 是唯一的，这为"向量相等 $\rightarrow$ 系数相等"的代数转化提供了理论基础。
  2. **正交化特例**：当基向量两两垂直且长度为 $1$ 时，称为**单位正交基底** $\{\vec{i}, \vec{j}, \vec{k}\}$，这是空间坐标系的逻辑原型。
* **【核心特点剖析（Characteristics）】**：
  * *代数结构特征*：线性组合结构。它是将几何位置转化为代数标量的"万能翻译机"。
  * *几何图像特征*：以 $\vec{a}, \vec{b}, \vec{c}$ 为邻边构成的平行六面体的对角线即为合成向量。
  * *符号特征*：$\{\vec{a}, \vec{b}, \vec{c}\}$ 表示集合形式的基底。
* **【要素拆解】**：
  * 【适用前提】：基底向量组必须不共面。
  * 【核心结论】：空间任意向量可由基底唯一线性表示。
  * 【适用范围/边界】：基底中的分量可以为 $0$（此时向量落在某些基向量确定的平面或轴上）。

### 应用

* **学科内应用**：将复杂的立体几何位置关系证明（平行、垂直）转化为纯代数系数运算。
* **跨学科/实际应用**：**量子力学中的态矢量分解**。任何复杂的量子态都可以看作是希尔伯特空间中一组正交基底的叠加。

### 本质

* **数学思想方法**：**基底思想**（化整为零）与**维度扩张**。
* **高观点视域**：本定理定义了三维线性空间的维数（Dimension）。它揭示了三维欧几里得空间的"秩"为 $3$，是线性代数在物理空间的直观映射。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

* **解题策略**：执行"定基底、表目标、解系数"的标准化流程。优先选择图形中交于同一点的三条棱或互相垂直的向量作为基底。
* **标准操作步骤（SOP）**：
  * **步骤 $1$ [基底确立]**：在图形中寻找三个已知长度或夹角的不共面向量作为 $\{\vec{a}, \vec{b}, \vec{c}\}$。
  * **步骤 $2$ [路径拆解]**：利用三角形法则或平行四边形法则，将待求向量沿基底方向进行位移分解。
  * **步骤 $3$ [系数锁定]**：通过比例关系（如中点或定比分点）合并同类项，得出唯一的 $(x, y, z)$。

### 典型例题

#### 例题1（基础示范题）：
1. **题目**：已知 $M$ 是四面体 $O-ABC$ 棱 $BC$ 的中点，点 $P$ 在线段 $AM$ 上，且 $AP = 3PM$。用基底 $\{\overrightarrow{OA}, \overrightarrow{OB}, \overrightarrow{OC}\}$ 表示 $\overrightarrow{OP}$。
2. **【结构与特征分析】**：形视识别入口为"四面体的顶点放射结构"。目标向量起点为空间基点 $O$，涉及中点和定比分点的复合表示。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：将 $\overrightarrow{OP}$ 拆解为过基点 $O$ 的路径 ➔ $\overrightarrow{OA} + \overrightarrow{AP}$。
   * *分支*：处理 $\overrightarrow{AP}$ ➔ 利用比例 $3/4 \overrightarrow{AM}$ ➔ 将 $\overrightarrow{AM}$ 转化为终点减起点 $\overrightarrow{OM} - \overrightarrow{OA}$。
   * *收敛*：处理中点向量 $\overrightarrow{OM}$ ➔ 代入 $1/2(\overrightarrow{OB} + \overrightarrow{OC})$ ➔ 合并基底项得出最终系数。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [路径表示]]：$\overrightarrow{OP} = \overrightarrow{OA} + \frac{3}{4}\overrightarrow{AM}$。
   * [步骤 $2$ [分解计算]]：$\overrightarrow{OP} = \overrightarrow{OA} + \frac{3}{4}(\overrightarrow{OM} - \overrightarrow{OA}) = \frac{1}{4}\overrightarrow{OA} + \frac{3}{4}\overrightarrow{OM}$。
   * [步骤 $3$ [中点代换]]：$\overrightarrow{OP} = \frac{1}{4}\overrightarrow{OA} + \frac{3}{4} \cdot \frac{1}{2}(\overrightarrow{OB} + \overrightarrow{OC}) = \frac{1}{4}\overrightarrow{OA} + \frac{3}{8}\overrightarrow{OB} + \frac{3}{8}\overrightarrow{OC}$。
5. **【避坑提示】**：注意比例 $AP = 3PM$ 意味着 $AP$ 占全长 $AM$ 的 $3/4$，而非 $1/3$。
6. **结论**：$\overrightarrow{OP} = \frac{1}{4}\overrightarrow{OA} + \frac{3}{8}\overrightarrow{OB} + \frac{3}{8}\overrightarrow{OC}$。

#### 例题2（综合变式题）：
1. **题目**：在平行六面体 $ABCD-A_1B_1C_1D_1$ 中，设 $\overrightarrow{AB}=\vec{a}, \overrightarrow{AD}=\vec{b}, \overrightarrow{AA_1}=\vec{c}$。若 $M, N$ 分别为 $D_1C_1, C_1B_1$ 的中点。求证：$MN \perp AC_1$ 的向量表达条件。
2. **【结构与特征分析】**：形视识别入口为"空间垂直关系的基底化"。核心在于证明两个线性组合的数量积为 $0$。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：用基底表示 $\overrightarrow{MN}$ ➔ $D_1C_1$ 与 $C_1B_1$ 中点位移的差。
   * *决策*：用基底表示 $\overrightarrow{AC_1}$ ➔ 体对角线 $\vec{a} + \vec{b} + \vec{c}$。
   * *分支*：执行数量积运算 $(\frac{1}{2}\vec{a} - \frac{1}{2}\vec{b}) \cdot (\vec{a} + \vec{b} + \vec{c})$ ➔ 分配律展开。
   * *收敛*：代入各棱长及夹角（若为正方体则分量抵消）证明结果为 $0$。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [基底表示]]：$\overrightarrow{MN} = \overrightarrow{MC_1} + \overrightarrow{C_1N} = \frac{1}{2}\vec{a} - \frac{1}{2}\vec{b}$；$\overrightarrow{AC_1} = \vec{a} + \vec{b} + \vec{c}$。
   * [步骤 $2$ [运算证明]]：$\overrightarrow{MN} \cdot \overrightarrow{AC_1} = \frac{1}{2}(\vec{a} - \vec{b}) \cdot (\vec{a} + \vec{b} + \vec{c}) = \frac{1}{2}(\vec{a}^2 - \vec{b}^2 + \vec{a}\cdot\vec{c} - \vec{b}\cdot\vec{c})$。
   * [步骤 $3$ [条件匹配]]：若棱长相等且夹角一致（如正方体），则项抵消为 $0$。
5. **【避坑提示】**：求 $\overrightarrow{MN}$ 时注意方向，$\overrightarrow{C_1N}$ 是 $\overrightarrow{C_1B_1}$ 的一半，即 $-\frac{1}{2}\vec{b}$。
6. **结论**：若满足模长与夹角特定约束，则 $MN \perp AC_1$。

### 巩固习题

##### 梯度一：基础达标
1. **题 $1$ **：若 $\{\vec{a}, \vec{b}, \vec{c}\}$ 是空间的一个基底，则对于向量 $\vec{p} = \vec{a} + \vec{b}$，$\vec{q} = \vec{a} - \vec{b}$，下列哪一个向量能与 $\vec{p}, \vec{q}$ 构成新基底？
   *   **答案**：$\vec{c}$。解析：$\vec{p}, \vec{q}$ 均在 $\vec{a}, \vec{b}$ 确定的平面内，必须选平面外的 $\vec{c}$。
2. **题 $2$ **：在平行六面体中，$\overrightarrow{AC_1}$ 可表示为 $\overrightarrow{AB}, \overrightarrow{AD}, \overrightarrow{AA_1}$ 的系数和，其系数分别为？
   *   **答案**：$(1, 1, 1)$。解析：遵循平行六面体法则的对角线合成。

##### 梯度二：高考中档
3. **题 $3$ **：已知四面体 $O-ABC$，$G$ 为底面 $\triangle ABC$ 的重心，用 $\overrightarrow{OA}, \overrightarrow{OB}, \overrightarrow{OC}$ 表示 $\overrightarrow{OG}$。
   *   **详细解析**：$\overrightarrow{OG} = \overrightarrow{OA} + \overrightarrow{AG} = \overrightarrow{OA} + \frac{2}{3}(\frac{\overrightarrow{AB} + \overrightarrow{AC}}{2})$。最终结论为 $\overrightarrow{OG} = \frac{1}{3}(\overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC})$。
4. **题 $4$ **：判断：若 $\vec{a}, \vec{b}$ 共线，则 $\{\vec{a}, \vec{b}, \vec{c}\}$ 能否构成空间基底？
   *   **详细解析**：不能。若 $\vec{a}, \vec{b}$ 共线，则三个向量必然共面，不满足基底定义的"不共面"条件。

##### 梯度三：能力拔高
5. **题 $5$ **：在正方体 $ABCD-A_1B_1C_1D_1$ 中，$E, F, G$ 分别为 $C_1D_1, A_1D_1, D_1D$ 的中点，求证 $EF \parallel AC$。
   *   **思维破局**：建立以 $D$ 为起点的正交基底 $\{\vec{i}, \vec{j}, \vec{k}\}$，分别表示出两个向量，观察其系数是否成比例。
   *   **解析**：$\overrightarrow{EF} = \frac{1}{2}\vec{i} - \frac{1}{2}\vec{j}$，$\overrightarrow{AC} = \overrightarrow{AD} - \overrightarrow{AB} = \vec{j} - \vec{i}$。显见 $\overrightarrow{EF} = -\frac{1}{2}\overrightarrow{AC}$，满足共线条件，故平行。
