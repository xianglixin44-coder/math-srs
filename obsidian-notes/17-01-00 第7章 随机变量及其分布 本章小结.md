# 第7章 随机变量及其分布 本章小结
**教材**: 人教版选择性必修第三册第七章小结

## 知识深度笔记

### 现象

* **【情境锚定：从"点对点"概率到"全景分布"的数学跨越】**：
    * **起因（背景与任务）**：在处理如"抽样检测"、"射击精度分析"或"身高的工业测度"时，单一的古典概型公式已无法描述变量在整个取值空间内的演化规律。
    * **冲突（瓶颈与矛盾）**：虽然已知单个事件的概率，但面对"成功次数"这种受多个因素影响且具有随机波动的量，缺乏一种能同时刻画"集中趋势"与"波动强度"的综合算子。
    * **指向（概念诞生）**：通过建立**随机变量及其分布协议**，将物理样本空间映射为实数集，并引入"期望"与"方差"作为系统状态的特征指标，标志着概率研究由"静态算术"进入了"函数动力学"时代。

### 原因

* **形成机制**：基于**测度映射与极限收敛逻辑**。
    * **结构化**：利用分布列（离散）或密度函数（连续）建立变量与概率的函数关系。
    * **模型化**：将复杂的试验背景抽象为伯努利试验（二项分布）或有限总体抽样（超几何分布）。
    * **极限化**：当离散因素趋于无穷微小且独立叠加时，系统分布自动坍缩为正态分布（钟形曲线）。
* **条件剖析**：模型有效的前提是严格遵循抽样独立性（二项）或有限总体不放回性（超几何）。

### 结果

* **【核心公式提取（Formulas）】**：
    * **分布协议集**：
        * 二项分布：$X \sim B(n, p)$，$$P(X=k) = C_n^k p^k (1-p)^{n-k}$$。
        * 超几何分布：$X \sim H(n, N, M)$，$$P(X=k) = \frac{C_M^k C_{N-M}^{n-k}}{C_N^n}$$。
        * 正态密度：$$f(x) = \frac{1}{\sigma \sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$。
    * **特征算子**：$E(X)$（重心/平均水平）、$D(X)$（波动/离散程度）。
* **【重要性质归纳（Properties）】**：
    1. **规范性协议**：离散型 $\sum p_i = 1$，连续型曲线下总面积为 $1$。
    2. **线性性质**：$E(aX+b) = aE(X)+b$；$D(aX+b) = a^2D(X)$。
    3. **正态 $3\sigma$ 准则**：$P(\mu-3\sigma < X \le \mu+3\sigma) \approx 0.9973$。
* **【要素拆解】**：
    * 【适用前提】：变量具有明确的概率生成机制。
    * 【核心结论】：分布列决定全域规律，期望定高下，方差定稳健。
    * 【适用范围】：正态分布适用于大量微小随机因素叠加的场景。

### 应用

* **学科内应用**：作为假设检验、回归分析及后续数理统计的基础模型。
* **跨学科/实际应用**：**生物进化博弈分析**。利用期望与方差评估特定性状在种群中的适应度，若期望收益高且方差（风险）低，则该性状具有进化优势。

### 本质

* **数学思想方法**：**化归思想**（复杂分布归结为数字特征）、**极限思想**（二项分布向正态分布的演化）。
* **高观点视域**：本章是概率论向统计学过渡的桥梁。期望是一阶原点矩，方差是二阶中心矩，它们通过对随机信息的"降维"，提取了系统演化的核心稳定性规律。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

* **解题策略**：执行"一判（分布模型）、二定（核心参数）、三算（数字特征）、四推（决策结论）"的 SOP。涉及决策优选时，优先计算 $E(X)$ 进行横向比对。
* **标准操作步骤（SOP）**：
    * **步骤 $1$：[模型映射]** 根据背景识别是 $B(n, p)$、$H(n, N, M)$ 还是 $N(\mu, \sigma^2)$。
    * **步骤 $2$：[参数锁定]** 提取样本量、单次概率或均值/方差。
    * **步骤 $3$：[算子执行]** 代入相应公式计算 $P(X=k)$ 或利用线性性质转换数字特征。
    * **步骤 $4$：[逻辑校验]** 利用规范性（和为 $1$）或对称性对结果进行闭环核验。

### 典型例题

#### 例题1（综合分布与期望决策）：
**题目**：某商场开展促销，顾客可选择两种方案：方案一：直接获得 $20$ 元现金；方案二：摸奖，袋中 $10$ 个球，其中红球 $2$ 个，白球 $8$ 个，不放回摸 $2$ 个。每摸到红球奖 $60$ 元，白球无奖。你建议顾客选哪种方案？

1. **【结构与特征分析】**：形视识别入口为"常量收益与超几何分布收益的比对"。方案二的变量 $X$ 符合超几何分布模型。
2. **【解题决策逻辑流（思维推演）】**：
    * 起点（源头）：理性决策以"数学期望"最大化为准则 ➔
    * 分支（决策）：方案一收益为常数 $20$ ➔ 方案二需计算奖金变量 $Y$ 的分布列 ➔
    * 决策（模型）：$X$（红球数）为超几何分布 ➔ 利用 $Y = 60X$ 的线性映射关系 ➔
    * 终点（收敛）：比对期望大小完成决策。
3. **【解析（对照 SOP 步骤）】**：
    * [步骤 $1$ [模型]]：$X \in \{0, 1, 2\}$，$X \sim H(2, 10, 2)$。
    * [步骤 $2$ [期望]]：$E(X) = 2 \times \frac{2}{10} = 0.4$。
    * [步骤 $3$ [映射]]：$Y = 60X \implies E(Y) = 60 \times 0.4 = 24$ 元。
    * [步骤 $4$ [比对]]：$24 > 20$，方案二期望收益更高。
4. **【避坑提示】**：不要因为方案二有概率得 $0$ 元就直观放弃，统计决策必须基于期望值。
**结论**：建议选方案二。

#### 例题2（正态分布与质量控制）：
**题目**：某工厂生产的零件直径 $X \sim N(10, 0.01^2)$（单位：$\text{cm}$）。若直径在 $(9.98, 10.02]$ 视为合格，求合格率；若抽检 $1000$ 个零件，不合格品数的期望是多少？

1. **【结构与特征分析】**：形视识别入口为"正态分布区间概率与二项分布期望的复合"。
2. **【解题决策逻辑流（思维推演）】**：
    * 起点（源头）：识别正态参数 $\mu=10, \sigma=0.01$ ➔
    * 分支（区间）：$(9.98, 10.02]$ 对应 $[\mu-2\sigma, \mu+2\sigma]$ ➔ 调用 $2\sigma$ 区间概率 $0.9545$ ➔
    * 分支（复合）：$1000$ 件抽检看作二项分布 ➔ 期望 $n(1-p)$ ➔
    * 终点（收敛）：输出合格率与不合格期望。
3. **【解析（对照 SOP 步骤）】**：
    * [步骤 $1$ [合格率]]：$P(9.98 < X \le 10.02) \approx 0.9545$。
    * [步骤 $2$ [不合格期望]]：$E(Y) = 1000 \times (1 - 0.9545) = 45.5$。
4. **【避坑提示】**：注意 $\sigma^2$ 与 $\sigma$ 的转换。
**结论**：合格率约 $95.45\%$，不合格品数期望 $45.5$ 个。

### 巩固习题

##### 梯度一：基础达标
1. **题 $1$ **：已知 $X \sim B(n, 0.3), E(X)=3$，则 $n=$ ____，$D(X)=$ ____。
    * **答案**：$10$；$2.1$。步骤：$n \times 0.3 = 3 \implies n=10$；$D(X)=10 \times 0.3 \times 0.7 = 2.1$。
2. **题 $2$ **：若 $X \sim N(3, 1)$，则 $P(X \le 3) = $ ____。
    * **答案**：$0.5$。正态曲线关于 $\mu=3$ 对称。

##### 梯度二：高考中档
3. **题 $3$ **：袋中有 $5$ 个球，$3$ 红 $2$ 白。不放回摸 $2$ 个，记红球数为 $X$。求分布列及 $E(X)$。
    * **详细解析**：$P(X=0)=0.1, P(X=1)=0.6, P(X=2)=0.3$。$E(X)=1.2$。
4. **题 $4$ **：某气象台预报明天降水概率为 $40\%$。不降水获利 $8$ 万，降水损失 $3$ 万。求获利期望。
    * **详细解析**：$E(X)=8 \times 0.6 + (-3) \times 0.4 = 3.6$ 万元。

##### 梯度三：能力拔高
5. **题 $5$ **：已知 $X \sim B(n, p)$，且 $E(X)=12, D(X)=4$。求 $n$ 和 $p$。
    * **思维破局**：方程组。$np=12$ 和 $np(1-p)=4$。
    * **解析**：$1-p = 4/12 = 1/3 \implies p = 2/3$。则 $n = 12/(2/3) = 18$。
