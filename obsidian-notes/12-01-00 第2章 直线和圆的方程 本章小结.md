# 第2章 直线和圆的方程 本章小结
**教材**: 人教版选择性必修第一册第二章小结

## 知识深度笔记

### 现象
* **【情境锚定：从"形"的定性到"数"的精密解析】**：
  1. **起因（背景与任务）**：在研究多边形（直线形）和圆这两类基本图形时，初中几何通过观察和操作判定位置关系。
  2. **冲突（瓶颈与矛盾）**：定性的几何推导（如"看起来相切"）在处理含参动态问题或高精度度量（如具体交点坐标、弦长、最短距离）时，逻辑链条过于抽象，难以实现程序化求解。
  3. **指向（概念诞生）**：通过在平面建立坐标系，数学家建立了**解析几何协议**。将"点"映射为"实数对"，将"曲线"映射为"方程"，标志着几何研究由"视觉感知"进入"数学机械化"时代。

### 原因
* **形成机制**：基于**坐标法（Coordinate Method）**。通过直线和圆的几何要素（点、斜率、圆心、半径）建立变量 $x, y$ 满足的代数等式，从而将图形的拓扑属性转化为代数方程的根。
* **条件剖析**：方程与曲线的互证性是解析几何的基石：
    * 曲线 $C$ 上任意一点的坐标都满足方程 $f(x, y)=0$。
    * 方程 $f(x, y)=0$ 的每一组解对应点都在曲线 $C$ 上。

### 结果
* **【核心公式提取（Formulas）】**：
  * **直线全协议**：点斜式 $y - y_0 = k(x - x_0)$、两点式、一般式 $Ax + By + C = 0$。
  * **圆全协议**：标准式 $(x-a)^2 + (y-b)^2 = r^2$、一般式 $x^2 + y^2 + Dx + Ey + F = 0$。
  * **距离算子**：点线距 $d = \frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}$；心距 $d = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}$。
* **【重要性质归纳（Properties）】**：
  1. **位置关系判定**：直线与圆：通过比较心距 $d$ 与半径 $r$（几何法）或判别式 $\Delta$（代数法）。
  2. **唯一性映射**：任意二元一次方程均对应一条直线；满足特定判别式的二元二次方程对应一个圆。
* **【核心特点剖析（Characteristics）】**：
  * *代数结构特征*：利用方程组解的个数（$0, 1, 2$）锁定相离、相切、相交状态。
  * *几何图像特征*：直线体现线性增长，圆体现二阶测度对称。
* **【要素拆解】**：
  * 【适用前提】：建立适当的直角坐标系。
  * 【核心结论】：几何问题可转化为代数方程求解。

### 应用
* **学科内应用**：求解三角形面积、圆的切线方程、公共弦方程及后续圆锥曲线的交切问题。
* **跨学科/实际应用**：**赵州桥拱设计**。利用跨度与拱高建立圆方程，精确计算每间隔 $4\text{m}$ 的支柱高度。

### 本质
* **数学思想方法**：**数形结合**（形数互换）、**化归思想**、**待定系数法**。
* **高观点视域**：本章是"数学机械化"思想的典型实践（吴文俊方法）。它证明了欧几里得平面的几何事实可以完全由多项式方程的零点集合（代数簇）来描述。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤
* **解题策略**：执行**"坐标法三步曲"**：**表示**（点线面映射为坐标方程） $\to$ **运算**（执行代数求解） $\to$ **翻译**（还原几何结论）。
* **标准操作步骤（SOP）**：
  * **步骤 $1$ [选系表点]**：选择对称轴或垂直线为坐标轴，写出关键点坐标及方程。
  * **步骤 $2$ [建立方程]**：根据几何要素（如垂直、距离相等、相切）建立方程（组）。
  * **步骤 $3$ [运算翻译]**：解方程得出数值，并根据公式（如弦长公式 $2\sqrt{r^2-d^2}$）翻译几何量。

---

### 典型例题
#### 例题1（基础示范题）：
1. **题目**：已知直线 $l: x - y + 1 = 0$ 和圆 $C: x^2 + y^2 - 2x = 0$。判断直线与圆的位置关系，并求弦长。
2. **【结构与特征分析】**：形视识别入口为"直线一般式 + 圆的一般式"。核心考核直线与圆位置判定的"几何路径"算子。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：将圆方程配方。
   * *决策*：提取圆心坐标 $(a, b)$ 和半径 $r$ ➔ 选取几何法（计算 $d$）。
   * *分支*：比较 $d$ 与 $r$ ➔ 判定位置 ➔ 若相交，套用勾股弦长算子。
   * *终点*：输出几何结论与数值。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [锁定参数]]：圆 $C$ 配方得 $(x-1)^2 + y^2 = 1$，圆心 $(1, 0)$，半径 $r = 1$。
   * [步骤 $2$ [距离运算]]：$d = \frac{|1-0+1|}{\sqrt{1^2+(-1)^2}} = \frac{2}{\sqrt{2}} = \sqrt{2}$。
   * [步骤 $3$ [阈值判定]]：因 $d = \sqrt{2} > r = 1$，故判定结论为相离。
5. **【避坑提示】**：求距离时，直线方程系数 $A, B$ 需准确对应，分母必须带根号。
6. **结论**：直线与圆相离，无弦长。

#### 例题2（综合变式题）：
1. **题目**：已知两圆 $C_1: x^2 + y^2 + 2x + 8y - 8 = 0$ 与 $C_2: x^2 + y^2 - 4x - 4y - 2 = 0$，求两圆公共弦所在直线的方程。
2. **【结构与特征分析】**：形视识别入口为"双二次方程组"。特征点在于两圆 $x^2, y^2$ 项系数均为 $1$，且相减可消元。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：判定两圆是否相交。
   * *决策*：利用"相减消项法"提取一次方程 ➔ 一次方程即为穿过两个交点的公共弦。
   * *收敛*：整理得一般式方程。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [联立消元]]：$(C_1) - (C_2) = 0$。
   * [步骤 $2$ [代数化简]]：$6x + 12y - 6 = 0$。
   * [步骤 $3$ [标准化输出]]：化简得 $x + 2y - 1 = 0$。
5. **【避坑提示】**：公共弦方程的前提是两圆必须相交，若两圆不相交，此方程代表的是两圆的"等幂轴"而非公共弦。
6. **结论**：公共弦方程为 $x + 2y - 1 = 0$。

### 巩固习题
##### 梯度一：基础达标
1. **题 $1$ **：点 $P(-1, 2)$ 到直线 $l: 3x + 4y - 2 = 0$ 的距离为 ____。
   *   **答案**：$0.6$。解析：$d = \frac{|3(-1)+4(2)-2|}{\sqrt{3^2+4^2}} = \frac{3}{5} = 0.6$。
2. **题 $2$ **：判断：方程 $x^2 + y^2 + 2x - 4y + 5 = 0$ 表示一个圆。
   *   **答案**：错误。解析：$D^2+E^2-4F = 4+16-20=0$，方程仅表示一个点 $(-1, 2)$。

##### 梯度二：高考中档
3. **题 $3$ **：经过点 $P(2, 3)$ 且在两坐标轴上截距相等的直线方程为？
   *   **详细解析**：分类讨论：① 过原点时 $k = 1.5$，方程 $3x - 2y = 0$；② 不经过原点时设 $x/a + y/a = 1$，代入得 $a = 5$，方程 $x + y - 5 = 0$。
4. **题 $4$ **：直线 $x + y - 2 = 0$ 被圆 $x^2 + y^2 = 4$ 截得的弦长为？
   *   **详细解析**：圆心 $(0, 0), r = 2$。距离 $d = \frac{|-2|}{\sqrt{2}} = \sqrt{2}$。弦长 $L = 2\sqrt{2^2 - (\sqrt{2})^2} = 2\sqrt{2}$。

##### 梯度三：能力拔高
5. **题 $5$ **：已知圆 $C: x^2 + y^2 - 4x - 14y + 4 = 0$，直线 $l: y = kx + 1$。若直线 $l$ 恒与圆 $C$ 有公共点，求 $k$ 的范围。
   *   **思维破局**：圆心 $(2, 7), r = 7$。利用圆心到直线距离 $d \le r$ 建立关于 $k$ 的不等式。
   *   **解析**：$\frac{|2k - 7 + 1|}{\sqrt{k^2+1}} \le 7 \implies (2k-6)^2 \le 49(k^2+1)$。展开得 $45k^2 + 24k + 13 \ge 0$。由于 $\Delta < 0$，该不等式对任意 $k \in \mathbb{R}$ 恒成立。故 $k$ 取一切实数。
