# 复数的三角表示
**教材**: 人教版必修第二册第七章 7.3 节

## 知识深度笔记

### 现象

*   **【情境锚定：从"直角坐标"到"极径辐角"的视角升维】**：
    *   **起因（背景与任务）**：在 $7.2$ 节中，复数的代数形式 $a + bi$ 能够高效处理线性加减运算。但在处理复数的乘方、开方以及涉及平面旋转的物理模型时，代数形式的计算量呈指数级增长。
    *   **冲突（瓶颈与矛盾）**：代数形式侧重于"平移"逻辑，难以直观描述复平面内向量的"伸缩"与"旋转"本质。当我们需要计算 $z^n$ 或判断复数旋转后的位置时，旧的代数工具显得极为笨重。
    *   **指向（概念诞生）**：通过建立**复数三角表示协议（Complex Trigonometric Protocol）**，利用模长 $r$ 和辐角 $\theta$ 作为核心参数，实现了复数从"位置点"向"旋转算子"的逻辑跨越。

### 原因

*   **形成机制**：基于**向量极坐标化与三角投影逻辑**。
    1.  **几何映射**：复数 $z = a + bi$ 对应向量 $\vec{OZ} = (a, b)$。令 $r = |\vec{OZ}|$，实部 $a = r\cos\theta$，虚部 $b = r\sin\theta$。
    2.  **结构合成**：将投影关系代入代数式，提取公因子 $r$，得到标准算子 $r(\cos\theta + i\sin\theta)$。
    3.  **算子叠加**：复数乘法的几何本质是"模长相乘，辐角相加"，这在三角形式下通过和角公式得到了完美的代数支撑。
*   **条件剖析**：辐角具有多值性。
    *   *反例*：复数 $i$ 的辐角可以是 $\frac{\pi}{2}$，也可以是 $\frac{5\pi}{2}$。为确保表达唯一性，协议规定 $arg z \in [0, 2\pi)$ 为**辐角主值**。

### 结果

*   **【核心公式提取（Formulas）】**：
    *   **三角表示算子**：$z = r(\cos\theta + i\sin\theta)$。
    *   **乘除法算子**：$z_1z_2 = r_1r_2[\cos(\theta_1+\theta_2) + i\sin(\theta_1+\theta_2)]$；$\frac{z_1}{z_2} = \frac{r_1}{r_2}[\cos(\theta_1-\theta_2) + i\sin(\theta_1-\theta_2)]$。
    *   **棣莫弗定理**：$z^n = r^n(\cos n\theta + i\sin n\theta)$ ($n \in \mathbb{N}^*$)。
*   **【重要性质归纳（Properties）】**：
    1.  **模长契约**：$r = |z| = \sqrt{a^2 + b^2}$ 恒为非负实数。
    2.  **共轭转换**：$\bar{z}$ 的模为 $r$，辐角为 $-\theta$（或 $2\pi - \theta$）。
*   **【核心特点剖析（Characteristics）】**：
    *   **代数结构特征**：将复数解构为规模（模）与指向（辐角）两个独立因子。
    *   **几何图像特征**：复数乘法对应复平面内的**伸缩旋转变换**。
*   **【要素拆解】**：
    *   【适用前提】：复数 $z \neq 0$（零复数辐角任意）。
    *   【核心结论】：乘除运算转化为模的算术运算与角的加减运算。

### 应用

*   **学科内应用**：求复数的 $n$ 次方根、简化三角恒等式的证明。
*   **跨学科/实际应用**：**交流电向量图分析**。利用复数的三角形式表示电流、电压的峰值与初相位，将电路分析转化为复平面的向量几何旋转。

### 本质

*   **数学思想方法**：**数形结合**、**化归思想**（乘除→加减）。
*   **高观点视域**：本节是"欧拉公式（Euler's Formula）" $e^{i\theta} = \cos\theta + i\sin\theta$ 的初等表达。它揭示了指数运算与三角函数在复数域的深层统一。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

*   **解题策略**：执行"一求模 $r$、二定象限、三算主值 $\theta$、四写三角式"的 SOP。
*   **标准操作步骤（SOP）**：
    *   **步骤 $1$：[参数析出]** 计算 $r = \sqrt{a^2 + b^2}$。
    *   **步骤 $2$：[相位锁定]** 结合 $\cos\theta = \frac{a}{r}$ 和 $\sin\theta = \frac{b}{r}$ 判定 $\theta$。
    *   **步骤 $3$：[算子计算]** 应用乘除协议，执行"模乘积、角相加（减）"。

---

### 典型例题

#### 例题1（代数式向三角式转换）：
**题目**：把复数 $z = 1 - i$ 表示成三角形式。

1.  **【结构与特征分析】**：形视识别入口为"实虚部相等"。点位于第四象限。
2.  **【解题决策逻辑流（思维推演）】**：
    *   $r = \sqrt{1+1} = \sqrt{2}$ ➔
    *   $\cos\theta = 1/\sqrt{2}, \sin\theta = -1/\sqrt{2}$，第四象限 → $\theta = 7\pi/4$ ➔
    *   $z = \sqrt{2}(\cos(7\pi/4) + i\sin(7\pi/4))$。
3.  **【解析（对照 SOP 步骤）】**：$\sqrt{2}(\cos(7\pi/4) + i\sin(7\pi/4))$。
4.  **【避坑提示】**：辐角 $\theta$ 取值不唯一，标准表示通常用主值或负角。
**结论**：$z = \sqrt{2}(\cos\frac{7\pi}{4} + i\sin\frac{7\pi}{4})$。

#### 例题2（乘法运算及其几何意义）：
**题目**：$z_1 = \sqrt{2}(\cos\pi/4 + i\sin\pi/4), z_2 = 2(\cos\pi/3 + i\sin\pi/3)$，求 $z_1z_2$ 并描述几何变换。

1.  **【结构与特征分析】**：形视识别入口为"三角形式乘法"。
2.  **【解题决策逻辑流（思维推演）】**：
    *   $z_1z_2 = 2\sqrt{2}[\cos(7\pi/12) + i\sin(7\pi/12)]$ ➔
    *   几何意义：模长变为原来的 $2$ 倍，向量逆时针旋转 $\pi/3$。
3.  **【解析（对照 SOP 步骤）】**：$2\sqrt{2}(\cos 7\pi/12 + i\sin 7\pi/12)$。
4.  **【避坑提示】**：相乘时角度相加，相除时相减。
**结论**：$2\sqrt{2}(\cos\frac{7\pi}{12} + i\sin\frac{7\pi}{12})$。
