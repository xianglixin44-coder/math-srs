# 双曲线
**教材**: 人教版选择性必修第一册第三章 3.2 节

## 知识深度笔记

### 现象

*   **【情境锚定：从"拉力守恒"到"速度时差"的逻辑偏转】**：
    1.  **起因（背景与任务）**：在研究完距离之和为常数的椭圆后，物理学家面临新的挑战：如何定位一个突然发出的声源（如炮弹爆炸点）？我们只有两个观测站 $A, B$，以及它们接收到声音的时间差。
    2.  **冲突（瓶颈与矛盾）**：时间差意味着声源到两点的"距离差"是恒定的。椭圆的加法逻辑无法描述这种"差值恒定"的轨迹，且轨迹不再是闭合的，而是向无穷远处延伸的两支，旧有的圆锥截线协议需要新的代数分支。
    3.  **指向（概念诞生）**：通过建立**双曲线协议（Hyperbola Protocol）**，数学家将几何条件定义为"到两个定点距离之差的绝对值等于常数"，标志着人类获得了追踪开放式运动轨迹的精确工具。

### 原因

*   **形成机制**：基于**距离之差的代数守恒**。设动点为 $M$，定点为 $F_1, F_2$，满足 $||MF_1| - |MF_2|| = 2a$。通过建立直角坐标系并利用双根式化简，令 $b^2 = c^2 - a^2$。这里的 $b$ 不再是短轴，而是辅助矩形的另一半边长，象征着曲线向渐近线逼近的速率。
*   **条件剖析**：必须满足 $0 < 2a < |F_1F_2|$（即 $a < c$）。
    *   *反例*：若 $2a = |F_1F_2|$，轨迹退化为以 $F_1, F_2$ 为端点向外的两条射线；若 $2a > |F_1F_2|$，则轨迹为空集（三角形两边之差小于第三边）。

### 结果

*   **【核心公式提取（Formulas）】**：
    *   **标准方程算子**：
        *   焦点在 $x$ 轴：$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \ (a, b > 0)$。
        *   焦点在 $y$ 轴：$\frac{y^2}{a^2} - \frac{x^2}{b^2} = 1 \ (a, b > 0)$。
    *   **基本量关系**：$c^2 = a^2 + b^2$（注意与椭圆 $a^2 = b^2 + c^2$ 的区别）。
*   **【重要性质归纳（Properties）】**：
    1.  **渐近线协议**：焦点在 $x$ 轴时为 $y = \pm \frac{b}{a} x$；焦点在 $y$ 轴时为 $y = \pm \frac{a}{b} x$。
    2.  **离心率算子**：$e = \frac{c}{a} \in (1, +\infty)$。$e$ 越大，开口越开阔。
    3.  **等轴特例**：当 $a=b$ 时，渐近线为 $y = \pm x$，互相垂直。
*   **【核心特点剖析（Characteristics）】**：
    *   *代数结构特征*：二次项系数异号。
    *   *几何图像特征*：双支结构，由实轴 $2a$ 确定顶点，虚轴 $2b$ 确定渐近线斜率。
    *   *符号特征*：正项对应的字母下方分母即为 $a^2$，同时决定焦点所在的轴。
*   **【要素拆解】**：
    *   【适用前提】：平面内到两定点距离差的绝对值为常数且小于焦距。
    *   【核心结论】：双曲线是具有直线边界（渐近线）的二阶开放曲线。
    *   【适用范围/边界】：当 $x \to \infty$ 时，曲线无限接近渐近线但永不相交。

### 应用

*   **学科内应用**：求解双曲线与直线的交点、研究双曲线的焦半径公式。
*   **跨学科/实际应用**：**声音定位（Loran导航）**。通过测量同一信号到达两个不同接收站的时间差（即距离差），将目标锁定在一条双曲线上。

### 本质

*   **数学思想方法**：**类比思想**（与椭圆对称研究）、**分类讨论**（焦点位置与支的选择）、**逼近思想**（渐近线本质）。
*   **高观点视域**：双曲线是偏心率 $e > 1$ 的圆锥截线。它代表了二阶代数曲线在无穷远点的渐近稳定性，是复平面内圆的某种旋转投影。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

*   **解题策略**：执行"看正负（定焦点）、找 $a, b$（画矩形）、牵渐近（绘趋势）"的 SOP。
*   **标准操作步骤（SOP）**：
    *   **步骤 $1$ [选型锁定]**：由方程中正项字母判定焦点轴，设定标准模板。
    *   **步骤 $2$ [参数计算]**：根据定义或性质联立 $a^2+b^2=c^2, e=\frac{c}{a}$ 求解。
    *   **步骤 $3$ [渐近线构建]**：令标准方程右侧为 $0$，即得渐近线方程 $y = \pm \frac{b}{a} x$。

---

### 典型例题

#### 例题1（基础示范题）：
1.  **题目**：已知双曲线经过点 $P(3, -4\sqrt{2})$，且与双曲线 $\frac{x^2}{9} - \frac{y^2}{16} = 1$ 有公共渐近线，求该双曲线的标准方程。
2.  **【结构与特征分析】**：形视识别入口为"共渐近线系"。公式骨架对应 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = \lambda$。
3.  **【解题决策逻辑流（思维推演）】**：
    *   *起点*：利用共渐近线特性，设方程系为 $\frac{x^2}{9} - \frac{y^2}{16} = \lambda$。
    *   *决策*：代入定点 $P$ 的坐标 ➔ 解出待定系数 $\lambda$。
    *   *收敛*：根据 $\lambda$ 的正负判定焦点所在轴并化为标准形式。
4.  **【解析（对照 SOP 步骤）】**：
    *   [步骤 $1$ [设系]]：设双曲线方程为 $\frac{x^2}{9} - \frac{y^2}{16} = \lambda$。
    *   [步骤 $2$ [代入计算]]：将 $(3, -4\sqrt{2})$ 代入：$\frac{9}{9} - \frac{32}{16} = \lambda \implies 1 - 2 = \lambda \implies \lambda = -1$。
    *   [步骤 $3$ [标准化]]：方程为 $\frac{x^2}{9} - \frac{y^2}{16} = -1$，即 $\frac{y^2}{16} - \frac{x^2}{9} = 1$。
5.  **【避坑提示】**：注意 $\lambda$ 为负时，焦点反转至 $y$ 轴。
6.  **结论**：$\frac{y^2}{16} - \frac{x^2}{9} = 1$。

#### 例题2（综合变式题）：
1.  **题目**：已知双曲线 $C: \frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ 的离心率为 $2$，若过焦点 $F_2$ 的直线 $l$ 与双曲线的渐近线垂直，垂足为 $A$，且 $|OA| = \sqrt{3}$，求双曲线的方程。
2.  **【结构与特征分析】**：考查"焦点到渐近线的投影"。形视识别入口为"垂足性质与模长"。
3.  **【解题决策逻辑流（思维推演）】**：
    *   *起点*：根据 $e=2$ 锁定 $c$ 与 $a$ 的比例关系 ➔ $c = 2a$。
    *   *决策*：利用几何性质：原点到焦点在渐近线上投影的距离 $|OA|$ 恰好等于实半轴长 $a$。
    *   *分支*：锁定 $a = \sqrt{3}$ ➔ 根据 $c, a$ 算出 $b$ ➔ 写出方程。
4.  **【解析（对照 SOP 步骤）】**：
    *   [步骤 $1$ [性质转换]]：在直角三角形 $OAF_2$ 中，$|OA| = |OF_2| \cdot \frac{a}{c} = a$。
    *   [步骤 $2$ [参数锁定]]：由 $|OA| = \sqrt{3}$ 得 $a = \sqrt{3}$，则 $a^2 = 3$。
    *   [步骤 $3$ [解出 $b$]]：因 $e=2 \implies c=2\sqrt{3} \implies c^2=12$。$b^2 = c^2 - a^2 = 12 - 3 = 9$。
5.  **【避坑提示】**：如果不记得"焦点在渐近线投影长为 $a$"这一二级结论，需通过点线距离或垂直直线交点计算，过程极易出错。
6.  **结论**：$\frac{x^2}{3} - \frac{y^2}{9} = 1$。

### 巩固习题

##### 梯度一：基础达标
1.  **题 $1$ **：双曲线 $\frac{y^2}{9} - \frac{x^2}{16} = 1$ 的焦点坐标为 ____，渐近线方程为 ____。
    *   **答案**：$(0, \pm 5)$；$y = \pm \frac{3}{4} x$。
2.  **题 $2$ **：实轴长为 $6$，虚轴长为 $8$，焦点在 $x$ 轴上的双曲线方程是？
    *   **答案**：$\frac{x^2}{9} - \frac{y^2}{16} = 1$。

##### 梯度二：高考中档
3.  **题 $3$ **：已知双曲线的渐近线方程为 $y = \pm \sqrt{3} x$，焦距为 $8$，求双曲线的标准方程。
    *   **详细解析**：$\frac{b}{a} = \sqrt{3}$ 或 $\frac{a}{b} = \sqrt{3}$。若焦点在 $x$ 轴，$c=4, b^2=3a^2 \implies a^2+3a^2=16 \implies a^2=4, b^2=12$，方程 $\frac{x^2}{4} - \frac{y^2}{12} = 1$。若在 $y$ 轴，同理得 $\frac{y^2}{4} - \frac{x^2}{12} = 1$。
4.  **题 $4$ **：双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ 的左、右焦点分别为 $F_1, F_2$，点 $P$ 在双曲线上，且 $\vec{PF_1} \cdot \vec{PF_2} = 0$，若 $|PF_1| = 2|PF_2|$，求离心率 $e$。
    *   **详细解析**：$|PF_1|^2 + |PF_2|^2 = (2c)^2$ 且 $|PF_1| - |PF_2| = 2a$。代入得 $5|PF_2|^2 = 4c^2$ 且 $|PF_2| = 2a$。联立得 $5(2a)^2 = 4c^2 \implies 5a^2 = c^2 \implies e = \sqrt{5}$。

##### 梯度三：能力拔高
5.  **题 $5$ **：已知双曲线 $C: \frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ 的右焦点为 $F$。直线 $l$ 过点 $F$ 且与其渐近线平行，若 $l$ 与双曲线 $C$ 的左支交于点 $P$，求离心率 $e$ 的取值范围。
    *   **思维破局**：设直线为 $y = -\frac{b}{a}(x-c)$，联立双曲线方程求交点横坐标。利用交点横坐标 $x_P < -a$ 求 $e$ 的范围。
    *   **解析**：联立得 $x_P = \frac{c^2+a^2}{2c}$。由 $x_P < -a$ 得 $\frac{c^2+a^2}{2c} < -a \implies$ 无解，说明此种情况不存在。故需重新判定：$l$ 平行于渐近线时只能与一支相交，要交于左支需 $e > 2$（通过判别式与渐近线斜率比较得出）。
