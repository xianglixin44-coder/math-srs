# 平面向量加、减运算的坐标表示
**教材**: 人教版必修第二册第六章 6.3.3 节

## 知识深度笔记

### 现象
*   **【情境锚定：从"几何平移"到"算术求和"的效率飞跃】**：
    *   **起因（背景与任务）**：在 $6.3.2$ 中，我们建立了坐标协议，将向量映射为坐标 $(x, y)$。现在的任务是计算两个向量的和 $\vec{a} + \vec{b}$ 或差 $\vec{a} - \vec{b}$。
    *   **冲突（瓶颈与矛盾）**：传统的三角形法则或平行四边形法则依赖于精确的几何作图和角度测量。在处理复杂的力系合成或连续位移时，频繁的尺规作图不仅误差大，且无法进行大规模代数运算。
    *   **指向（概念诞生）**：通过建立**坐标运算法则（Coordinate Operation Protocol）**，利用基底 $\vec{i}, \vec{j}$ 的线性性质，将向量的几何叠加坍缩为对应分量的代数加减，实现了向量运算与实数加减法的逻辑并轨。

### 原因
*   **形成机制**：基于**基底组合与分配律逻辑**。
    1.  **分量解构**：设 $\vec{a} = x_1\vec{i} + y_1\vec{j}$，$\vec{b} = x_2\vec{i} + y_2\vec{j}$。
    2.  **线性组合**：根据加法交换律与结合律，将同基底项合并：$(x_1 + x_2)\vec{i} + (y_1 + y_2)\vec{j}$。
    3.  **坐标重构**：合并后的系数对 $(x_1 + x_2, y_1 + y_2)$ 即为和向量的新坐标。
*   **条件剖析**：运算必须在同一正交基底系统下进行。
    *   *反例*：若向量 $\vec{a}$ 在系 $A$ 下表示，$\vec{b}$ 在系 $B$ 下表示，直接分量相加将导致方向逻辑错位。

### 结果
*   **【核心公式提取（Formulas）】**：
    *   **加法算子**：$(x_1, y_1) + (x_2, y_2) = (x_1 + x_2, y_1 + y_2)$。
    *   **减法算子**：$(x_1, y_1) - (x_2, y_2) = (x_1 - x_2, y_1 - y_2)$。
    *   **终起点协议**：若 $A(x_1, y_1)$，$B(x_2, y_2)$，则 $\vec{AB} = (x_2 - x_1, y_2 - y_1)$。
*   **【重要性质归纳（Properties）】**：
    1.  **分量独立性**：$x$ 轴上的运算与 $y$ 轴上的运算互不干扰，遵循一维实数运算法则。
    2.  **点矢关联性**：向量的坐标等于终点坐标减去起点坐标，即"后减前"。
*   **【核心特点剖析（Characteristics）】**：
    *   **代数结构特征**：呈现出分量对齐、一一对应的齐次特征。
    *   **符号特征**：注意 $\vec{AB}$ 与 $\vec{BA}$ 坐标互为相反数。
*   **【要素拆解】**：
    *   【适用前提】：向量已实现坐标化。
    *   【核心结论】：两个向量和（差）的坐标等于各向量相应坐标的和（差）。
    *   【适用范围】：涵盖所有平面线性位移系统。

### 应用
*   **学科内应用**：作为解平行四边形顶点坐标、证明几何中点性质的基础工具。
*   **跨学科/实际应用**：**北斗导航差分定位**。通过接收机坐标 $\vec{P}$ 与基准站坐标 $\vec{O}$ 的减法运算 $\vec{OP}$，实时修正定位偏差。

### 本质
*   **数学思想方法**：**化归转化**（几何运算 → 代数运算）、**数形结合**。
*   **高观点视域**：坐标加法是向量空间作为加法群的代数表现。它揭示了欧几里得空间平移对称性的算术本质。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤
*   **解题策略**：执行"一找点（起点/终点坐标）、二套协议（终点减起点）、三算值（分量对齐结算）"的坐标运算 SOP。
*   **标准操作步骤（SOP）**：
    *   **步骤 $1$ [分量对齐]**：将参与运算的向量坐标按 $x, y$ 对应位置排布。
    *   **步骤 $2$ [符号代入]**：严格执行加减号规则，注意负负得正。
    *   **步骤 $3$ [结果封装]**：输出有序实数对。

---

### 典型例题
#### 例题1（基础坐标化简）：
**题目**：已知 $\vec{a} = (2, 1)$，$\vec{b} = (-3, 4)$，求 $\vec{a}+\vec{b}$ 与 $\vec{a}-\vec{b}$ 的坐标。

1.  **【结构与特征分析】**：形视识别入口为"已知分量求和差"。
2.  **【解题决策逻辑流（思维推演）】**：
    *   $\vec{a}+\vec{b} = (2-3, 1+4) = (-1, 5)$ ➔
    *   $\vec{a}-\vec{b} = (2-(-3), 1-4) = (5, -3)$。
3.  **【解析（对照 SOP 步骤）】**：$(-1, 5)$；$(5, -3)$。
4.  **【避坑提示】**：减法运算时容易忽略减负数的符号反转。
**结论**：$(-1, 5)$ 和 $(5, -3)$。

#### 例题2（几何顶点追溯）：
**题目**：平行四边形 $ABCD$ 中 $A(-2,1), B(-1,3), C(3,4)$，求 $D$ 坐标。

1.  **【结构与特征分析】**：形视识别入口为"平行四边形顶点关联"。
2.  **【解题决策逻辑流（思维推演）】**：
    *   $\vec{AB} = (1, 2)$ ➔ 设 $D(x,y)$，$\vec{DC} = (3-x, 4-y)$ ➔
    *   $\vec{AB} = \vec{DC} \implies 3-x=1, 4-y=2 \implies x=2, y=2$。
3.  **【解析（对照 SOP 步骤）】**：$D(2, 2)$。
4.  **【避坑提示】**：$\vec{AB}$ 必须对应 $\vec{DC}$ 而非 $\vec{CD}$。
**结论**：$D(2, 2)$。
