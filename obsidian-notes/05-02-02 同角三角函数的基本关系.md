# 同角三角函数的基本关系
**教材**: 人教版必修第一册第五章 5.2.2 节

## 知识深度笔记

### 现象

*   **【情境锚定：从"孤立定义"到"结构耦合"的逻辑闭环】**：
    *   **起因（背景与任务）**：在 $5.2.1$ 中，我们通过单位圆上的点 $P(x, y)$ 独立定义了正弦、余弦和正切。在已知其中一个函数值时，我们往往需要推算其他两个值。
    *   **冲突（瓶颈与矛盾）**：初看起来，三个函数值似乎是独立的投影。但由于点 $P$ 被强制锁定在"半径为 $1$ 的圆周"上，其横纵坐标并非随机，而是受到圆方程的物理约束。旧有的孤立观察法无法解释这种"牵一发而动全身"的数值联动。
    *   **指向（概念诞生）**：通过建立**同角三角关系协议（Fundamental Identities Protocol）**，将勾股定理转化为三角函数的代数等式，实现了三角函数间从"离散定义"向"结构整体"的质变。

### 原因

*   **形成机制**：基于**勾股定理的解析映射逻辑**。
    1.  **平方和逻辑**：点 $P(x, y)$ 在单位圆上 $\implies x^2 + y^2 = 1$。代入定义 $x = \cos \alpha, y = \sin \alpha$ 即得平方和关系。
    2.  **商数逻辑**：根据正切定义 $\tan \alpha = \frac{y}{x}$，直接映射为正弦与余弦的比值比。
*   **条件剖析**：必须满足"同角"前提。
    *   *反例*：$\sin^2 \alpha + \cos^2 \beta$ 通常不等于 $1$，因为它们对应单位圆上不同的点。

### 结果

*   **【核心公式提取（Formulas）】**：
    *   **平方关系算子**：$\sin^2 \alpha + \cos^2 \alpha = 1$。
    *   **商数关系算子**：$\tan \alpha = \frac{\sin \alpha}{\cos \alpha}$ （$\alpha \neq k\pi + \frac{\pi}{2}$）。
*   **【重要性质归纳（Properties）】**：
    1.  **知一求二契约**：已知 $\sin \alpha, \cos \alpha, \tan \alpha$ 中的任意一个（及象限），可锁定另外两个。
    2.  **结构互化性**：允许在解析式中实现"切割化弦"或将 $\tan$ 转化为 $\sin, \cos$。
*   **【核心特点剖析（Characteristics）】**：
    *   **代数结构特征**：平方关系体现了对称性与守恒律；商数关系体现了比例性。
    *   **符号特征**：$\sin^2 \alpha$ 是 $(\sin \alpha)^2$ 的缩写，严禁写成 $\sin \alpha^2$。
*   **【要素拆解】**：
    *   【适用前提】：自变量 $\alpha$ 必须完全相同。
    *   【核心结论】：三角函数是单位圆几何关系的代数编码。
    *   【适用范围】：涵盖所有使公式有意义的实数域。

### 应用

*   **学科内应用**：作为简化三角综合式、证明三角恒等式以及解三角方程的底层算法。
*   **跨学科/实际应用**：**波动能量分析**。在物理学中，波的动能与势能往往分别正比于位移的正弦与余弦平方，利用平方和关系可证明总机械能的守恒性。

### 本质

*   **数学思想方法**：**化归转化**（切弦互化）、**分类讨论**（由平方根引入的正负号判定）。
*   **高观点视域**：这两个公式本质上是单位圆在欧几里得空间下的拓扑不变性。它揭示了旋转变换中"距离不变"这一深刻的几何真理。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

*   **解题策略**：执行"一判象限（定符号）、二套平方（求弦值）、三用比例（求切值）"的求值 SOP。在证明题中，遵循"从繁到简、切化为弦"的化简准则。
*   **标准操作步骤（SOP）**：
    *   **步骤 $1$：[象限安检]** 根据已知条件判定角 $\alpha$ 所在象限，预设 $\sin, \cos, \tan$ 的正负号。
    *   **步骤 $2$：[平方映射]** 应用 $\sin^2 \alpha + \cos^2 \alpha = 1$ 求解未知弦值。
    *   **步骤 $3$：[比例合成]** 应用 $\tan \alpha = \frac{\sin \alpha}{\cos \alpha}$ 补全关系链。

---

### 典型例题

#### 例题1（基础求值示范题）：
**题目**：已知 $\sin \alpha = -\frac{3}{5}$，求 $\cos \alpha$ 和 $\tan \alpha$ 的值。

1.  **【结构与特征分析】**：形视识别入口为"已知正弦求其余"。由于未给出明确象限，需触发"分类讨论算子"。
2.  **【解题决策逻辑流（思维推演）】**：
    *   起点（源头）：正弦值为负 ➔
    *   分支（决策）：角 $\alpha$ 可能在第三或第四象限 ➔
    *   决策（平方）：通过 $\cos^2 \alpha = 1 - \sin^2 \alpha$ 开启双向映射 ➔
    *   终点（收敛）：针对每个象限输出成对函数值。
3.  **【解析（对照 SOP 步骤）】**：
    *   [步骤 $1$ [平方求解]]：$\cos^2 \alpha = 1 - 9/25 = 16/25$。
    *   [步骤 $2$ [三象限]]：$\cos \alpha = -4/5, \tan \alpha = 3/4$。
    *   [步骤 $3$ [四象限]]：$\cos \alpha = 4/5, \tan \alpha = -3/4$。
4.  **【避坑提示】**：忽略开方后的正负号讨论是最大逻辑陷阱。
**结论**：$\cos \alpha = -4/5, \tan \alpha = 3/4$ 或 $\cos \alpha = 4/5, \tan \alpha = -3/4$。

#### 例题2（恒等证明变式题）：
**题目**：证明 $\frac{\cos x}{1 - \sin x} = \frac{1 + \sin x}{\cos x}$。

1.  **【结构与特征分析】**：形视识别入口为"分式结构等价性"。分子分母包含互补结构 $1 \pm \sin x$，暗示可应用平方差转化。
2.  **【解题决策逻辑流（思维推演）】**：
    *   起点（源头）：观察左侧分母含 $1 - \sin x$ ➔
    *   分支（决策）：分子分母同乘 $1 + \sin x$，构造平方差 ➔
    *   决策（化简）：应用 $\sin^2 x + \cos^2 x = 1$ 坍缩为 $\cos^2 x$ ➔
    *   终点（收敛）：约分完成收敛。
3.  **【解析（对照 SOP 步骤）】**：
    *   [步骤 $1$ [同乘]]：左边 $= \frac{\cos x(1 + \sin x)}{1 - \sin^2 x}$。
    *   [步骤 $2$ [坍缩]]：$= \frac{\cos x(1 + \sin x)}{\cos^2 x} = \frac{1 + \sin x}{\cos x}$。
4.  **【避坑提示】**：证明前需默认分母不为零。
**结论**：原等式成立。

### 巩固习题

##### 梯度一：基础达标
1.  **题 $1$ **：已知 $\cos \alpha = -4/5$ 且 $\alpha$ 为第三象限角，则 $\sin \alpha = -3/5, \tan \alpha = 3/4$。
2.  **题 $2$ **：已知 $\tan \alpha = -\sqrt{3}$，则 $\cos \alpha = \pm 1/2$，$\sin \alpha = \mp \sqrt{3}/2$。

##### 梯度二：高考中档
3.  **题 $3$ **：化简 $\sqrt{1 + 2\sin \alpha \cos \alpha} = |\sin \alpha + \cos \alpha|$。在 $(\pi/4, \pi/2)$ 内为 $\sin \alpha + \cos \alpha$。
4.  **题 $4$ **：已知 $\tan \alpha = 2$，弦化切得 $\frac{\sin \alpha + \cos \alpha}{\sin \alpha - \cos \alpha} = \frac{\tan \alpha + 1}{\tan \alpha - 1} = 3$。

##### 梯度三：能力拔高
5.  **题 $5$ **：$\sin^4 \alpha + \cos^4 \alpha = 5/9$。$(\sin^2 \alpha + \cos^2 \alpha)^2 - 2\sin^2 \alpha \cos^2 \alpha = 5/9 \implies \sin \alpha \cos \alpha = \pm \sqrt{2}/3$。
