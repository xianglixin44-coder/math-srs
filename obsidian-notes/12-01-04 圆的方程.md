# 圆的方程
**教材**: 人教版选择性必修第一册第二章 2.4 节

## 知识深度笔记

### 现象

* **【情境锚定：从"规矩定形"到"算子锁域"的逻辑重构】**：
  1. **起因（背景与任务）**：在平面几何中，圆被定义为到定点距离等于定长的点的集合。为了将这一直观图形引入坐标系进行定量分析，我们需要刻画圆上任意一点 $M(x, y)$ 必须服从的代数协议。
  2. **冲突（瓶颈与矛盾）**：传统的定性描述（如"圆心在 $A$，半径为 $r$"）无法直接参与代数方程组的消元运算。在解决涉及圆的切线、交点或运动轨迹时，旧工具缺乏一个能将"等距离性"转化为"变量约束"的桥梁。
  3. **指向（概念诞生）**：通过建立**圆的方程协议**（标准方程与一般方程），将圆的几何轨迹映射为二元二次方程的解集，标志着圆形研究由"视觉感知"转向"数字化计算"。

### 原因

* **形成机制**：基于**距离算子的代数化**。利用两点间距离公式 $\sqrt{(x-a)^2+(y-b)^2}=r$，平方化简即得标准方程。而一般方程 $x^2+y^2+Dx+Ey+F=0$ 则是通过配方法还原为标准形式，其逻辑前提是必须满足判别式约束。
* **条件剖析**：一般方程表示圆的充要条件是 $D^2 + E^2 - 4F > 0$。
    * *反例*：若 $D^2 + E^2 - 4F = 0$，方程退化为一个点 $(-\frac{D}{2}, -\frac{E}{2})$；若 $D^2 + E^2 - 4F < 0$，方程在实数范围内无解（空集）。

### 结果

* **【核心公式提取（Formulas）】**：
  * **标准方程算子**：$(x-a)^2 + (y-b)^2 = r^2$（圆心 $(a, b)$，半径 $r$）。
  * **一般方程算子**：$x^2 + y^2 + Dx + Ey + F = 0$。
* **【重要性质归纳（Properties）】**：
  1. **圆心与半径转化**：对于一般方程，圆心为 $(-\frac{D}{2}, -\frac{E}{2})$，半径 $r = \frac{1}{2}\sqrt{D^2+E^2-4F}$。
  2. **对称性协议**：圆既是关于圆心对称的中心对称图形，也是关于过圆心的任何直线对称的轴对称图形。
* **【核心特点剖析（Characteristics）】**：
  * *代数结构特征*：二次项系数相等且不为 $0$ ($A=C \neq 0$)，且不含 $xy$ 交叉项。
  * *几何图像特征*：闭合曲线，内部点满足 $(x-a)^2 + (y-b)^2 < r^2$。
  * *符号特征*：注意标准方程中的负号，如 $(x+2)^2$ 对应圆心横坐标 $a = -2$。
* **【要素拆解】**：
  * 【适用前提】：确定圆心坐标和半径大小。
  * 【核心结论】：方程是圆在代数空间的唯一身份算子。
  * 【适用范围/边界】：需校验 $D, E, F$ 的判别式，确保图形不是点或不存在。

### 应用

* **学科内应用**：判定直线与圆的位置关系、求解圆的弦长、研究圆与圆的公切线。
* **跨学科/实际应用**：**赵州桥拱设计**。通过跨度与拱高数据建立圆的方程，精确计算每根支撑支柱的高度。

### 本质

* **数学思想方法**：**待定系数法**（由点求方程）、**数形结合**、**化归思想**。
* **高观点视域**：圆是平面上曲率为常数的特殊曲线。从解析几何看，圆方程是二元二次曲线的初级形态，揭示了二阶代数流形在欧几里得测度下的对称性特征。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

* **解题策略**：执行"几何要素先行 $\rightarrow$ 模板择优匹配 $\rightarrow$ 系数待定锁定"的 SOP。已知圆心与半径选"标准式"；已知圆上三点选"一般式"。
* **标准操作步骤（SOP）**：
  * **步骤 $1$ [选型]**：根据题目是给出几何特征（圆心、半径）还是点坐标，选择标准方程或一般方程模板。
  * **步骤 $2$ [列式]**：建立关于待定参数（$a, b, r$ 或 $D, E, F$）的方程组。
  * **步骤 $3$ [求解]**：解方程组并回代，注意对一般方程需核验 $D^2+E^2-4F>0$。

---

### 典型例题

#### 例题1（基础示范题）：
1. **题目**：求圆心为 $A(2, -3)$，且经过点 $M(5, -7)$ 的圆的标准方程。
2. **【结构与特征分析】**：形视识别入口为"圆心坐标 + 定点"。适用模板为圆的标准方程算子。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：提取圆心坐标 $(a, b) = (2, -3)$。
   * *决策*：计算圆心 $A$ 到点 $M$ 的距离，锁定半径 $r$。
   * *收敛*：代入标准方程模板 $(x-a)^2 + (y-b)^2 = r^2$。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [选型]]：选择标准方程模板 $(x-2)^2 + (y+3)^2 = r^2$。
   * [步骤 $2$ [列式计算]]：$r^2 = (5-2)^2 + (-7+3)^2 = 3^2 + (-4)^2 = 25$。
   * [步骤 $3$ [标准化输出]]：方程为 $(x-2)^2 + (y+3)^2 = 25$。
5. **【避坑提示】**：注意圆心纵坐标为 $-3$，代入方程后应为 $(y+3)^2$。
6. **结论**：$(x-2)^2 + (y+3)^2 = 25$。

#### 例题2（综合变式题）：
1. **题目**：求过三点 $O(0, 0), M_1(1, 1), M_2(4, 2)$ 的圆的方程。
2. **【结构与特征分析】**：形视识别入口为"圆上不共线三点"。适用模板为圆的一般方程算子，利用待定系数法求解。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：设一般方程模板 $x^2 + y^2 + Dx + Ey + F = 0$。
   * *决策*：将三点坐标分别代入，建立关于 $D, E, F$ 的三元一次方程组。
   * *分支*：由原点 $(0,0)$ 快速锁定 $F=0$ ➔ 降维为二元一次方程组求解 $D, E$。
   * *收敛*：得出各系数，并进行判别式校验。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [列方程组]]：$\begin{cases} F = 0 \\ 1+1+D+E+F = 0 \\ 16+4+4D+2E+F = 0 \end{cases} \implies \begin{cases} D+E = -2 \\ 4D+2E = -20 \end{cases}$。
   * [步骤 $2$ [求解]]：解得 $D = -8, E = 6$。
   * [步骤 $3$ [校验输出]]：$D^2+E^2-4F = 64+36-0 = 100 > 0$，符合。方程为 $x^2+y^2-8x+6y=0$。
5. **【避坑提示】**：求过三点圆方程时，切忌使用标准方程展开，计算量会激增。
6. **结论**：$x^2+y^2-8x+6y=0$。

### 巩固习题

##### 梯度一：基础达标
1. **题 $1$ **：求圆心为 $C(-3, 4)$，半径为 $\sqrt{5}$ 的圆的标准方程。
   *   **答案**：$(x+3)^2 + (y-4)^2 = 5$。步骤：直接代入标准公式。
2. **题 $2$ **：求圆 $x^2 + y^2 - 6x = 0$ 的圆心坐标和半径。
   *   **答案**：圆心 $(3, 0)$，半径 $3$。步骤：配方得 $(x-3)^2 + y^2 = 9$。

##### 梯度二：高考中档
3. **题 $3$ **：已知圆 $C$ 经过原点和点 $A(2, 1)$，圆心在直线 $x-2y-1=0$ 上，求圆 $C$ 的标准方程。
   *   **详细解析**：设圆心为 $(a, b)$。由 $|OC|=|AC|$ 得 $\sqrt{a^2+b^2} = \sqrt{(a-2)^2+(b-1)^2} \implies 4a+2b-5=0$。又圆心在直线上，有 $a-2b-1=0$。联立解得 $a=1.2, b=0.1$。半径 $r^2 = 1.45$。方程为 $(x-1.2)^2 + (y-0.1)^2 = 1.45$。
4. **题 $4$ **：判断点 $P(3, -6)$ 与圆 $(x-3)^2 + (y+2)^2 = 16$ 的位置关系。
   *   **详细解析**：代入 $(3-3)^2 + (-6+2)^2 = 0 + 16 = 16$。因等于半径平方，故点 $P$ 在圆上。

##### 梯度三：能力拔高
5. **题 $5$ **：已知线段 $AB$ 的端点 $B(4, 3)$，端点 $A$ 在圆 $(x+1)^2 + y^2 = 4$ 上运动，求线段 $AB$ 中点 $M$ 的轨迹方程。
   *   **思维破局**：坐标代换法。设 $M(x, y), A(x_0, y_0)$。利用中点公式 $x = \frac{x_0+4}{2}, y = \frac{y_0+3}{2}$ 将 $A$ 的坐标用 $M$ 的坐标表示，代入圆方程。
   *   **解析**：$x_0 = 2x-4, y_0 = 2y-3$。代入得 $(2x-4+1)^2 + (2y-3)^2 = 4 \implies (2x-3)^2 + (2y-3)^2 = 4 \implies (x-1.5)^2 + (y-1.5)^2 = 1$。
