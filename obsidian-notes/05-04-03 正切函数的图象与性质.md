# 正切函数的图象与性质
**教材**: 人教版必修第一册第五章 5.4.3 节

## 知识深度笔记

### 现象

*   **【情境锚定：从"连续波动"到"周期性断裂"的形态突变】**：
    *   **起因（背景与任务）**：在完成了正弦、余弦函数的研究后，我们需要对三角家族的第三个核心成员——正切函数 $y = \tan x$ 进行几何建模。
    *   **冲突（瓶颈与矛盾）**：正切函数与弦函数有本质不同。由于其定义中含有分母（横坐标 $x$），在 $\frac{\pi}{2} + k\pi$ 等点处会产生"除以零"的逻辑奇点，导致图象无法像正弦波那样一笔画成，而是呈现出被无数条垂直线隔开的离散支脉。
    *   **指向（概念诞生）**：通过建立**正切曲线协议（Tangent Curve Protocol）**，利用单位圆外的正切线（线段 $AT$）作为几何算子，将数值的剧烈爆发转化为向渐近线无限逼近的形态，实现了对"发散性"周期运动的数学刻画。

### 原因

*   **形成机制**：基于**正切线投影与诱导公式对称逻辑**。
    1.  **几何诱导**：在单位圆外的切线上，角 $x$ 对应的正切值等于切线段 $AT$ 的有向长度，当角趋近于 $\frac{\pi}{2}$ 时，交点 $T$ 迅速上移至无穷远处。
    2.  **周期锁定**：由 $\tan(x + \pi) = \tan x$ 可知其步长为 $\pi$，比弦函数短一半。
    3.  **奇偶约束**：由 $\tan(-x) = -\tan x$ 确定其图象关于原点对称。
*   **条件剖析**：自变量 $x$ 必须避开 $\frac{\pi}{2} + k\pi$。
    *   *反例*：若强行在 $x = \frac{\pi}{2}$ 处取值，由于此时终边在 $y$ 轴上，横坐标为 $0$，正切算子将因分母为 $0$ 而产生逻辑崩塌。

### 结果

*   **【核心公式提取（Formulas）】**：
    *   **正切图象算子**：$y = \tan x, x \in \{x | x \neq k\pi + \frac{\pi}{2}, k \in \mathbb{Z} \}$。
*   **【重要性质归纳（Properties）】**：
    1.  **周期契约**：最小正周期 $T = \pi$。
    2.  **渐近线协议**：直线 $x = k\pi + \frac{\pi}{2}$ 是其图象的禁区，曲线向其无限靠近而不触碰。
    3.  **全域单调性**：在每一个开区间 $(k\pi - \frac{\pi}{2}, k\pi + \frac{\pi}{2})$ 内均为增函数。
*   **【核心特点剖析（Characteristics）】**：
    *   **代数结构特征**：值域为 $\mathbb{R}$，没有最大值和最小值。
    *   **几何图像特征**：图象是由无数支形状相同的"发散曲线"组成。
*   **【要素拆解】**：
    *   【适用前提】：自变量在单支区间内连续。
    *   【核心结论】：单调性是分段的，不可跨越渐近线直接比较。
    *   【适用范围】：涉及频率翻倍的振荡系统及斜率计算。

### 应用

*   **学科内应用**：作为解三角不等式、研究复合正切函数单调区间的基础。
*   **跨学科/实际应用**：**物理光学中的视差计算**。在小角度近似下，$\tan \theta \approx \theta$，但在精密测量中，利用正切函数的爆发式增长特性可对远距离物体的微小位移进行高灵敏度捕捉。

### 本质

*   **数学思想方法**：**数形结合**（正切线几何 ↔ 代数函数）、**化归转化**（复杂周期 → 基本区间）。
*   **高观点视域**：正切函数是射影直线上的自同构。它将有限的角度区间映射为无限的实数轴，其渐近线本质上是射影平面上的"无穷远点"在仿射坐标系下的投影。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

*   **解题策略**：执行"一求定域（找渐近线）、二算周期（系数缩放）、三解不等式（锁定单调支）"的 SOP。在比较大小时，强制要求自变量"归位"到同一单支区间内。
*   **标准操作步骤（SOP）**：
    *   **步骤 $1$：[周期计算]** 利用 $T = \frac{\pi}{\omega}$ 确定重复步长。
    *   **步骤 $2$：[单调映射]** 令 $k\pi - \frac{\pi}{2} < \omega x + \phi < k\pi + \frac{\pi}{2}$。
    *   **步骤 $3$：[范围锁定]** 求解关于 $x$ 的不等式，输出对应单调区间。

---

### 典型例题

#### 例题1（基础性质示范题）：
**题目**：求函数 $y = \tan (2x - \frac{\pi}{4})$ 的定义域及最小正周期。

1.  **【结构与特征分析】**：形视识别入口为"复合正切结构"。$\omega = 2$ 引起周期减半，且存在初相平移。
2.  **【解题决策逻辑流（思维推演）】**：
    *   起点（源头）：禁区协议 $\omega x + \phi \neq k\pi + \frac{\pi}{2}$ ➔
    *   决策：$2x - \frac{\pi}{4} \neq k\pi + \frac{\pi}{2}$ ➔ 解出 $x \neq \frac{k\pi}{2} + \frac{3\pi}{8}$ ➔
    *   终点（收敛）：$T = \frac{\pi}{2}$。
3.  **【解析（对照 SOP 步骤）】**：定义域 $\{x | x \neq \frac{k\pi}{2} + \frac{3\pi}{8}, k \in \mathbb{Z}\}$，$T = \pi/2$。
4.  **【避坑提示】**：定义域必须写集合形式，不能漏掉 $k \in \mathbb{Z}$。
**结论**：定义域如上，周期 $\pi/2$。

#### 例题2（综合单调性变式题）：
**题目**：比较 $\tan (- \frac{13\pi}{4})$ 与 $\tan \frac{17\pi}{5}$ 的大小。

1.  **【结构与特征分析】**：形视识别入口为"大角正切比大小"。需利用周期性"归位"到同一单调区间。
2.  **【解题决策逻辑流（思维推演）】**：
    *   起点（源头）：周期性 $\tan (x + k\pi) = \tan x$ ➔
    *   $\tan (-13\pi/4) = \tan (-\pi/4) = -1$ ➔
    *   $\tan (17\pi/5) = \tan (2\pi/5)$ ➔
    *   终点（收敛）：$-\pi/2 < -\pi/4 < 2\pi/5 < \pi/2$，递增 → $\tan(-\pi/4) < \tan(2\pi/5)$。
3.  **【解析（对照 SOP 步骤）】**：$\tan(-13\pi/4) < \tan(17\pi/5)$。
4.  **【避坑提示】**：严禁跨越渐近线直接套用增减性。
**结论**：$\tan (-13\pi/4) < \tan (17\pi/5)$。

### 巩固习题

##### 梯度一：基础达标
1.  **题 $1$ **：正切函数 $y = \tan x$ 对称中心坐标集合为 $(\frac{k\pi}{2}, 0), k \in \mathbb{Z}$。
2.  **题 $2$ **：$y = \tan \frac{x}{3}$ 的周期 $T = 3\pi$。

##### 梯度二：高考中档
3.  **题 $3$ **：$y = \tan (x + \frac{\pi}{3})$ 单调增区间：$(k\pi - \frac{5\pi}{6}, k\pi + \frac{\pi}{6})$。
4.  **题 $4$ **：$\tan x \ge \sqrt{3}$ 在 $(-\pi/2, \pi/2)$ 内：$x \in [\pi/3, \pi/2)$。

##### 梯度三：能力拔高
5.  **题 $5$ **：相邻渐近线 $x = \pi/6$ 和 $x = 2\pi/3$ → $T = \pi/2$ → $\omega = 2$。过点 $(\pi/3, 0)$ → $\phi = \pi/3$。$f(x) = \tan(2x + \pi/3)$。
