# 空间向量及其运算的坐标表示
**教材**: 人教版选择性必修第一册第一章 1.3 节

## 知识深度笔记

### 现象
* **【情境锚定：从"纯几何推演"到"数字精确控制"的逻辑合流】**：
  1. **起因（背景与任务）**：虽然空间向量基本定理提供了基底分解的逻辑，但在处理复杂的建筑结构（如大跨度网壳）或航天对接时，纯几何的向量合成仍需依赖复杂的图形想象。
  2. **冲突（瓶颈与矛盾）**：几何法（找基底、画平行六面体）在处理非对称图形或高精度度量（如夹角、距离）时，推理链条过长，极易产生视觉误差，且无法通过计算机程序实现自动化证明。
  3. **指向（概念诞生）**：通过在空间中建立**单位正交基底**，数学家建立了**空间直角坐标系（Space Rectangular Coordinate System）**。它将向量的物理指向转化为三元有序实数对 $(x, y, z)$，标志着空间几何彻底进入了"数字化计算"时代。

### 原因
* **形成机制**：基于**单位正交基底 $\{\vec{i}, \vec{j}, \vec{k}\}$ ** 的唯一分解。由于 $\vec{i}, \vec{j}, \vec{k}$ 两两垂直且长度为 $1$，空间任意向量 $\vec{a}$ 可唯一表示为 $\vec{a} = x\vec{i} + y\vec{j} + z\vec{k}$。这组有序实数 $(x, y, z)$ 即为向量的坐标。
* **条件剖析**：坐标系必须满足**右手直角坐标系**规则：右手拇指指向 $x$ 轴正向，食指指向 $y$ 轴正向，中指指向 $z$ 轴正向。
    * *反例*：若基底不互相垂直，则坐标运算将失去 $\vec{i} \cdot \vec{j} = 0$ 的简化特性，导致数量积公式失效。

### 结果
* **【核心公式提取（Formulas）】**：
  * **线性运算算子**：$\vec{a} \pm \vec{b} = (a_1 \pm b_1, a_2 \pm b_2, a_3 \pm b_3)$；$\lambda \vec{a} = (\lambda a_1, \lambda a_2, \lambda a_3)$。
  * **数量积与度量算子**：
    * $\vec{a} \cdot \vec{b} = a_1b_1 + a_2b_2 + a_3b_3$。
    * $|\vec{a}| = \sqrt{a_1^2 + a_2^2 + a_3^2}$。
    * $d_{P_1P_2} = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$。
* **【重要性质归纳（Properties）】**：
  1. **位置判定**：$\vec{a} \parallel \vec{b} \iff a_1 = \lambda b_1, a_2 = \lambda b_2, a_3 = \lambda b_3$；$\vec{a} \perp \vec{b} \iff a_1b_1 + a_2b_2 + a_3b_3 = 0$。
  2. **夹角余弦**：$\cos \langle \vec{a}, \vec{b} \rangle = \frac{a_1b_1 + a_2b_2 + a_3b_3}{\sqrt{a_1^2 + a_2^2 + a_3^2}\sqrt{b_1^2 + b_2^2 + b_3^2}}$。
* **【核心特点剖析（Characteristics）】**：
  * *代数结构特征*：空间向量坐标等于终点坐标减去起点坐标。
  * *几何图像特征*：坐标是向量在三个坐标轴上的投影分量。
  * *符号特征*：注意区分点坐标 $A(x, y, z)$ 与向量坐标 $\vec{a} = (x, y, z)$ 的书写语境。
* **【要素拆解】**：
  * 【适用前提】：已建立单位正交的空间直角坐标系。
  * 【核心结论】：将几何关系（平行、垂直、角度、距离）完全"代数化"。
  * 【适用范围/边界】：零向量 $\vec{0} = (0, 0, 0)$ 与任意向量垂直或平行的代数判定需注意分母不为 $0$。

### 应用
* **学科内应用**：为后续"利用法向量求二面角"和"点到平面距离"提供底层的运算工具。
* **跨学科/实际应用**：**机器人路径规划**。通过建立 $3D$ 空间坐标系，计算机械臂末端执行器的实时位姿向量与目标点的欧氏距离。

### 本质
* **数学思想方法**：**化归思想**（几何空间 $\to$ 实数空间）与**数学机械化**。
* **高观点视域**：坐标法将欧几里得空间 $E^3$ 映射为实数三元组空间 $\mathbb{R}^3$。它证明了空间结构不仅是直观的，更是可以被"算术化"的线性代数对象。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤
* **解题策略**：执行"建系 $\to$ 向量化 $\to$ 运算 $\to$ 翻译"的坐标法四步走。
* **标准操作步骤（SOP）**：
  * **步骤 $1$ [建系表点]**：选择图形中垂直关系最丰富的点为原点，写出各关键点的坐标。
  * **步骤 $2$ [向量转化]**：根据"终点坐标减起点坐标"得出目标向量的坐标。
  * **步骤 $3$ [执行运算]**：应用数量积（求垂直/夹角）或距离公式（求长度）。

---

### 典型例题
#### 例题1（基础示范题）：
1. **题目**：已知向量 $\vec{a} = (-3, 2, 5)$, $\vec{b} = (1, 5, -1)$。求：$(1) 3\vec{a} - \vec{b}$；$(2) \vec{a} \cdot \vec{b}$；$(3) |\vec{a}|$。
2. **【结构与特征分析】**：形视识别入口为"向量的显式分量表示"。直接考察线性运算、数量积及模长的坐标定义。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：提取向量分量 $a_i, b_i$。
   * *分支*：针对 $(1)$ 执行分量数乘及作差；针对 $(2)$ 执行分量乘积求和；针对 $(3)$ 执行分量平方和开方。
   * *终点*：得出标量或三元组结果。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [线性运算]]：$3(-3, 2, 5) - (1, 5, -1) = (-9-1, 6-5, 15+1) = (-10, 1, 16)$。
   * [步骤 $2$ [数量积]]：$(-3) \times 1 + 2 \times 5 + 5 \times (-1) = -3 + 10 - 5 = 2$。
   * [步骤 $3$ [模长计算]]：$\sqrt{(-3)^2 + 2^2 + 5^2} = \sqrt{9 + 4 + 25} = \sqrt{38}$。
5. **【避坑提示】**：作差时注意分量中的负号（如 $15 - (-1) = 16$）。
6. **结论**：$(1) (-10, 1, 16)$；$(2) 2$；$(3) \sqrt{38}$。

#### 例题2（综合变式题）：
1. **题目**：在棱长为 $1$ 的正方体 $ABCD-A_1B_1C_1D_1$ 中，$M$ 为 $BC_1$ 的中点。求 $A M$ 的长。
2. **【结构与特征分析】**：形视识别入口为"正方体内的距离度量"。需将几何长度转化为向量模长计算。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：建立空间直角坐标系。
   * *决策*：锁定顶点 $A$ 和中点 $M$ 的坐标。
   * *分支*：求得中点 $M$ 坐标 ➔ 利用终点减起点得出 $\vec{AM}$。
   * *收敛*：应用空间两点距离公式或向量模长公式。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [建系表点]]：以 $D$ 为原点建立坐标系。$A(1, 0, 0)$，$B(1, 1, 0)$，$C_1(0, 1, 1)$。
   * [步骤 $2$ [中点转化]]：$M$ 坐标为 $(\frac{1+0}{2}, \frac{1+1}{2}, \frac{0+1}{2}) = (\frac{1}{2}, 1, \frac{1}{2})$。
   * [步骤 $3$ [距离计算]]：$AM = \sqrt{(\frac{1}{2}-1)^2 + (1-0)^2 + (\frac{1}{2}-0)^2} = \sqrt{\frac{1}{4} + 1 + \frac{1}{4}} = \frac{\sqrt{6}}{2}$。
5. **【避坑提示】**：注意 $M$ 是 $BC_1$ 的中点，其纵坐标应由 $B, C_1$ 的纵坐标平均值得出。
6. **结论**：$\frac{\sqrt{6}}{2}$。

### 巩固习题
##### 梯度一：基础达标
1. **题 $1$ **：已知 $\vec{a} = (2, -1, 3)$, $\vec{b} = (-4, 2, x)$。若 $\vec{a} \perp \vec{b}$，则 $x =$ ____。
   *   **答案**：$x = \frac{10}{3}$。解析：$2 \times (-4) + (-1) \times 2 + 3x = 0 \implies -10 + 3x = 0$。
2. **题 $2$ **：点 $A(3, 4, 5)$ 在坐标平面 $xOy$ 内的射影 $B$ 到原点的距离为？
   *   **答案**：$5$。解析：$B(3, 4, 0)$，$|OB| = \sqrt{3^2 + 4^2} = 5$。

##### 梯度二：高考中档
3. **题 $3$ **：在正方体 $ABCD-A_1B_1C_1D_1$ 中，$M$ 是 $AB$ 的中点，求 $D B_1$ 与 $C M$ 所成角的余弦值。
   *   **详细解析**：建系，设棱长为 $2$。$D(0, 0, 0), B_1(2, 2, 2) \implies \vec{DB_1} = (2, 2, 2)$；$C(0, 2, 0), M(2, 1, 0) \implies \vec{CM} = (2, -1, 0)$。$\cos \theta = \frac{4-2+0}{\sqrt{12} \times \sqrt{5}} = \frac{2}{2\sqrt{3} \times \sqrt{5}} = \frac{\sqrt{15}}{15}$。
4. **题 $4$ **：已知 $A(3, 5, -7)$, $B(-2, 4, 3)$，求线段 $A B$ 的中点坐标及长度。
   *   **详细解析**：中点 $(\frac{3-2}{2}, \frac{5+4}{2}, \frac{-7+3}{2}) = (0.5, 4.5, -2)$；$|AB| = \sqrt{(3+2)^2 + (5-4)^2 + (-7-3)^2} = \sqrt{25+1+100} = \sqrt{126} = 3\sqrt{14}$。

##### 梯度三：能力拔高
5. **题 $5$ **：已知 $\{\vec{a}, \vec{b}, \vec{c}\}$ 是单位正交基底，$\vec{p} = \vec{a} + 2\vec{b} + 3\vec{c}$。若用新基底 $\{\vec{a}+\vec{b}, \vec{a}-\vec{b}, \vec{c}\}$ 表示 $\vec{p}$，系数分别为多少？
   *   **思维破局**：设 $\vec{p} = x(\vec{a}+\vec{b}) + y(\vec{a}-\vec{b}) + z\vec{c}$，展开后根据对应分量相等建立方程组。
   *   **解析**：$\vec{p} = (x+y)\vec{a} + (x-y)\vec{b} + z\vec{c}$。对照 $\vec{p} = (1, 2, 3)$，得 $x+y=1, x-y=2, z=3$。解得 $x=1.5, y=-0.5, z=3$。
