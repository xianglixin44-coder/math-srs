# 两角和与差的正弦、余弦和正切公式
**教材**: 人教版必修第一册第五章 5.5.1 节

## 知识深度笔记

### 现象

*   **【情境锚定：从"特殊偏角"到"任意角组合"的逻辑泛化】**：
    *   **起因（背景与任务）**：诱导公式已经解决了 $\frac{k\pi}{2} \pm \alpha$ 形式的三角函数化简。然而，在研究物理简谐运动的叠加或计算如 $\cos 15^{\circ}$ 这种非轴线关联的角时，任务变得复杂。
    *   **冲突（瓶颈与矛盾）**：旧有的诱导公式协议本质上是"角与坐标轴"的对称性。当面对两个独立变量 $\alpha$ 与 $\beta$ 的和或差时，三角函数并不具备线性分配律（即 $\cos(\alpha - \beta) \neq \cos \alpha - \cos \beta$）。这种逻辑断层限制了数学处理复杂波形叠加的能力。
    *   **指向（概念诞生）**：通过建立**两角和差协议（Sum and Difference Identities Protocol）**，利用单位圆的旋转对称性，将合成角的三角函数映射为原始角函数值的代数组合，实现了三角变换从"静态平移"向"动态合成"的跨越。

### 原因

*   **形成机制**：基于**单位圆旋转对称性与距离守恒逻辑**。
    1.  **坐标映射**：在单位圆上，角 $\alpha$、$\beta$、$\alpha - \beta$ 分别对应点 $P_1(\cos \alpha, \sin \alpha)$、 $A_1(\cos \beta, \sin \beta)$ 及 $P(\cos(\alpha - \beta), \sin(\alpha - \beta))$。
    2.  **几何等效**：由于圆的旋转对称性，弧 $AP$ 与弧 $A_1P_1$ 相等，对应的弦长 $|AP| = |A_1P_1|$。
    3.  **解析推导**：利用两点间距离公式展开 $|AP|^2 = |A_1P_1|^2$，经过代数坍缩导出余弦差角公式。
*   **条件剖析**：公式对任意实数角 $\alpha, \beta$ 均成立，但正切公式需满足分母不为零。
    *   *反例*：若 $\tan \alpha \cdot \tan \beta = 1$，则 $\tan(\alpha + \beta)$ 无意义。

### 结果

*   **【核心公式提取（Formulas）】**：
    *   **余弦和差**：$\cos(\alpha \mp \beta) = \cos \alpha \cos \beta \pm \sin \alpha \sin \beta$。
    *   **正弦和差**：$\sin(\alpha \pm \beta) = \sin \alpha \cos \beta \pm \cos \alpha \sin \beta$。
    *   **正切和差**：$\tan(\alpha \pm \beta) = \frac{\tan \alpha \pm \tan \beta}{1 \mp \tan \alpha \tan \beta}$。
    *   **倍角协议**：$\sin 2\alpha = 2 \sin \alpha \cos \alpha$；$\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha$；$\tan 2\alpha = \frac{2 \tan \alpha}{1 - \tan^2 \alpha}$。
*   **【重要性质归纳（Properties）】**：
    1.  **结构对称性**：余弦公式为"同名积之和差"，正弦公式为"异名积之和差"。
    2.  **符号交错律**：余弦和差符号与括号内相反，正弦和差符号与括号内相同。
    3.  **倍角降幂性**：利用 $\cos 2\alpha$ 的变式 $1 + \cos 2\alpha = 2 \cos^2 \alpha$ 可实现降幂化简。
*   **【核心特点剖析（Characteristics）】**：
    *   **代数结构特征**：建立了单角与多角之间的线性化映射。
    *   **符号特征**：注意 $\tan(\alpha \pm \beta)$ 分母中的符号反转。
*   **【要素拆解】**：
    *   【适用前提】：角必须是实数，且使相关函数有意义。
    *   【核心结论】：复角运算可降维为单角代数运算。

### 应用

*   **学科内应用**：作为证明半角公式、积化和差、和差化积以及解斜三角形的底层协议。
*   **跨学科/实际应用**：**信号调制与解调**。在通信工程中，载波信号的乘法运算通过和差化积公式可分解为两个频率之和与差的分量，是收音机选台滤波的理论基础。

### 本质

*   **数学思想方法**：**化归转化**（复角 → 单角）、**数形结合**（单位圆旋转 → 代数恒等式）。
*   **高观点视域**：这些公式本质上是复数域乘法算子 $e^{i(\alpha \pm \beta)} = e^{i\alpha} e^{\pm i\beta}$ 在实部与虚部上的分投影。它揭示了欧几里得平面的旋转群 $SO(2)$ 的代数同构结构。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤

*   **解题策略**：执行"一看角、二看名、三看式、四看号"的变换 SOP。优先进行"变角"操作（寻找已知角与未知角之间的倍数、和差关系），其次执行"变名"（切化弦）。
*   **标准操作步骤（SOP）**：
    *   **步骤 $1$：[角关系析出]** 观察目标角是否能表示为 $\alpha \pm \beta$ 或 $2\alpha$ 的形式。
    *   **步骤 $2$：[公式适配]** 根据函数名及和差符号选择对应的恒等式。
    *   **步骤 $3$：[值域校验]** 计算各分项函数值时，务必根据象限锁定正负号。

---

### 典型例题

#### 例题1（基础求值示范题）：
**题目**：利用和差角公式求 $\cos 15^{\circ}$ 的值。

1.  **【结构与特征分析】**：形视识别入口为"非特殊角"。$15^{\circ} = 45^{\circ} - 30^{\circ}$。
2.  **【解题决策逻辑流（思维推演）】**：
    *   起点（源头）：角的关系拆解 ➔
    *   分支（决策）：调用差角余弦公式 $C_{(\alpha - \beta)}$ ➔
    *   决策（代入）：代入特殊角的正余弦函数值 ➔
    *   终点（收敛）：$\cos 15^{\circ} = \frac{\sqrt{6} + \sqrt{2}}{4}$。
3.  **【解析（对照 SOP 步骤）】**：$\cos(45^{\circ} - 30^{\circ}) = \cos 45^{\circ} \cos 30^{\circ} + \sin 45^{\circ} \sin 30^{\circ} = \frac{\sqrt{6} + \sqrt{2}}{4}$。
4.  **【避坑提示】**：$C_{(\alpha - \beta)}$ 展开中间符号为"$+$"。
**结论**：$\frac{\sqrt{6} + \sqrt{2}}{4}$。

#### 例题2（综合变角变式题）：
**题目**：已知 $\sin \alpha = 4/5, \alpha \in (\pi/2, \pi)$，$\cos \beta = -5/13$，$\beta$ 是第三象限角，求 $\cos(\alpha - \beta)$。

1.  **【结构与特征分析】**：形视识别入口为"已知单角函数值求复角"。核心难点在于反求全属性正余弦值。
2.  **【解题决策逻辑流（思维推演）】**：
    *   起点（源头）：二象限 $\cos \alpha < 0$，三象限 $\sin \beta < 0$ ➔
    *   决策：$\cos \alpha = -3/5$，$\sin \beta = -12/13$ ➔
    *   终点（收敛）：$\cos(\alpha - \beta) = (-3/5)(-5/13) + (4/5)(-12/13) = -33/65$。
3.  **【解析（对照 SOP 步骤）】**：$\cos(\alpha - \beta) = -33/65$。
4.  **【避坑提示】**：开方时必须严格依据象限判定正负号。
**结论**：$-33/65$。
