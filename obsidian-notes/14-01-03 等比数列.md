# 等比数列
**教材**: 人教版选择性必修第二册第四章 4.3 节

## 知识深度笔记

### 现象
* **【情境锚定：从"一尺之棰"到"指数爆炸"的几何倍增】**：
  1. **起因（背景与任务）**：在研究古巴比伦泥版上的幂次记录、庄子描述的"日取其半"的木棰演变，以及实验室中细菌每 $20$ 分钟分裂一代的过程时，我们需要描述一种特殊的演化规律。
  2. **冲突（瓶颈与矛盾）**：等差数列的"线性累加"逻辑无法解释细胞数量为何能在短时间内呈几何级数增长，也无法精确计算复利模式下（利滚利）财富的积累速度，旧的加法算子在面对"倍数锁定"时显得无能为力。
  3. **指向（概念诞生）**：通过建立**等比数列（Geometric Progression）协议**，将几何上的"相似放大"映射为代数上的"恒定比值"，标志着数学获得了处理"倍增/半减离散变化"的标准模型。

### 原因
* **形成机制**：基于**比值守恒逻辑**。定义从第 $2$ 项起，每一项与前一项的比都等于同一个常数 $q$。其递推原型为 $a_{n+1} = a_n \cdot q$。
* **条件剖析**：公比 $q$ 必须满足 $q \neq 0$，且数列项 $a_n$ 恒不为 $0$。
    * *反例*：数列 $1, 0, 0, \dots$ 虽然看起来有规律，但因为项中出现了 $0$，无法计算比值，不属于等比数列协议范围。

### 结果
* **【核心公式提取（Formulas）】**：
  * **通项公式算子**：$a_n = a_1 q^{n-1}$。
  * **前 $n$ 项和算子**：
    * 当 $q = 1$ 时，$S_n = na_1$。
    * 当 $q \neq 1$ 时，$S_n = \frac{a_1(1-q^n)}{1-q} = \frac{a_1-a_n q}{1-q}$。
* **【重要性质归纳（Properties）】**：
  1. **等比中项协议**：若 $a, G, b$ 成等比数列，则 $G^2 = ab$（注意 $a, b$ 必须同号）。
  2. **下标和联动**：若 $m+n = p+q$，则 $a_m \cdot a_n = a_p \cdot a_q$。
  3. **和的结构性质**：当 $q \neq -1$ 时，$S_n, S_{2n}-S_n, S_{3n}-S_{2n}$ 仍成等比数列。
* **【核心特点剖析（Characteristics）】**：
  * *代数结构特征*：通项是关于 $n$ 的指数型函数；求和涉及"错位相减"技术。
  * *几何图像特征*：图象分布在指数函数 $y = \frac{a_1}{q} \cdot q^x$ 的图象上。
  * *符号特征*：$q < 0$ 时为摆动数列；$0 < q < 1$ 且 $a_1 > 0$ 时为递减数列。
* **【要素拆解】**：
  * 【适用前提】：相邻项之比为非零常数。
  * 【核心结论】：等比数列是指数函数在正整数域的采样。
  * 【适用范围/边界】：求和公式必须对 $q=1$ 和 $q \neq 1$ 进行强制分支讨论。

### 应用
* **学科内应用**：求解含指数幂的复杂数列求和、分形几何周期的计算。
* **跨学科/实际应用**：**金融复利与理财预测**。计算储蓄卡复利计息或分期付款中的现值与终值。

### 本质
* **数学思想方法**：**错位相减法**（求和的核心逻辑）与**化归思想**（利用对数将等比化为等差）。
* **高观点视域**：等比数列是一阶齐次线性差分方程的解。它揭示了离散世界中"增长率守恒"的深层动力学平衡。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤
* **解题策略**：奉行"基本量优先"与"分类讨论"原则。处理 $S_n$ 问题时，第一直觉必须是判断 $q$ 是否可能等于 $1$。
* **标准操作步骤（SOP）**：
  * **步骤 $1$ [锁定 $q$]**：由 $a_n/a_{n-1}$ 或联立方程确定公比，优先判定 $q$ 是否为 $1$。
  * **步骤 $2$ [基本量映射]**：将已知项转化为 $a_1$ 和 $q$ 的表达式。
  * **步骤 $3$ [执行公式]**：应用通项公式 $a_n = a_1q^{n-1}$ 或求和公式 $S_n$ 求解。

---

### 典型例题
#### 例题1（基础示范题）：
1. **题目**：已知等比数列 $\{a_n\}$ 的第 $4$ 项和第 $6$ 项分别为 $48$ 和 $12$，求 $\{a_n\}$ 的第 $5$ 项。
2. **【结构与特征分析】**：形视识别入口为"已知奇数间隔项"。利用等比中项协议 $a_5^2 = a_4 a_6$ 可快速切入。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：提取等比中项定义。
   * *分支*：由于是偶次方根 ➔ 产生正负两个解（摆动数列的可能性）。
   * *收敛*：计算乘积并开方。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [性质套用]]：根据 $a_5$ 是 $a_4$ 与 $a_6$ 的等比中项，有 $a_5^2 = a_4 a_6$。
   * [步骤 $2$ [代数计算]]：$a_5^2 = 48 \times 12 = 576$。
   * [步骤 $3$ [结果锁定]]：$a_5 = \pm \sqrt{576} = \pm 24$。
5. **【避坑提示】**：求等比中项时极易漏掉负值，除非题目明确说明数列各项均为正。
6. **结论**：$a_5$ 为 $24$ 或 $-24$。

#### 例题2（综合变式题）：
1. **题目**：已知等比数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，若 $S_{10}/S_5 = 31/32$，求公比 $q$。
2. **【结构与特征分析】**：形视识别入口为"和的比例特征"。涉及 $S_n$ 公式的结构化简，核心在于因式分解。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：**强制校验**：判断 $q=1$ 是否成立 ➔ $S_{10}/S_5 = 2 \neq 31/32$ ➔ 确定 $q \neq 1$。
   * *决策*：代入 $q \neq 1$ 时的求和公式。
   * *分支*：化简比例式 $\frac{a_1(1-q^{10})}{1-q} \cdot \frac{1-q}{a_1(1-q^5)}$ ➔ 提取 $(1+q^5)$ 项。
   * *收敛*：解关于 $q^5$ 的幂方程。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [分支判定]]：若 $q=1$，比值为 $2$，不符，故 $q \neq 1$。
   * [步骤 $2$ [公式化简]]：$\frac{1-q^{10}}{1-q^5} = 1 + q^5 = \frac{31}{32}$。
   * [步骤 $3$ [幂运算]]：$q^5 = \frac{31}{32} - 1 = -\frac{1}{32} \implies q = -1/2$。
5. **【避坑提示】**：若不进行 $q=1$ 的预校验，在复杂的题目中可能导致漏解或逻辑分值丢失。
6. **结论**：$q = -1/2$。

### 巩固习题
##### 梯度一：基础达标
1. **题 $1$ **：在等比数列 $\{a_n\}$ 中，$a_1 = 3, q = 2$，则 $S_6 =$ ____。
   *   **答案**：$189$。解析：$S_6 = \frac{3(1-2^6)}{1-2} = 3(64-1) = 189$。
2. **题 $2$ **：已知 $4, G, 16$ 成等比数列，则 $G = $ ____。
   *   **答案**：$\pm 8$。解析：$G^2 = 64 \implies G = \pm 8$。

##### 梯度二：高考中档
3. **题 $3$ **：已知等比数列 $\{a_n\}$ 满足 $a_1 a_3 = 1/4, a_2 + a_4 = 5/8$，求其通项公式。
   *   **详细解析**：由 $a_1 a_3 = a_2^2 = 1/4 \implies a_2 = \pm 1/2$。当 $a_2 = 1/2$ 时，$a_4 = 1/8 \implies q^2 = 1/4 \implies q = \pm 1/2$。带回校验得 $a_n = (1/2)^n$ 等解。
4. **题 $4$ **：在等比数列 $\{a_n\}$ 中，$S_3 = 9/2, a_3 = 3/2$，求 $a_1$ 与 $q$。
   *   **详细解析**：代入 $a_1(1+q+q^2)=9/2$ 与 $a_1q^2=3/2$。相除得 $q^2/(1+q+q^2)=1/3 \implies 2q^2-q-1=0$。解得 $q=1$ 或 $q=-1/2$。

##### 梯度三：能力拔高
5. **题 $5$ **：设数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，若 $S_n = 2a_n + 1$，证明 $\{a_n\}$ 是等比数列并求其通项公式。
   *   **思维破局**：利用 $a_n = S_n - S_{n-1}$ 消除 $S_n$。
   *   **解析**：当 $n \ge 2$ 时，$a_n = (2a_n + 1) - (2a_{n-1} + 1) \implies a_n = 2a_n - 2a_{n-1} \implies a_n = 2a_{n-1}$。又 $a_1 = S_1 = 2a_1 + 1 \implies a_1 = -1$。首项非零且比值为常数，故为等比数列。$a_n = -1 \cdot 2^{n-1} = -2^{n-1}$。
