# 正弦函数、余弦函数的性质
**教材**: 人教版必修第一册第五章 5.4.2 节

## 知识深度笔记

### 现象
*   **【情境锚定：从"视觉波形"到"代数协议"的精确合围】**：
    *   **起因（背景与任务）**：在完成正弦、余弦曲线的绘制后，我们能直观看到图象在"上升"、"下降"和"往复运动"。
    *   **冲突（瓶颈与矛盾）**：纯粹的视觉观察无法提供精确的判定准则。例如，对于 $y = \sin (2x + \frac{\pi}{3})$，仅凭肉眼无法确定它在具体哪个区间内递增，也无法量化其循环一次的确切"步长"。
    *   **指向（概念诞生）**：通过建立**三角性质协议（Trigonometric Properties Protocol）**，将周期性、单调性、奇偶性和最值转化为严密的代数不等式与等式约束，实现了对周期运动的定量分析。

### 原因
*   **形成机制**：基于**单位圆的对称性与周期重合逻辑**。
    1.  **周期源起**：终边相同角的三角函数值相等，决定了函数值随角度增加 $2\pi$ 而重复，形成周期性。
    2.  **对称诱导**：单位圆关于坐标轴及原点的对称性，通过诱导公式直接映射为函数的奇偶性协议。
    3.  **投影升降**：动点 $P$ 在单位圆上旋转时，其纵、横坐标的连续变动决定了函数在特定区间的增减。
*   **条件剖析**：单调区间的判定必须基于"整体代换"的前提。
    *   *反例*：在求 $y = \sin (-x)$ 的单调增区间时，若直接套用 $y = \sin x$ 的结论而不考虑自变量系数的正负，将导致增减性判定的彻底反转。

### 结果
*   **【核心公式提取（Formulas）】**：
    *   **周期协议**：$f(x + T) = f(x)$；$y = A \sin (\omega x + \phi)$ 的最小正周期 $T = \frac{2\pi}{\omega} (\omega > 0)$。
    *   **奇偶性算子**：$\sin (-x) = -\sin x$（奇）；$\cos (-x) = \cos x$（偶）。
*   **【重要性质归纳（Properties）】**：
    1.  **值域契约**：$| \sin x | \le 1, | \cos x | \le 1$。
    2.  **单调区间（基准）**：$\sin x$ 增区间 $[-\frac{\pi}{2} + 2k\pi, \frac{\pi}{2} + 2k\pi]$；减区间 $[\frac{\pi}{2} + 2k\pi, \frac{3\pi}{2} + 2k\pi]$。$\cos x$ 增区间 $[-\pi + 2k\pi, 2k\pi]$；减区间 $[2k\pi, \pi + 2k\pi]$。
*   **【核心特点剖析（Characteristics）】**：
    *   **代数结构特征**：利用"整体思想"，将 $\omega x + \phi$ 视为一个复合算子进行区间映射。
    *   **几何图像特征**：周期反映波长的疏密，最值反映波峰波谷的高度，对称性反映波形的镜像规律。
*   **【要素拆解】**：
    *   【适用前提】：函数必须处于标准定义域内且 $\omega \ne 0$。
    *   【核心结论】：单调性与最值是周期性的局部切片表现。

### 应用
*   **学科内应用**：作为研究 $y = A \sin (\omega x + \phi)$ 综合图象变换与物理简谐运动性质的理论核心。
*   **跨学科/实际应用**：**潮汐预报模型**。利用 $y = A \sin (\omega x + \phi) + h$ 刻画港口水深随时间的周期性波动，通过计算单调性区间确定船只进出港的安全窗口。

### 本质
*   **数学思想方法**：**整体代换思想**（由简单到复合）、**数形结合**（图象辅助代数判定）。
*   **高观点视域**：三角函数的性质本质上是有限群在圆周轨道上的连续作用。它揭示了时间平移对称性（周期性）与空间反射对称性（奇偶性）在解析表达上的高度统一。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤
*   **解题策略**：执行"一化（化为标准型）、二代（整体代换）、三解（解不等式）、四还原（求出 $x$ 区间）"的 SOP。
*   **标准操作步骤（SOP）**：
    *   **步骤 $1$：[结构标准化]** 确保 $\omega > 0$（若为负则利用奇偶性转化），整理为 $y = A \sin (\omega x + \phi)$。
    *   **步骤 $2$：[整体换元]** 令 $z = \omega x + \phi$。
    *   **步骤 $3$：[性质映射]** 将 $z$ 置于基元函数的单调或最值已知区间内。
    *   **步骤 $4$：[变量还原]** 求解关于 $x$ 的不等式，标注 $k \in \mathbb{Z}$。

---

### 典型例题
#### 例题1（基础比大小示范题）：
**题目**：不通过求值，比较 $\sin (-\frac{\pi}{18})$ 与 $\sin (-\frac{\pi}{10})$ 的大小。

1.  **【结构与特征分析】**：形视识别入口为"同名三角函数值的位序比较"。
2.  **【解题决策逻辑流（思维推演）】**：
    *   起点（源头）：正弦在 $[-\frac{\pi}{2}, \frac{\pi}{2}]$ 上单调递增 ➔
    *   决策：$-\frac{\pi}{2} < -\frac{\pi}{10} < -\frac{\pi}{18} < \frac{\pi}{2}$ ➔
    *   终点（收敛）：$\sin (-\frac{\pi}{10}) < \sin (-\frac{\pi}{18})$。
3.  **【解析（对照 SOP 步骤）】**：均在增区间内，序关系保持。
4.  **【避坑提示】**：若自变量不在同一单调区间，必须先诱导公式转换。
**结论**：$\sin (-\frac{\pi}{18}) > \sin (-\frac{\pi}{10})$。

#### 例题2（综合单调性变式题）：
**题目**：求函数 $y = \sin (\frac{1}{2} x + \frac{\pi}{3})$ 在 $x \in [-2\pi, 2\pi]$ 上的单调递增区间。

1.  **【结构与特征分析】**：形视识别入口为"复合正弦函数的局部单调性"。
2.  **【解题决策逻辑流（思维推演）】**：
    *   起点（源头）：基准增区间 $[-\frac{\pi}{2} + 2k\pi, \frac{\pi}{2} + 2k\pi]$ ➔
    *   整体代换：$-\frac{\pi}{2} + 2k\pi \le \frac{1}{2} x + \frac{\pi}{3} \le \frac{\pi}{2} + 2k\pi$ ➔
    *   求解：两边同乘 $2$ 得 $-\frac{5\pi}{3} + 4k\pi \le x \le \frac{\pi}{3} + 4k\pi$ ➔
    *   终点（收敛）：取 $k=0$ 得 $[-\frac{5\pi}{3}, \frac{\pi}{3}]$。
3.  **【解析（对照 SOP 步骤）】**：递增区间为 $[-\frac{5\pi}{3}, \frac{\pi}{3}]$。
4.  **【避坑提示】**：必须标注 $k \in \mathbb{Z}$；$\omega < 0$ 时需先利用奇偶性反转方向。
**结论**：单调递增区间为 $[-\frac{5\pi}{3}, \frac{\pi}{3}]$。
