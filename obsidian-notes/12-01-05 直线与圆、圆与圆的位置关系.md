# 直线与圆、圆与圆的位置关系
**教材**: 人教版选择性必修第一册第二章 2.5 节

## 知识深度笔记

### 现象
* **【情境锚定：从"静态几何"到"动态干涉"的逻辑合成】**：
  1. **起因（背景与任务）**：在研究赵州桥的圆拱支撑支柱（支柱位置与拱圈的接触点）或轮船返港避开环岛暗礁（航线与危险区域边缘的交切情况）时，孤立的图形方程已无法描述物体间的相互作用。
  2. **冲突（瓶颈与矛盾）**：初中的直观观察（如"看起来相切"）缺乏代数运算的支撑，无法在含有参数或高精度要求的工程设计中给出"交点坐标"或"公共区域大小"的精确解。
  3. **指向（概念诞生）**：通过建立**位置关系判定协议**，将几何上的"交点个数"与代数上的"方程组解的个数"或"测度偏差"挂钩，标志着解析几何进入了多对象耦合的研究阶段。

### 原因
* **形成机制**：基于**判别式逻辑**与**测度对比逻辑**。
    * **代数路经**：联立方程组，利用二次方程判别式 $\Delta$ 判定解的个数。
    * **几何路径**：计算圆心到直线的距离 $d$（或两圆心距 $d_{C_1C_2}$）与半径 $r$（或 $r_1 \pm r_2$）的大小关系。
* **条件剖析**：几何路径（$d$ 与 $r$ 对比）通常比代数路径（$\Delta$ 判定）运算量更小，是首选协议。
    * *反例*：在判断两圆位置关系时，若只计算 $d < r_1+r_2$，可能忽略内含或内切的情况，必须执行双侧（和与差）校验。

### 结果
* **【核心公式提取（Formulas）】**：
  * **直线与圆判定算子**：
    * $d < r \iff$ 相交；$d = r \iff$ 相切；$d > r \iff$ 相离。
  * **弦长算子**：$L = 2\sqrt{r^2 - d^2}$。
  * **两圆位置算子**（圆心距 $d$）：
    * $d > r_1 + r_2 \iff$ 外离；$d = r_1 + r_2 \iff$ 外切。
    * $|r_1 - r_2| < d < r_1 + r_2 \iff$ 相交。
    * $d = |r_1 - r_2| \iff$ 内切；$d < |r_1 - r_2| \iff$ 内含。
* **【重要性质归纳（Properties）】**：
  1. **公共弦协议**：若两圆方程相减，消去二次项，所得一次方程即为两圆公共弦所在直线的方程。
  2. **唯一性切线**：过圆外一点作切线必有两条；过圆上一点作切线有且仅有一条。
* **【核心特点剖析（Characteristics）】**：
  * *代数结构特征*：利用方程组解的结构反映几何拓扑。
  * *几何图像特征*：以圆心距为基准，半径的和与差为"阈值"进行全景分类。
  * *符号特征*：求两圆位置关系时，注意使用绝对值符号 $|r_1 - r_2|$。
* **【要素拆解】**：
  * 【适用前提】：涉及直线与圆或圆与圆的干涉判定。
  * 【核心结论】：位置关系是距离测度与半径边界的布尔运算结果。
  * 【适用范围/边界】：计算弦长时，必须确保直线与圆相交，即 $d < r$。

### 应用
* **学科内应用**：求解切线方程、公共弦方程及圆锥曲线的交点问题。
* **跨学科/实际应用**：**赵州桥拱设计**。通过跨度与拱高数据建立圆的方程，精确计算每根支撑支柱的高度以确保结构安全。

### 本质
* **数学思想方法**：**数形结合**（距离转化为关系）、**待定系数法**（由位置求方程）及**化归思想**。
* **高观点视域**：本节是"数学机械化"思想的体现（吴文俊方法），通过坐标法将复杂的拓扑推演转化为可由计算机自动执行的代数多项式运算。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤
* **解题策略**：执行**"一选（路径选几何法优先）、二算（算 $d$ 或 $d_{C_1C_2}$）、三比（比 $r$ 或 $r_1 \pm r_2$）、四译（得出几何结论）"**的 SOP。
* **标准操作步骤（SOP）**：
  * **步骤 $1$ [锁定参数]**：找出直线方程的一般式和圆的圆心坐标、半径。
  * **步骤 $2$ [距离运算]**：应用点到直线距离公式求 $d$，或两点距离公式求心距 $d_{C_1C_2}$。
  * **步骤 $3$ [阈值判定]**：根据 $d$ 与 $r$ 的大小关系，或 $d_{C_1C_2}$ 与 $|r_1 \pm r_2|$ 的关系锁定位置。
  * **步骤 $4$ [后续计算]**：若相交，利用勾股定理 $2\sqrt{r^2 - d^2}$ 求弦长。

---

### 典型例题
#### 例题1（基础示范题）：
1. **题目**：判断直线 $l: 3x + y - 6 = 0$ 与圆 $C: x^2 + y^2 - 2y - 4 = 0$ 的位置关系，并求弦长。
2. **【结构与特征分析】**：形视识别入口为"直线一般式 + 圆的一般式"。考察直线与圆位置判定的"几何路径"算子。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：将圆方程配方，提取圆心 $(a, b)$ 和半径 $r$。
   * *分支*：选择几何法 ➔ 计算圆心到直线的距离 $d$。
   * *收敛*：对比 $d$ 与 $r$ ➔ 判定位置 ➔ 套用弦长算子 $2\sqrt{r^2 - d^2}$。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [锁定参数]]：圆 $C$ 配方得 $x^2 + (y-1)^2 = 5$，圆心 $C(0, 1)$，$r = \sqrt{5}$。
   * [步骤 $2$ [距离运算]]：$d = \frac{|3\times 0 + 1 - 6|}{\sqrt{3^2 + 1^2}} = \frac{5}{\sqrt{10}} = \frac{\sqrt{10}}{2}$。
   * [步骤 $3$ [阈值判定]]：因 $d = \sqrt{2.5} < r = \sqrt{5}$，故直线与圆相交。
   * [步骤 $4$ [弦长计算]]：$L = 2\sqrt{(\sqrt{5})^2 - (\frac{\sqrt{10}}{2})^2} = 2\sqrt{5 - 2.5} = 2\sqrt{2.5} = \sqrt{10}$。
5. **【避坑提示】**：求距离时注意直线方程必须是 $Ax + By + C = 0$ 形式；半径是 $\sqrt{5}$ 而非 $5$。
6. **结论**：相交，弦长为 $\sqrt{10}$。

#### 例题2（综合变式题）：
1. **题目**：已知圆 $C_1: x^2 + y^2 + 2x + 8y - 8 = 0$ 与圆 $C_2: x^2 + y^2 - 4x - 4y - 2 = 0$，试判断两圆位置关系并求其公共弦所在直线方程。
2. **【结构与特征分析】**：形视识别入口为"双圆方程比对"。核心在于圆心距与半径和、差的协同判定。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：分别化简两圆方程，锁定圆心 $C_1, C_2$ 与半径 $r_1, r_2$。
   * *决策*：计算圆心距 $d$ ➔ 计算阈值 $r_1 + r_2$ 与 $|r_1 - r_2|$。
   * *分支*：两方程相减 ➔ 消去二次项。
   * *收敛*：得公共弦方程。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [锁定参数]]：$C_1(-1, -4), r_1=5$；$C_2(2, 2), r_2=\sqrt{10} \approx 3.16$。
   * [步骤 $2$ [距离运算]]：$d = \sqrt{(2+1)^2 + (2+4)^2} = \sqrt{9+36} = 3\sqrt{5} \approx 6.71$。
   * [步骤 $3$ [阈值判定]]：$r_1 - r_2 \approx 1.84$，$r_1 + r_2 \approx 8.16$。因 $1.84 < 6.71 < 8.16$，故两圆相交。
   * [步骤 $4$ [公共弦提取]]：$(C_1) - (C_2)$ 得 $6x + 12y - 6 = 0 \implies x + 2y - 1 = 0$。
5. **【避坑提示】**：相减时注意常数项的正负号（如 $-8 - (-2) = -6$）；公共弦方程仅在两圆相交时有几何意义。
6. **结论**：相交，公共弦方程为 $x + 2y - 1 = 0$。

### 巩固习题
##### 梯度一：基础达标
1. **题 $1$ **：直线 $x - y + 1 = 0$ 与圆 $x^2 + y^2 = 3$ 的位置关系是？
   *   **答案**：相交。解析：$d = \frac{1}{\sqrt{2}} < \sqrt{3}$。
2. **题 $2$ **：圆 $x^2 + y^2 = 4$ 与圆 $x^2 + y^2 - 8x - 6y + 16 = 0$ 的位置关系是？
   *   **答案**：外切。解析：$C_1(0,0), r_1=2$；$C_2(4,3), r_2=3$。$d=5, r_1+r_2=5 \implies$ 外切。

##### 梯度二：高考中档
3. **题 $3$ **：求经过点 $P(2, 1)$ 且与圆 $x^2 + y^2 = 1$ 相切的直线方程。
   *   **详细解析**：设斜率为 $k$，$kx - y + (1 - 2k) = 0$。由 $\frac{|1-2k|}{\sqrt{k^2+1}} = 1 \implies 1-4k+4k^2 = k^2+1 \implies 3k^2-4k=0 \implies k=0$ 或 $k=\frac{4}{3}$。方程为 $y=1$ 或 $4x-3y-5=0$。
4. **题 $4$ **：直线 $3x + 4y + 2 = 0$ 被圆 $x^2 + y^2 - 2x = 0$ 截得的弦长为？
   *   **详细解析**：圆 $(x-1)^2 + y^2 = 1$，$r=1$。$d = \frac{|3+0+2|}{5} = 1$。因 $d=r$，弦长为 $0$（相切）。

##### 梯度三：能力拔高
5. **题 $5$ **：已知圆 $C$ 过坐标原点和点 $A(2, 1)$，其圆心在直线 $x - 2y - 1 = 0$ 上，若直线 $l: y = kx + 1$ 与圆 $C$ 始终有公共点，求 $k$ 的范围。
   *   **思维破局**：先求圆方程，再利用圆心到直线距离 $d \le r$。
   *   **解析**：圆方程为 $(x-1.2)^2 + (y-0.1)^2 = 1.45$。$d = \frac{|1.2k - 0.1 + 1|}{\sqrt{k^2+1}} \le \sqrt{1.45}$。平方后解关于 $k$ 的不等式即可。
