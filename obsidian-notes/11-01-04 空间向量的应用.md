# 空间向量的应用
**教材**: 人教版选择性必修第一册第一章 1.4 节

## 知识深度笔记

### 现象
* **【情境锚定：从"直观想象"到"算力解析"的维度合流】**：
  1. **起因（背景与任务）**：在解决复杂的立体几何问题（如证明三垂线定理、计算降落伞绳索拉力或求异面直线距离）时，传统的综合几何法极度依赖辅助线和空间想象力。
  2. **冲突（瓶颈与矛盾）**：随着几何对象复杂化，寻找垂足、构造直角三角形的思维成本激增，且定性描述无法满足高精度的度量需求，逻辑推演易陷入"不可见"的困局。
  3. **指向（概念诞生）**：通过建立**空间向量应用协议**，将几何要素（点、线、面）映射为位置向量、方向向量和法向量，标志着几何研究由"巧思驱动"转向"程序化计算"。

### 原因
* **形成机制**：利用向量的线性运算刻画"位置"，利用数量积刻画"度量"（长度与角度）。
    * **方向向量**：描述直线 $l$ 的延伸趋向 $\vec{u}$。
    * **法向量**：描述平面 $\alpha$ 的"朝向"约束 $\vec{n}$，满足 $\vec{n} \perp \alpha$。
* **条件剖析**：向量化应用的前提是基准点的统一或坐标系的建立。
    * *反例*：若选取的法向量 $\vec{n}$ 与平面内向量不垂直，则所有基于法向量的投影计算将全部失效。

### 结果
* **【核心公式提取（Formulas）】**：
  * **点到平面距离算子**：$d = \frac{|\overrightarrow{AP} \cdot \vec{n}|}{|\vec{n}|}$（$A$ 为面上任一点，$P$ 为面外点，$\vec{n}$ 为法向量）。
  * **线面角正弦算子**：$\sin \theta = \frac{|\vec{u} \cdot \vec{n}|}{|\vec{u}||\vec{n}|}$（$\vec{u}$ 为线方向向量）。
* **【重要性质归纳（Properties）】**：
  1. **平行判定**：$l \parallel \alpha \iff \vec{u} \cdot \vec{n} = 0$；$\alpha \parallel \beta \iff \vec{n}_1 \parallel \vec{n}_2$。
  2. **垂直判定**：$l \perp \alpha \iff \vec{u} \parallel \vec{n}$；$\alpha \perp \beta \iff \vec{n}_1 \cdot \vec{n}_2 = 0$。
* **【核心特点剖析（Characteristics）】**：
  * *代数结构特征*：利用数量积的"零值"锁定垂直，利用"投影长度"锁定距离。
  * *几何图像特征*：法向量始终是平面的"风向标"。
  * *符号特征*：注意线面角公式用 $\sin$，异面直线与二面角公式用 $\cos$。
* **【要素拆解】**：
  * 【适用前提】：已建立空间直角坐标系或选取不共面基底。
  * 【核心结论】：向量运算结果具备唯一的几何解释（翻译机制）。
  * 【适用范围/边界】：求二面角时需根据图形判定是 $\langle \vec{n}_1, \vec{n}_2 \rangle$ 还是其补角。

### 应用
* **学科内应用**：证明空间平行/垂直判定定理，解决高考压轴的"解体三角形"及二面角计算。
* **跨学科/实际应用**：**降落伞受力分析**。通过 8 根绳索向量的合力计算，确定匀速下落时的拉力大小。

### 本质
* **数学思想方法**：**化归思想**（空间几何 $\to$ 向量代数）与**坐标法**。
* **高观点视域**：这是线性算子在欧几里得空间（内积空间）的具体体现。它证明了空间关系可以通过度量矩阵和内积运算实现"机械化证明"。

# 第二部分：方法、例题与解题训练

## 方法、例题与解题训练

### 方法与步骤
* **解题策略**：严格执行"向量法三步曲"：**向量化**（坐标或基底表示） $\to$ **运算**（内积或线性计算） $\to$ **翻译**（还原为几何结论）。
* **标准操作步骤（SOP）**：
  * **步骤 $1$ [建系表点]**：选择规则交点为原点，写出所有关键顶点的坐标。
  * **步骤 $2$ [求法向量]**：联立 $\vec{n} \cdot \vec{v}_1 = 0$ 和 $\vec{n} \cdot \vec{v}_2 = 0$ 解出 $\vec{n} = (x, y, z)$。
  * **步骤 $3$ [公式套用]**：根据目标选择距离公式、夹角公式计算数值。

---

### 典型例题
#### 例题1（基础示范题）：
1. **题目**：已知正方体 $ABCD-A_1B_1C_1D_1$ 棱长为 $1$，求平面 $A_1BC$ 的一个法向量。
2. **【结构与特征分析】**：形视识别入口为"求解未知平面朝向"。核心在于利用平面内两条不共线向量与法向量垂直的性质。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：建立空间直角坐标系。
   * *分支*：写出点 $A_1, B, C$ 坐标 ➔ 提取向量 $\overrightarrow{BA_1}, \overrightarrow{BC}$。
   * *决策*：设 $\vec{n} = (x, y, z)$，列出垂直方程组 ➔ 自由变量取值。
   * *终点*：解得法向量坐标。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [建系表点]]：以 $D$ 为原点，$DA, DC, DD_1$ 为 $x, y, z$ 轴。$A_1(1, 0, 1), B(1, 1, 0), C(0, 1, 0)$。
   * [步骤 $2$ [求法向量]]：$\overrightarrow{BC} = (-1, 0, 0), \overrightarrow{BA_1} = (0, -1, 1)$。
   * [步骤 $3$ [解方程]]：$\begin{cases} -x = 0 \\ -y + z = 0 \end{cases} \implies x = 0, y = z$。取 $z = 1$，则 $\vec{n} = (0, 1, 1)$。
5. **【避坑提示】**：法向量不唯一，只要方向一致（共线）均可，建议选取最简整数比。
6. **结论**：$\vec{n} = (0, 1, 1)$。

#### 例题2（综合变式题）：
1. **题目**：在直三棱柱 $ABC-A_1B_1C_1$ 中，$AC=CB=2, AA_1=3, \angle ACB=90^\circ$。求平面 $PQR$（$P, Q, R$ 分别为中点及定比分点）与底面的二面角余弦值。
2. **【结构与特征分析】**：考查"法向量夹角转化"。识别入口为"二面角向量协议"。
3. **【解题决策逻辑流（思维推演）】**：
   * *起点*：分别求出两个平面的法向量 $\vec{n}_1, \vec{n}_2$。
   * *决策*：计算数量积 $\vec{n}_1 \cdot \vec{n}_2$ ➔ 计算模长乘积。
   * *分支*：代入公式 $\cos \theta = \frac{|\vec{n}_1 \cdot \vec{n}_2|}{|\vec{n}_1||\vec{n}_2|}$。
   * *收敛*：结合图形判定二面角是锐角还是钝角。
4. **【解析（对照 SOP 步骤）】**：
   * [步骤 $1$ [求法向量]]：底面 $A_1B_1C_1$ 法向量为 $\vec{n}_1 = (0, 0, 1)$；由已知点解得平面 $PQR$ 法向量 $\vec{n}_2 = (3, 4, 2)$。
   * [步骤 $2$ [运算]]：$\vec{n}_1 \cdot \vec{n}_2 = 2$；$|\vec{n}_1|=1, |\vec{n}_2|=\sqrt{29}$。
   * [步骤 $3$ [翻译]]：$\cos \theta = \frac{2}{\sqrt{29}} = \frac{2\sqrt{29}}{29}$。
5. **【避坑提示】**：法向量夹角公式自带绝对值求的是"平面夹角"（锐角或直角），若求"二面角"需通过二面角开口方向二次判定正负。
6. **结论**：余弦值为 $\frac{2\sqrt{29}}{29}$。

### 巩固习题
##### 梯度一：基础达标
1. **题 $1$ **：若直线 $l$ 的方向向量 $\vec{u} = (1, 0, 1)$，平面 $\alpha$ 的法向量 $\vec{n} = (-1, 1, 1)$，则 $l$ 与 $\alpha$ 的位置关系是？
   *   **答案**：$l \parallel \alpha$。解析：$\vec{u} \cdot \vec{n} = -1 + 0 + 1 = 0 \implies \vec{u} \perp \vec{n} \implies l \parallel \alpha$。
2. **题 $2$ **：点 $P(1, 2, 1)$ 到坐标平面 $xOy$ 的距离为？
   *   **答案**：$1$。解析：法向量为 $(0, 0, 1)$，距离即竖坐标绝对值。

##### 梯度二：高考中档
3. **题 $3$ **：在正方体 $ABCD-A_1B_1C_1D_1$ 中，求异面直线 $A_1B$ 与 $B_1C$ 所成角的余弦值。
   *   **详细解析**：建立坐标系，$\overrightarrow{A_1B} = (0, 1, -1)$，$\overrightarrow{B_1C} = (-1, 0, -1)$。$\cos \theta = \frac{|0 + 0 + 1|}{\sqrt{2} \times \sqrt{2}} = 0.5$。夹角为 $60^\circ$。
4. **题 $4$ **：已知平面 $\alpha$ 的法向量 $\vec{n} = (2, -1, 2)$，点 $A(1, 0, 1)$ 在 $\alpha$ 内，则点 $P(3, -1, 4)$ 到 $\alpha$ 的距离为？
   *   **详细解析**：$\overrightarrow{AP} = (2, -1, 3)$。$d = \frac{|2 \times 2 + (-1) \times (-1) + 3 \times 2|}{\sqrt{2^2 + (-1)^2 + 2^2}} = \frac{11}{3}$。

##### 梯度三：能力拔高
5. **题 $5$ **：如图，在四棱锥 $P-ABCD$ 中，$PD \perp$ 底面，$PD=DC=1$，底面为正方形。求平面 $CPB$ 与平面 $PBD$ 的夹角余弦值。
   *   **思维破局**：建立以 $D$ 为原点的坐标系，分别求出两个平面的法向量。
   *   **解析**：经计算 $\vec{n}_1 = (0, 1, 1)$，$\vec{n}_2 = (1, -1, 0)$。$\cos \theta = \frac{|0-1+0|}{\sqrt{2} \times \sqrt{2}} = 0.5$。夹角为 $60^\circ$。
