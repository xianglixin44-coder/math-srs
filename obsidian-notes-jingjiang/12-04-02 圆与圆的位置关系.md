# 圆与圆的位置关系
**分类**: 选择性必修第一册

## 核心概念界定

## 一、核心概念界定

两圆 $C_1, C_2$ 的相对姿态分为：
* **相交**：有两个公共点。
* **相切**：只有一个公共点，包括**外切**与**内切**。
* **相离**：没有公共点，包括**外离**与**内含**。

## 解题策略与方法论

## 二、位置关系判定的几何法 SOP

设两圆圆心距为 $d$，半径分别为 $r_1, r_2$：

* **动作**：将两圆方程配方化为标准式，提取圆心坐标与半径，计算 $d$。
* **判定标准**：
    * $d > r_1 + r_2 \iff$ **外离**
    * $d = r_1 + r_2 \iff$ **外切**
    * $|r_1 - r_2| < d < r_1 + r_2 \iff$ **相交**
    * $d = |r_1 - r_2| \iff$ **内切**
    * $d < |r_1 - r_2| \iff$ **内含**

### 代数法
联立两圆方程，通过相减消去二次项得到直线方程（相交时为公共弦），再判定该直线与圆的 $\Delta$。

## 易错点与风险规避

## 三、易错点与风险规避

### 1. 内切/内含判定中的"单侧"陷阱
* **陷阱描述**：在比较 $d$ 与半径差时，忽略了绝对值 $|r_1 - r_2|$，导致无法正确判定大圆包含小圆的情形。
* **避坑策略**：始终将 $d$ 与 $r_1+r_2$（和）及 $|r_1-r_2|$（差的绝对值）这两个阈值进行对标。

### 2. 公共弦方程的"名存实亡"
* **陷阱描述**：认为任意两圆方程相减得到的都是公共弦。
* **避坑策略**：该直线仅在两圆**相交**时才是公共弦；若两圆相离，该直线虽存在（根轴），但并无几何交点。

## 经典例题精讲

## 五、经典例题精讲

### [例题 1] 一般式圆的位置关系判定
**题目**：判断圆 $C_1: x^2+y^2+2x+8y-8=0$ 与 $C_2: x^2+y^2-4x-4y-2=0$ 的位置关系。

**规范解答**：
化标准式：$C_1: (x+1)^2+(y+4)^2=25$ → $C_1(-1,-4), r_1=5$。
$C_2: (x-2)^2+(y-2)^2=10$ → $C_2(2,2), r_2=\sqrt{10}$。
$d = \sqrt{(-1-2)^2 + (-4-2)^2} = 3\sqrt{5} \approx 6.71$。
$r_1+r_2 = 5+\sqrt{10} \approx 8.16$；$|r_1-r_2| = 5-\sqrt{10} \approx 1.84$。
$1.84 < 6.71 < 8.16$ → $|r_1-r_2| < d < r_1+r_2$ → **相交**。

**方法提炼**：化标准式 → 提取圆心半径 → 算 $d$ → 五区间判定。

### [例题 2] 求公共弦方程
**题目**：两圆 $x^2+y^2=10$ 与 $(x-1)^2+(y-3)^2=20$ 相交，求公共弦所在直线方程。

**规范解答**：
展开 $C_2$：$x^2+y^2-2x-6y-10=0$。
$C_1 - C_2$：$(x^2+y^2-10) - (x^2+y^2-2x-6y-10) = 0$ → $2x+6y=0$ → $x+3y=0$。
$\therefore$ 公共弦为 $x+3y=0$。

**方法提炼**：两圆方程相减 → 消去二次项 → 得公共弦所在直线。
