# 正弦定理与余弦定理
**分类**: 高一数学-第二册-平面向量及其应用

## 核心概念界定

## 一、核心概念界定

### 1. 余弦定理
在 $\triangle ABC$ 中：
$$a^2 = b^2 + c^2 - 2bc \cos A$$
$$b^2 = a^2 + c^2 - 2ac \cos B$$
$$c^2 = a^2 + b^2 - 2ab \cos C$$
余弦定理是勾股定理在非直角三角形中的普适化推广．

### 2. 正弦定理
$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$
其中 $R$ 为三角形外接圆半径．反映了三角形边长与其外接圆的对称比例关系．

## 解题策略与方法论

## 二、解题策略与方法论

### 1. 定理选择的决策路径
*   **SAS / SSS**：优先余弦定理．直接求第三边或用 $\cos A = \frac{b^2+c^2-a^2}{2bc}$ 锁定唯一角．
*   **ASA / AAS / SSA**：优先正弦定理．利用比例 $a = \frac{b \sin A}{\sin B}$ 转化．

### 2. 边角互化 SOP
*   **化边为角**：令 $a = 2R \sin A$ 代入．
*   **化角为边**：令 $\sin A = \frac{a}{2R}$ 代入．

## 易错点与风险规避

## 三、易错点与风险规避

### 1. SSA 模式下的「多解陷阱」
*   **陷阱描述**：已知 $a, b, A$ 求 $B$ 时，$\sin B = \sin(\pi - B)$，容易漏掉钝角解．
*   **避坑策略**：强制执行「大边对大角」校验．

### 2. 正弦定理求角的盲目性
*   **陷阱描述**：已知三边求角时使用正弦定理．
*   **避坑策略**：优先使用余弦定理，因其在 $(0, \pi)$ 上单调，结果唯一．

## 多维原理解码

## 四、多维原理解码

![[06-04-03-sine-cosine-insight.png]]

*   **代数/逻辑视阈**：余弦定理本质是向量数量积展开式 $|\vec{c}|^2 = |\vec{a}-\vec{b}|^2 = \vec{a}^2 + \vec{b}^2 - 2\vec{a} \cdot \vec{b}$ 的代数化映射．
*   **几何/直观视阈**：正弦定理体现了三角形作为圆内接多边形的比例协调性．
*   **物理/现实视阈**：它是航海定位和不可达高度测量的核心算法，将「无法触及的距离」转化为「可测量的角度」．

## 经典例题精讲

## 五、经典例题精讲

### [例题 1] 已知三边求角
**题目**：在 $\triangle ABC$ 中，$a=2, b=\sqrt{2}, c=\sqrt{3}+1$，解三角形．

**深度分析**：已知三边 (SSS)，触发余弦定理推论，优先求最长边 $c$ 所对的角．

**规范解答**：
1.  $\cos C = \frac{a^2+b^2-c^2}{2ab} = \frac{4+2-(3+2\sqrt{3}+1)}{4\sqrt{2}} = \frac{2-2\sqrt{3}}{4\sqrt{2}}$
2.  计算得 $C = 105^\circ$．
3.  利用正弦定理求 $B=30^\circ$，$A=45^\circ$．

**方法提炼**：SSS 场景下，余弦定理是锁定角度的刚性工具．

### [例题 2] 正弦定理求边
**题目**：在 $\triangle ABC$ 中，已知 $A = 45^\circ, B = 60^\circ, a = 2$，求边 $b$．

**规范解答**：
由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B}$：
$$b = \frac{a \cdot \sin B}{\sin A} = \frac{2 \cdot \sin 60^\circ}{\sin 45^\circ} = \frac{2 \cdot \frac{\sqrt{3}}{2}}{\frac{\sqrt{2}}{2}} = \frac{\sqrt{3}}{\frac{\sqrt{2}}{2}} = \sqrt{6}$$

**方法提炼**：正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = 2R$ — 已知两角一边求其他，首选正弦定理．

## 101星思维挑战

## 七、101星思维挑战

### 1. 海伦公式的推导
**挑战问题**：利用余弦定理及 $\sin^2 A + \cos^2 A = 1$，证明三角形面积 $S = \sqrt{p(p-a)(p-b)(p-c)}$（$p$ 为半周长）．
**思考引导**：将 $\cos A$ 用边表示，代入 $S = \frac{1}{2}bc \sin A$ 后代数平方差分解．

### 2. 正弦定理的射影几何意义
**挑战问题**：证明 $a = b \cos C + c \cos B$，思考这一射影定理如何与正弦定理及余弦定理共同构成三角形的完备代数描述．
