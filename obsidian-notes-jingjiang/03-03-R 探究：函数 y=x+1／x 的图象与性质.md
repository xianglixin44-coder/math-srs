# 探究：函数 y=x+1/x 的图象与性质
**分类**: 高一数学-第一册-函数的概念与性质

## 核心概念界定

## 一、核心概念界定

### 1. 函数定义与结构
函数 **$f(x) = x + \frac{1}{x}$ ** 是由正比例函数 $y=x$ 与反比例函数 $y=\frac{1}{x}$ 通过加法运算构成的复合结构函数。
*   **定义域**：由于分母不能为零，其定义域为 $\{x \mid x \neq 0\}$，即 $(-\infty, 0) \cup (0, +\infty)$。
*   **奇偶性**：$f(-x) = -x + \frac{1}{-x} = -(x + \frac{1}{x}) = -f(x)$，故该函数为**奇函数**，图象关于原点成中心对称。

### 2. 图象形态 (Nike Function)
该函数在第一、三象限各有一支曲线，形状酷似运动品牌"耐克"的标识或数学中的"对勾"，因此常被称为**"对勾函数"**。

## 解题策略与方法论

## 二、解题策略与方法论

### 1. 单调性判定的 SOP 流程
研究该函数的增减性需分区间讨论，以 $x=1$ 和 $x=-1$ 为逻辑转折点：
1.  **正半轴讨论**：
    *   在 $(0, 1]$ 上单调递减。
    *   在 $[1, +\infty)$ 上单调递增。
2.  **负半轴同步（利用奇偶性）**：
    *   在 $(-\infty, -1]$ 上单调递增。
    *   在 $[-1, 0)$ 上单调递减。
3.  **判定依据**：可采用定义法（取值、作差、变形、定号）或利用导数 $f'(x) = 1 - \frac{1}{x^2}$ 锁定零点。

### 2. 最值与值域求解路径
1.  **触发基本不等式**：当 $x > 0$ 时，$x + \frac{1}{x} \ge 2\sqrt{x \cdot \frac{1}{x}} = 2$，当且仅当 $x=1$ 时取得最小值 $2$。
2.  **镜像推导**：由于对称性，当 $x < 0$ 时，$-x > 0$，$-x + \frac{1}{-x} \ge 2 \implies x + \frac{1}{x} \le -2$，当且仅当 $x=-1$ 时取得最大值 $-2$。
3.  **结论收敛**：函数值域为 $(-\infty, -2] \cup [2, +\infty)$。

## 易错点与风险规避

## 三、易错点与风险规避

### 1. 单调区间的"并集"非法书写
*   **陷阱描述**：学生习惯将递增区间写成 $(-\infty, -1] \cup [1, +\infty)$。
*   **具体反例**：取 $x_1 = -1, x_2 = 1$，虽然 $x_1 < x_2$，但 $f(-1) = -2, f(1) = 2$ 虽增加，但在跨越 $x=0$ 断点时，整体并非单调。
*   **避坑策略**：单调性是局部性质，必须用"和"或"，"分隔不连续区间。

### 2. 忽略 $x < 0$ 时的值域缺失
*   **陷阱描述**：在求 $x + \frac{1}{x}$ 的值域时仅给出 $[2, +\infty)$。
*   **避坑策略**：除非题目限制 $x > 0$，否则必须完整考虑对称的负数支。

## 四、多维原理解码

*   **代数/逻辑视阈**：该函数是**线性增长与反比例收敛的博弈**。当 $|x|$ 极大时，$\frac{1}{x}$ 趋于 0，函数受 $y=x$ 支配；当 $|x|$ 趋于 0 时，$x$ 可忽略，函数受 $\frac{1}{x}$ 支配而发散。
*   **几何/直观视阈**：图象拥有两条渐近线：$y$ 轴（垂直渐近线）和直线 $y=x$（斜渐近线）。图象被夹在两条线之间，体现了数学边界的约束美。
*   **物理/现实视阈**：它是描述 **"效率最优化"** 的经典模型。例如在固定周长的矩形中寻找面积与周长关系的变体，或在考虑固定成本与可变成本的生产模型中寻找平均成本的最低点。

## 经典例题精讲

## 五、经典例题精讲

### [例题 1] 证明函数在 $(1, +\infty)$ 上单调递增
**规范解答**：
1.  **取值**：任取 $x_1, x_2 \in (1, +\infty)$，且 $x_1 < x_2$。
2.  **作差**：$f(x_1) - f(x_2) = (x_1 + \frac{1}{x_1}) - (x_2 + \frac{1}{x_2}) = (x_1 - x_2) + \frac{x_2 - x_1}{x_1x_2}$。
3.  **变形**：$(x_1 - x_2)(1 - \frac{1}{x_1x_2}) = \frac{(x_1 - x_2)(x_1x_2 - 1)}{x_1x_2}$。
4.  **定号**：因 $x_1, x_2 > 1$，则 $x_1x_2 > 1 \implies x_1x_2 - 1 > 0$；又 $x_1 < x_2 \implies x_1 - x_2 < 0$。
5.  **结论**：差值 $< 0$，即 $f(x_1) < f(x_2)$，函数在 $(1, +\infty)$ 上递增。

### [例题 2] 对勾函数的值域
**题目**：求 $f(x) = x + \frac{4}{x}$（$x > 0$）的最小值，并指出取最小值时的 $x$．

**规范解答**：
由基本不等式：$x + \frac{4}{x} \ge 2\sqrt{x \cdot \frac{4}{x}} = 4$
当且仅当 $x = \frac{4}{x}$ 即 $x = 2$ 时等号成立．
$\therefore f(x)_{\min} = 4$．

**方法提炼**：对勾函数 $x + \frac{k}{x}$（$k>0$）在 $x = \sqrt{k}$ 处取最小值 $2\sqrt{k}$，这是基本不等式的直接应用．

## 101星思维挑战

## 七、101星思维挑战

### 1. 参数 $k$ 的动态演化探究
**挑战问题**：对于广义对勾函数 $f(x) = x + \frac{k}{x} (k > 0)$，其单调区间的转折点（极值点）是多少？若 $k < 0$，函数性质会发生怎样的质变？
**思考引导**：利用导数或定义法证明转折点位于 $x = \pm \sqrt{k}$。当 $k < 0$ 时，函数将变为在定义域内单调递增，不再有"对勾"形态。

### 2. 复合函数的定点与平移
**挑战问题**：函数 $y = (x-h) + \frac{1}{x-h} + m$ 的对称中心在哪里？
**思考引导**：回归 $y = x + \frac{1}{x}$ 的对称中心 $(0, 0)$，执行坐标平移变换 $(h, m)$。
