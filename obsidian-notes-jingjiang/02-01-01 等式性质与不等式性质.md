# 等式性质与不等式性质
**分类**: 高一数学-第一册-一元二次函数、方程和不等式

## 核心概念界定

## 一、核心概念界定

### 1. 实数大小比较的基本事实
由于数轴上的点与实数一一对应，我们可以利用数轴上点的位置关系来规定实数的大小关系．关于实数 $a, b$ 大小的比较，其基本事实可以符号化表示为：
*   $a > b \iff a - b > 0$；
*   $a = b \iff a - b = 0$；
*   $a < b \iff a - b < 0$．
这表明要比较两个实数的大小，可以转化为比较它们的差与 $0$ 的大小．

### 2. 重要不等式与等号成立条件
一般地，对于任意 $a, b \in \mathbb{R}$，有 $a^2 + b^2 \ge 2ab$．该不等式的成立基于完全平方公式 $(a-b)^2 \ge 0$，且当且仅当 $a = b$ 时，等号成立．

### 3. 等式的五大基本性质
等式作为刻画相等关系的工具，具有以下运算不变性：
*   **对称性**：若 $a = b$，则 $b = a$．
*   **传递性**：若 $a = b$ 且 $b = c$，则 $a = c$．
*   **加减性**：若 $a = b$，则 $a \pm c = b \pm c$．
*   **乘法性**：若 $a = b$，则 $ac = bc$．
*   **除法性**：若 $a = b$ 且 $c \neq 0$，则 $\frac{a}{c} = \frac{b}{c}$．

## 解题策略与方法论

## 二、解题策略与方法论

### 1. 作差比较法 SOP
比较两个实数或代数式 $A$ 与 $B$ 的大小，执行以下标准动作：
1.  **作差**：构造差式 $D = A - B$。
2.  **变形**：通过因式分解、配方、通分等手段，将 $D$ 化为易于判断符号的形式。
3.  **定号**：判断 $D$ 与 $0$ 的大小关系。
4.  **结论**：由 $D$ 的符号判定 $A$ 与 $B$ 的大小。

### 2. 不等式链式推导路径
在复杂不等式证明中，利用基本性质进行结构组合：
*   **同向可加性**：$a > b, c > d \implies a + c > b + d$。
*   **正数同向可乘性**：$a > b > 0, c > d > 0 \implies ac > bd$。
*   **乘方性**：$a > b > 0 \implies a^n > b^n$ ($n \in \mathbb{N}, n \ge 2$)。

## 易错点与风险规避

## 三、易错点与风险规避

### 1. 负数乘法「失变」陷阱
*   **陷阱描述**：在不等式两边同乘含参变量 $c$ 时，未对 $c$ 的正负进行讨论，导致变号错误。
*   **具体反例**：由 $a > b$ 推导出 $a \cdot \sin \theta > b \cdot \sin \theta$ 是错误的，因为 $\sin \theta$ 可能小于 $0$ 或等于 $0$。
*   **避坑策略**：执行乘法操作前，必须强制确认乘数的符号，若不确定则必须**分类讨论**。

### 2. 同向相减的「非法操作」
*   **陷阱描述**：误以为不等式可以像等式一样同向相减。
*   **具体反例**：已知 $10 > 2$ 和 $8 > 1$，但 $10 - 8 = 2 < 2 - 1 = 1$ 不成立。
*   **避坑策略**：不等式没有「相减」性质。若需处理差值，应先将 $c > d$ 转化为 $-c < -d$，再利用**同向可加性**。

### 3. 等号成立条件的遗漏
*   **陷阱描述**：在应用 $a^2 + b^2 \ge 2ab$ 或后续基本不等式求最值时，忽略了等号能否取到的验证。
*   **避坑策略**：每当写下 $\ge$ 符号时，必须在括号内标注「当且仅当...时等号成立」。

## 多维原理解码

## 四、多维原理解码

### 几何/直观视阈
加法性质对应数轴的**整体平移**，不改变点与点之间的左右顺序；正数乘法对应**同向缩放**；负数乘法对应**关于原点的镜像翻转**，这种翻转正是改变不等号方向的物理本质。

![[02-01-01-inequality.png]]

### 代数/逻辑视阈
不等式是「序关系」的体现。作差法的本质是将两个量的相对位置比较，通过「减法」平移到数轴原点，转化为一个量相对于零点的绝对位置判定。

### 物理/现实视阈
不等式刻画了现实中的「阈值」。例如，高速公路限速 $0 < v \le 120$ km/h，反映了系统安全运行的合规边界，超出的部分在逻辑上被定义为「非法」或「失效」。

## 经典例题精讲

## 五、经典例题精讲

### 例题 1：比较代数式大小
**题目**：比较 $(x+3)(x+7)$ 与 $(x+4)(x+6)$ 的大小。

**深度分析**：两个式子项数相同，结构对称，适合使用作差法，通过展开抵消共有项来提取差异。

**规范解答**：
设 $A = (x+3)(x+7) = x^2 + 10x + 21$，
设 $B = (x+4)(x+6) = x^2 + 10x + 24$。
作差：$A - B = (x^2 + 10x + 21) - (x^2 + 10x + 24) = -3$。
因为 $-3 < 0$，所以 $A < B$。

**方法提炼**：通过化简，将变量间的比较转化为常数与 $0$ 的比较，体现了「变中求定」的数学思想。

### [例题 2] 作差法比较大小
**题目**：比较 $(x+1)(x-3)$ 与 $(x-1)^2$ 的大小．

**规范解答**：
作差：$(x+1)(x-3) - (x-1)^2 = (x^2 - 2x - 3) - (x^2 - 2x + 1) = -4$
$\because -4 < 0$ 恒成立，$\therefore (x+1)(x-3) < (x-1)^2$ 对一切实数 $x$ 成立．

**方法提炼**：比较两式大小 → 作差 → 化简 → 判断符号．差为常数是最理想的情况，一步定大小．

## 101星思维挑战

## 七、101星思维挑战

### 1. 倒数性质的严密性
**挑战问题**：已知 $a > b$，在什么条件下一定有 $\frac{1}{a} < \frac{1}{b}$？
**思考引导**：尝试从 $a, b$ 同号（同为正或同为负）和异号两种情况进行分类。通过作差法 $\frac{1}{a} - \frac{1}{b} = \frac{b-a}{ab}$ 观察分母 $ab$ 对正负的影响。

### 2. 糖水浓度逻辑
**挑战问题**：已知 $b > a > 0$，$m > 0$，证明：$\frac{a+m}{b+m} > \frac{a}{b}$。
**思考引导**：往糖水中加糖，糖水变甜了。请利用作差法证明，并思考其在分式线性变换中的含义。
