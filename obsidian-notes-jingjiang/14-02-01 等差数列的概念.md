# 等差数列的概念
**分类**: 选择性必修第二册

## 核心概念界定

## 一、核心概念界定

### 1. 等差数列的定义
* **严格定义**：如果一个数列从第 2 项起，每一项与它的前一项的差都等于同一个常数，那么这个数列就叫做**等差数列**。
* **符号化描述**：$a_n - a_{n-1} = d$ ($n \ge 2$)，其中常数 $d$ 称为公差。
* **递推性质**：$a_{n+1} - a_n = d$ 构成了等差数列的离散演化规则。

### 2. 等差中项
* **数学定义**：若三个数 $a, A, b$ 组成一个等差数列，则称 $A$ 为 $a$ 与 $b$ 的等差中项。
* **逻辑关系**：$A - a = b - A$，即 **$2A = a + b$ **。

### 3. 通项公式
* $$a_n = a_1 + (n - 1)d$$
* 通过 $a_1$ 与 $d$ 两个参数唯一确定数列的每一项。

## 解题策略与方法论

## 二、构建等差模型与求解参数的 SOP

1. **参数锚定**：识别题目中给出的基本量，通常需要锁定首项 $a_1$ 和公差 $d$。
2. **方程联立**：若已知两项 $a_m, a_n$，根据通项公式列出关于 $a_1$ 和 $d$ 的二元一次方程组。利用变式 $a_n = a_m + (n - m)d$ 可直接绕过 $a_1$ 求解 $d$。
3. **存在性验证**：令 $a_1 + (n - 1)d = K$，解 $n$。若 $n \in \mathbb{N}^*$，则 $K$ 是数列的项。

## 易错点与风险规避

## 三、易错点与风险规避

### 1. 忽略 $n \ge 2$ 的递推前提
* **陷阱描述**：在利用递推公式时忘记标注该关系从第 2 项开始才有效。
* **避坑策略**：书写递推关系式后强制标注 $n \ge 2$。

### 2. 公差 $d$ 的常数性误判
* **陷阱描述**：将差值为变量（如 $a_n - a_{n-1} = n$）的数列误认为等差数列。
* **避坑策略**：验证等差数列必须证明差值与 $n$ 无关。

### 3. 等差中项的正负号误区
* **陷阱描述**：在"三个数成等差数列"的含参问题中，忽略了 $a, b$ 可取负值。
* **避坑策略**：牢记 $2A = a + b$ 是一次方程，解的符号取决于 $a, b$ 的代数和。

## 多维原理解码

## 四、多维原理解码

![[14-02-01-arithmetic.png]]

* **代数/逻辑视阈**：等差数列是**离散的一次函数**。通项公式 $a_n = dn + (a_1 - d)$ 揭示了其本质是线性增长模型在正整数域上的取值序列，公差 $d$ 对应函数的斜率。
* **几何/直观视阈**：等差数列的图象是分布在一条直线上的**孤立点集**。这些点在 $x$ 轴上的投影距离相等（步长为 1），在 $y$ 轴上的投影跨度恒定（步长为 $d$）。
* **物理/现实视阈**：等差数列描述了**匀质的变化过程**。如天坛石板圈数的增加、匀速直线运动中固定时间间隔的位移，都是该逻辑模型的现实映射。

## 经典例题精讲

## 五、经典例题精讲

### [例题 1] 判定项的存在性
**题目**：$-401$ 是不是等差数列 $-5, -9, -13, \dots$ 的项？如果是，是第几项？

**规范解答**：
$a_1 = -5$，$d = -9 - (-5) = -4$。通项 $a_n = -5 + (n - 1)(-4) = -4n - 1$。
令 $-4n - 1 = -401$ → $n = 100 \in \mathbb{N}^*$。$\therefore$ $-401$ 是第 100 项。

**方法提炼**：存在性验证 = 提取 $a_1, d$ → 建通项 → 解方程 → 判整数。

### [例题 2] 下标对称性
**题目**：在等差数列中，$a_3 + a_8 = 20$，求 $a_5 + a_6$。

**规范解答**：
$3 + 8 = 5 + 6$ → $a_3 + a_8 = a_5 + a_6 = 20$。

**方法提炼**：$p+q = s+t \iff a_p + a_q = a_s + a_t$——等差数列下标对称性。

## 101星思维挑战

## 七、101星思维挑战

### 1. 下标对称性的普适推广
**挑战问题**：若 $\{a_n\}$ 为等差数列，且 $p + q = s + t$，证明 $a_p + a_q = a_s + a_t$。
**思考引导**：$a_p = a_1 + (p-1)d$，$a_q = a_1 + (q-1)d$，和 = $2a_1 + (p+q-2)d$。$p+q=s+t$，故 $a_s+a_t$ 中 $a_1$ 系数和 $d$ 系数完全一致。

### 2. 离散斜率的物理意义
**挑战问题**：证明等差数列中 $\frac{a_m - a_n}{m - n}$ 为常数，并解释其几何意义。
**思考引导**：$a_m - a_n = (m-n)d$ → $\frac{a_m - a_n}{m - n} = d$。在图象上，这就是连接两点的直线的斜率——等差数列的所有点共线。
