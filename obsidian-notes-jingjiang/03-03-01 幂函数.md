# 幂函数
**分类**: 高一数学-第一册-函数的概念与性质

## 核心概念界定

## 一、核心概念界定

### 1. 幂函数的定义
一般地，函数 y=xᵅ 叫做**幂函数**，其中 x 是自变量，α 是常数。
*   **结构特征**：底数变→幂函数；指数变→指数函数。
*   **公共点**：所有幂函数在 (0,+∞) 上有定义，且图象过 (1,1)。

### 2. 五类核心幂函数
*   y=x：定义域 R，奇函数。
*   y=x²：定义域 R，偶函数，值域 [0,+∞)。
*   y=x³：定义域 R，奇函数。
*   y=√x：定义域 [0,+∞)，非奇非偶。
*   y=1/x：定义域 x≠0，奇函数。

## 解题策略与方法论

## 二、解题策略与方法论

### 研究幂函数的一般路径 (SOP)
1.  **定域**：根据 α 确定定义域（分数→根号约束；负数→分母≠0）。
2.  **析性**：奇偶性（验证 f(-x)）+ 单调性（重点看 (0,+∞)）。
3.  **绘图**：「五点法」+ 必过 (1,1) 点。α>0 通常过 (0,0)。
4.  **推广**：利用奇偶性将局部性质对称到整个定义域。

### 比较幂值大小的策略
*   **同指数**：构造幂函数 f(x)=xᵅ，比较自变量大小。
*   **同底数**：利用幂函数的单调性（α>0 递增，α<0 递减）。

## 易错点与风险规避

## 三、易错点与风险规避

### 1. 概念混淆：幂函数 vs 指数函数
*   y=x²（幂函数）vs y=2ˣ（指数函数）。关键：「底数变」是幂函数。

### 2. 定义域遗漏
*   y=√x 的定义域为 [0,+∞)，不关于原点对称 → 非奇非偶。
*   y=1/x 在 x=0 处无定义。

### 3. 单调区间的「非法跨越」
*   y=1/x 不能说「在定义域内单调递减」。必须在 (-∞,0) 和 (0,+∞) 分别说明。

## 多维原理解码

## 四、多维原理解码

### 几何/直观视阈
所有图象在 (1,1) 点「会师」。α>1 时陡峭，0<α<1 时平缓，α<0 时衰减。

![[03-03-01-power.png]]

### 代数/逻辑视阈
α 的正负决定第一象限的增减方向：α>0 为「生长」，α<0 为「衰减」。

### 物理/现实视阈
边长 a 与面积 a²（2维）、体积 a³（3维）的关系——物理量随线性尺度缩放的幂律特征。

## 经典例题精讲

## 五、经典例题精讲

### [例题 1] 幂函数比较大小
**题目**：比较 $a = 2^{0.3}, b = 3^{0.3}, c = 0.3^2$ 的大小．

**规范解答**：
1. $a$ 和 $b$：底数不同指数相同，$y = x^{0.3}$ 在第一象限递增 $\implies a < b$
2. $c = 0.3^2 = 0.09$，而 $a = 2^{0.3} > 2^0 = 1$，故 $c < a$
3. 综上 $c < a < b$

**方法提炼**：同指数用幂函数单调性比较；同底数用指数函数单调性；跨类型找中间值（1 是最常用的桥梁）．

### [例题 2] 幂函数图象过定点
**题目**：无论 $\alpha$ 为何值，幂函数 $y = x^{\alpha}$ 的图象必过定点 $(1, 1)$．请证明并说明图象还经过哪些与 $\alpha$ 取值有关的定点．

**规范解答**：
$1^{\alpha} = 1$ 对所有 $\alpha$ 成立，故 $(1, 1)$ 是公共定点．
$0^{\alpha} = 0$（当 $\alpha > 0$ 时），故 $(0, 0)$ 是 $\alpha > 0$ 时的定点．
$(-1)^{\alpha} = 1$（当 $\alpha$ 为偶数时），$= -1$（当 $\alpha$ 为奇数时），故 $(-1, \pm 1)$ 也是常见定点．

**方法提炼**：幂函数定点问题 → 代入 $x = 0, 1, -1$ 验证，分类讨论 $\alpha$ 的奇偶性和正负．

## 101星思维挑战

## 七、101星思维挑战

### 1. 对号函数 y=x+1/x 的拆解
两个幂函数 x¹ 和 x⁻¹ 的叠加。为什么它在 (1,+∞) 递增而在 (0,1) 递减？

### 2. 指数大小的「临界争夺」
比较 x² 与 x³。在 (0,1) 区间和 (1,+∞) 区间，谁跑得更快？为什么在 (1,1) 点发生「位次交换」？

### 2. 幂函数图象的对称性
**挑战问题**：为什么 $y=x^2$ 和 $y=x^4$ 的图象关于 $y$ 轴对称，而 $y=x^3$ 关于原点对称？
**思考引导**：偶次幂→偶函数→关于 $y$ 轴对称；奇次幂→奇函数→关于原点对称．
