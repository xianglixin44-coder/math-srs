# 两点间的距离公式
**分类**: 选择性必修第一册

## 核心概念界定

## 一、核心概念界定

### 1. 两点间距离公式
* **代数表达式**：已知两点 $P_1(x_1, y_1)$ 和 $P_2(x_2, y_2)$，则：$$|P_1P_2| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$$
* **特殊情形**：原点 $O(0, 0)$ 与任一点 $P(x, y)$ 间的距离：$|OP| = \sqrt{x^2 + y^2}$。

### 2. 向量模的映射
* 距离公式本质上是向量 $\vec{P_1P_2}$ 的模长：$|\vec{P_1P_2}| = \sqrt{\vec{P_1P_2} \cdot \vec{P_1P_2}}$。

## 解题策略与方法论

## 二、坐标法解决几何问题的 SOP

1. **建系**：建立适当的平面直角坐标系，用坐标表示问题中的几何要素。
2. **坐标化**：根据题目给出的几何性质（如中点、平行等）设定点的坐标。
3. **公式执行**：利用距离公式将几何长度转化为坐标的算术平方和运算。
4. **结果还原**：将代数运算得出的数值关系"翻译"回几何结论。

### 判定分叉
* **求定点**：若已知距离相等（如 $|PA| = |PB|$），通过联立距离平方的等式解方程。
* **求轨迹**：若动点满足特定距离比例，则通过距离公式建立 $x, y$ 的方程。

## 易错点与风险规避

## 三、易错点与风险规避

### 1. 坐标相减的符号陷阱
* **陷阱描述**：在计算 $(x_2-x_1)^2$ 时处理不当导致数值错误。
* **避坑策略**：坚持"终点坐标减起点坐标"的原则，利用平方的性质进行自检。

### 2. 忘记"去根号"平方
* **陷阱描述**：在列 $|PA| = |PB|$ 的方程时，直接带根号运算，增加计算复杂度。
* **避坑策略**：优先使用距离的平方 $|PA|^2 = |PB|^2$ 进行列式，消去二次根式。

### 3. 建系不当导致运算冗余
* **陷阱描述**：选择不具有对称性的点作为原点，导致坐标中含有过多非零变量。
* **避坑策略**：优先以对称中心、直角顶点或底边中点作为坐标原点。

## 经典例题精讲

## 五、经典例题精讲

### [例题 1] 证明平行四边形性质
**题目**：用坐标法证明平行四边形两条对角线的平方和等于两条邻边的平方和的两倍。

**规范解答**：
设 $A(0,0), B(a,0), D(b,c)$，则 $C(a+b, c)$。
$|AC|^2 + |BD|^2 = [(a+b)^2 + c^2] + [(b-a)^2 + c^2] = 2a^2 + 2b^2 + 2c^2$
$2(|AB|^2 + |AD|^2) = 2(a^2 + b^2 + c^2)$。等式成立，证毕。

**方法提炼**：通过巧妙建系，将几何证明简化为简单的多项式展开。

### [例题 2] 求等距点
**题目**：在 $x$ 轴上求一点 $P$，使 $|PA| = |PB|$，其中 $A(1,2), B(3,4)$。

**规范解答**：
设 $P(x,0)$，$|PA|^2 = (x-1)^2 + 4$，$|PB|^2 = (x-3)^2 + 16$。
令相等：$(x-1)^2 + 4 = (x-3)^2 + 16$ → $x^2-2x+1+4 = x^2-6x+9+16$ → $4x = 20$ → $x=5$。
$\therefore P(5,0)$。

**方法提炼**：等距条件 → 距离平方相等 → 解一元一次方程。

## 101星思维挑战

## 七、101星思维挑战

### 1. 曼哈顿距离的几何异构
**挑战问题**：若规定平面内两点间的"距离"为 $d = |x_1-x_2| + |y_1-y_2|$（曼哈顿距离），那么到原点距离等于 1 的点的轨迹是什么形状？
**思考引导**：对比欧几里得距离下的圆形轨迹，思考绝对值求和在坐标系中的翻折逻辑——答案是倾斜 45° 的正方形。

### 2. 距离平方和的最值点
**挑战问题**：已知 $A, B$ 两定点，在直线 $l$ 上求一点 $P$，使得 $|PA|^2 + |PB|^2$ 最小。这个点 $P$ 是否一定是 $A, B$ 在直线 $l$ 上投影的中点？
**思考引导**：设点 $P$ 坐标为变量，利用二次函数的配方法分析其极值取得的代数条件。
