# 三角函数的概念
**分类**: 高一数学-第一册-三角函数

## 核心概念界定

## 一、核心概念界定

### 1. 任意角三角函数的定义（单位圆定义法）
在直角坐标系中，设 $\alpha$ 是一个任意角，它的顶点与原点重合，始边与 $x$ 轴的非负半轴重合．设角 $\alpha$ 的终边与**单位圆**（半径为 $1$ 的圆）相交于点 $P(x, y)$，则：
*   **正弦函数**：点 $P$ 的纵坐标 $y$ 叫做 $\alpha$ 的正弦，记作 $\sin \alpha = y$．
*   **余弦函数**：点 $P$ 的横坐标 $x$ 叫做 $\alpha$ 的余弦，记作 $\cos \alpha = x$．
*   **正切函数**：点 $P$ 的纵坐标 $y$ 与横坐标 $x$ 的比值 $\frac{y}{x}$ 叫做 $\alpha$ 的正切，记作 $\tan \alpha = \frac{y}{x}$（条件为 $x \neq 0$）．

### 2. 任意圆定义法（广义定义）
设 $\alpha$ 是一个任意角，其终边上任意一点 $P$（不与原点重合）的坐标为 $(x, y)$，点 $P$ 与原点的距离为 $r = \sqrt{x^2 + y^2} > 0$．则：
$$\sin \alpha = \frac{y}{r}, \quad \cos \alpha = \frac{x}{r}, \quad \tan \alpha = \frac{y}{x} \ (x \neq 0)$$

### 3. 函数要素约束
*   **定义域**：正弦函数与余弦函数的定义域均为 $\mathbb{R}$；正切函数的定义域为 $\{\alpha \mid \alpha \neq k\pi + \frac{\pi}{2}, k \in \mathbb{Z}\}$．
*   **值域**：正弦与余弦函数值域均为 $[-1, 1]$，正切函数值域为 $\mathbb{R}$．

## 解题策略与方法论

## 二、解题策略与方法论

### 1. 坐标法求三角函数值 SOP
当已知角 $\alpha$ 终边上一点 $P(x, y)$ 时，执行以下步骤：
1.  **计算模长**：利用公式 $r = \sqrt{x^2 + y^2}$ 计算点 $P$ 到原点的距离．
2.  **代入比值**：直接根据定义写出 $\sin \alpha = \frac{y}{r}$，$\cos \alpha = \frac{x}{r}$，$\tan \alpha = \frac{y}{x}$．
3.  **约分化简**：若坐标含根号，需进行分母有理化．

### 2. 三角函数符号判定决策路径
判断三角函数值在不同象限的符号：
*   **正弦 $\sin \alpha$ **：看纵坐标 $y$ 的正负．第一、二象限为正，第三、四象限为负．
*   **余弦 $\cos \alpha$ **：看横坐标 $x$ 的正负．第一、四象限为正，第二、三象限为负．
*   **正切 $\tan \alpha$ **：看 $x, y$ 是否同号．第一、三象限（同号）为正，第二、四象限（异号）为负．

## 易错点与风险规避

## 三、易错点与风险规避

### 1. 忽略正切函数的定义域限制
*   **陷阱描述**：在讨论终边在 $y$ 轴上的角（如 $90^\circ, 270^\circ$）时，误认为其正切值存在．
*   **具体反例**：当 $\alpha = \frac{\pi}{2}$ 时，终边与单位圆交于 $(0, 1)$，此时分母 $x=0$，$\tan \frac{\pi}{2}$ **无意义**．
*   **避坑策略**：凡涉及 $\tan \alpha$ 的运算或方程，首要步骤是排查终边是否落在 $y$ 轴上．

### 2. 坐标与比值关系张冠李戴
*   **陷阱描述**：在非单位圆（$r \neq 1$）的情况下，直接将纵横坐标当作函数值．
*   **具体反例**：角 $\alpha$ 终边过点 $(3, 4)$，误认 $\sin \alpha = 4$．
*   **避坑策略**：必须先求出 $r = \sqrt{3^2 + 4^2} = 5$，则 $\sin \alpha = \frac{4}{5}$．

### 3. 象限角与轴线角的混淆
*   **陷阱描述**：在判定符号时，忽略了终边在坐标轴上的情况．
*   **具体反例**：$\alpha = \pi$，其终边在 $x$ 轴负半轴，不属于任何象限，此时 $\sin \pi = 0$．
*   **避坑策略**：轴线角的三角函数值通常为 $0, 1, -1$ 或无意义，需单独记忆．

## 多维原理解码

## 四、多维原理解码

![[05-02-01-unit-circle-def.png]]

*   **代数/逻辑视阈**：三角函数本质上是**实数集到实数集的映射**．通过引入单位圆，角 $\alpha$ 的弧度数（实数）被映射到圆周上的点坐标，从而实现了几何图形与代数数值的完美统一，这消除了角度制下「度」与「值」单位不统一的逻辑障碍．
*   **几何/直观视阈**：在单位圆中，$\sin \alpha$ 是点 $P$ 在 $y$ 轴上的**有向投影**，$\cos \alpha$ 是在 $x$ 轴上的**有向投影**．这种投影视角解释了为什么函数值会随角旋转而呈现周期性的 $-1$ 到 $1$ 之间的波动．
*   **物理/现实视阈**：三角函数是刻画**简谐运动**和**交流电**的数学元语言．例如，单摆离开平衡位置的位移、电压随时间的变化，其本质都是质点在圆周运动时其坐标在直线上的投影演化．

## 经典例题精讲

## 五、经典例题精讲

### [例题 1]
**题目**：已知角 $\alpha$ 的终边经过点 $P(-3, 4)$，求角 $\alpha$ 的正弦、余弦及正切值．

**深度分析**：
本题属于「已知终边上一点求值」的典型场景．突破口在于计算点 $P$ 到原点的距离 $r$，然后严格按照任意角三角函数的广义定义（SOP）进行代入．

**规范解答**：
1.  **计算距离**：由已知点 $P(x, y) = (-3, 4)$，得 $x = -3, y = 4$．
    $$r = \sqrt{x^2 + y^2} = \sqrt{(-3)^2 + 4^2} = \sqrt{9 + 16} = 5$$
2.  **求正弦值**：$\sin \alpha = \frac{y}{r} = \frac{4}{5}$．
3.  **求余弦值**：$\cos \alpha = \frac{x}{r} = \frac{-3}{5} = -\frac{3}{5}$．
4.  **求正切值**：$\tan \alpha = \frac{y}{x} = \frac{4}{-3} = -\frac{4}{3}$．

**方法提炼**：
三角函数值仅取决于终边的**位置（斜率）**，与点 $P$ 在终边上的远近无关．

### [例题 2] 利用定义求三角函数值
**题目**：已知角 $\alpha$ 的终边经过点 $P(-3, 4)$，求 $\sin\alpha, \cos\alpha, \tan\alpha$ 的值．

**规范解答**：
$r = \sqrt{(-3)^2 + 4^2} = 5$
$$\sin\alpha = \frac{y}{r} = \frac{4}{5}, \quad \cos\alpha = \frac{x}{r} = -\frac{3}{5}, \quad \tan\alpha = \frac{y}{x} = -\frac{4}{3}$$

**方法提炼**：终边上任意点 $P(x,y)$ → $r = \sqrt{x^2+y^2}$ → $\sin\alpha = \frac{y}{r}, \cos\alpha = \frac{x}{r}, \tan\alpha = \frac{y}{x}$．这是三角函数最原始的定义．

## 101星思维挑战

## 七、101星思维挑战

### 1. 正切线的几何探究
**挑战问题**：在单位圆中，过点 $A(1, 0)$ 作垂直于 $x$ 轴的切线，与角 $\alpha$ 的终边相交于点 $T$．请证明线段 $AT$ 的有向长度即为 $\tan \alpha$．若角 $\alpha$ 的终边在第二象限，该结论如何通过向量形式表述？
**思考引导**：利用相似三角形 $\triangle OMP \sim \triangle OAT$，将比值 $\frac{y}{x}$ 转化为线段长度的比值．

### 2. 反函数关系的延伸
**挑战问题**：已知指数函数 $y = a^x$ 与对数函数 $y = \log_a x$ 互为反函数．那么，在区间 $[-\frac{\pi}{2}, \frac{\pi}{2}]$ 上，正弦函数 $y = \sin x$ 是否也存在「反向对应」的关系？这种对应关系在物理波动分析中有什么意义？
**思考引导**：关注映射的一一对应性，探讨定义域限制对函数存在性的边界作用．
