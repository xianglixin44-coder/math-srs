# 概率的性质
**分类**: 高一数学-第二册

## 核心概念界定

## 一、核心性质概览

基于古典概型与事件运算，概率具有以下六大核心性质：

1. **非负性**：对任意事件 $A$，有 $P(A) \ge 0$。
2. **必然与不可能事件**：$P(\Omega) = 1$，$P(\emptyset) = 0$ 。
3. **互斥事件加法公式**：若 $A$ 与 $B$ 互斥 ($A \cap B = \emptyset$)，则 **$P(A \cup B) = P(A) + P(B)$ ** 。
   * **推广**：若 $A_1, \dots, A_m$ 两两互斥，则并事件概率等于概率之和。
4. **对立事件性质**：**$P(A) = 1 - P(\bar{A})$ ** ——处理"至少"问题的代数利器．
5. **单调性**：若 $A \subseteq B$，则 $P(A) \le P(B)$；由此可得 $0 \le P(A) \le 1$。
6. **广义加法公式**：对任意事件 $A, B$，有 **$P(A \cup B) = P(A) + P(B) - P(A \cap B)$ ** ．

## 解题策略与方法论

## 二、解题策略

### 1. "正难则反"策略
当正面计算事件 $A$ 的概率包含多种互斥情形时：
* **寻找对立面**：识别 $\bar{A}$ 是否更易计数（如"不中奖"仅一种情形）．
* **执行扣减**：利用 $1 - P(\bar{A})$ 快速得出结果．

### 2. 并事件的"容斥"模型
处理并事件 $P(A \cup B)$ 时，必须先行判定 $A, B$ 是否互斥 [10:537, 539]：
* **若互斥**：直接求和．
* **若不互斥**：必须减去重叠部分 $P(A \cap B)$，防止重复计数．

## 易错点与风险规避

## 三、易错点与风险规避

### 1. 混淆"互斥"与"对立"
* **陷阱**：认为 $P(A) + P(B) = 1$ 时 $A, B$ 必互为对立事件．
* **避坑**：$P(A) + P(B) = 1$ 只是对立的必要条件——还需 $A \cup B = \Omega$ [10:522, 538]．

### 2. 忽视广义加法的"扣减"项
* **陷阱**：计算非互斥事件的并集概率时习惯性直接相加．
* **纠正**：必须先检查 $A \cap B$ 是否为空——若不为空，直接加会重复计算交集．

## 多维原理解码

## 四、多维原理解码

* **代数视阈**：概率性质建立了从**集合测度**到数值区间 $[0,1]$ 的映射。性质 3 对应测度的"可加性"，性质 5 对应集合包含的"序关系" [10:537-539]。
* **几何视阈**：可以将概率想象为样本空间区域的**面积**。性质 6 本质上是两个重叠图形面积合并时的"容斥原理"：总面积 = A 面积 + B 面积 - 交集面积．

## 经典例题精讲

## 五、经典例题精讲

### [例题 1] 促销抽奖的中奖概率
**题目**：一箱 6 罐饮料中有 2 罐中奖。随机抽 2 罐，求中奖概率。

**规范解答**：
正面：$n(\Omega) = 6 \times 5 = 30$（有序、不放回）．
中奖 = 一中一不中 + 两都中 = $(2\times4\times2 + 4\times2) + (2\times1) = 16 + 2 = 18$ → $P = 18/30 = 0.6$．
逆向（更简）：对立事件"两罐均不中"→ $n(\bar{A}) = 4 \times 3 = 12$ → $P(A) = 1 - 12/30 = 0.6$．

**方法提炼**：涉及"至少"、"含有"等词汇，优先考虑对立事件性质 $P(A) = 1 - P(\bar{A})$．

### [例题 2] 广义加法
**题目**：$P(A)=0.6, P(B)=0.5, P(AB)=0.3$，求 $P(A \cup B)$ 和 $P(\bar{A} \cup \bar{B})$．

**规范解答**：
$P(A \cup B) = 0.6 + 0.5 - 0.3 = 0.8$（广义加法）．
$P(\bar{A} \cup \bar{B}) = P(\overline{AB}) = 1 - P(AB) = 1 - 0.3 = 0.7$（德摩根律）．

**方法提炼**：德摩根律 $\overline{A \cap B} = \bar{A} \cup \bar{B}$ 是连接交事件和并事件的桥梁．

## 101星思维挑战

## 七、101星思维挑战

### 1. 概率为 0 的事件不一定不可能
**挑战问题**：在 $[0,1]$ 随机取一点，事件"恰好取到 0.5"的概率是多少？这是不可能事件吗？
**思考引导**：连续型随机变量中，单点概率为 0，但它确实可能发生——这挑战了"概率为 0 = 不可能"的直觉．

### 2. 容斥原理的推广
**挑战问题**：推导三个事件 $A,B,C$ 的并事件概率公式 $P(A \cup B \cup C)$．
**思考引导**：两次运用广义加法公式——先合并两个，再与第三个合并，展开得 $P(A)+P(B)+P(C) - P(AB) - P(AC) - P(BC) + P(ABC)$．
