# 平面向量的坐标表示
**分类**: 高一数学-第二册-平面向量及其应用

## 核心概念界定

## 一、核心概念界定

### 1. 平面向量的坐标定义
在平面直角坐标系中，分别取与 $x$ 轴、$y$ 轴方向相同的两个单位向量 $\vec{i}, \vec{j}$ 作为基底．对于平面内任一向量 $\vec{a}$，由平面向量基本定理可知，有且只有一对实数 $x, y$，使得：
$$\vec{a} = x\vec{i} + y\vec{j}$$
这一有序数对 $(x, y)$ 叫做向量 $\vec{a}$ 的**坐标表示**，记作 $\vec{a} = (x, y)$．
*   $\vec{i} = (1, 0)$，$\vec{j} = (0, 1)$，$\vec{0} = (0, 0)$．

### 2. 向量坐标与点坐标的一一对应
以原点 $O$ 为起点作 $\vec{OA} = \vec{a}$，则点 $A$ 的坐标 $(x, y)$ 就是向量 $\vec{a}$ 的坐标．

## 解题策略与方法论

## 二、解题策略与方法论

### 1. 向量线性运算的坐标 SOP
*   **加法**：$\vec{a} + \vec{b} = (x_1 + x_2, y_1 + y_2)$
*   **减法**：$\vec{a} - \vec{b} = (x_1 - x_2, y_1 - y_2)$
*   **数乘**：$\lambda \vec{a} = (\lambda x_1, \lambda y_1)$

### 2. 任意向量的坐标转换
已知起点 $A(x_1, y_1)$ 和终点 $B(x_2, y_2)$：
$$\vec{AB} = (x_2 - x_1, y_2 - y_1)$$

### 3. 共线（平行）的坐标判据
$\vec{a} = (x_1, y_1)$ 与 $\vec{b} = (x_2, y_2)$ 共线 $\iff x_1y_2 - x_2y_1 = 0$．

## 易错点与风险规避

## 三、易错点与风险规避

### 1. 减法运算的「起终」顺序颠倒
*   **陷阱描述**：在计算 $\vec{AB}$ 时，错误地用 $A$ 点坐标减去 $B$ 点坐标．
*   **避坑策略**：$\vec{AB} = B - A$（终点减起点）．

### 2. 混淆点坐标与向量坐标
*   **陷阱描述**：向量 $(x, y)$ 可以位于平面的任何位置（自由向量），只有当起点在原点时终点坐标才是 $(x, y)$．

### 3. 共线判定中的分母为零风险
*   **陷阱描述**：使用 $\frac{x_1}{x_2} = \frac{y_1}{y_2}$ 判定平行，当坐标含零时分母为 0 失效．
*   **避坑策略**：强制使用交叉相乘式 $x_1y_2 - x_2y_1 = 0$．

## 多维原理解码

## 四、多维原理解码

![[06-03-02-coord-def.png]]

*   **代数/逻辑视阈**：坐标表示实现了几何对象的「数字化脱壳」．它将复杂的空间指向逻辑转化为简单的实数对算术，使得几何证明可以程序化地通过代数运算完成．
*   **几何/直观视阈**：坐标系是平面上的「度量骨架」．通过正交分解，任何一个斜向的向量都被拆解为水平和垂直两个分量．
*   **物理/现实视阈**：坐标表示是「分量合成」的数学模型．导航中的经纬度分解、工程力学中的斜面拉力分解，本质都是向量的正交坐标化．

## 经典例题精讲

## 五、经典例题精讲

### [例题 1] 平行四边形第四顶点的求解
**题目**：$A(-2, 1), B(-1, 3), C(3, 4)$，求平行四边形 $ABCD$ 的顶点 $D$．

**规范解答**：
1.  设 $D(x, y)$．
2.  $\vec{AB} = (1, 2)$，$\vec{DC} = (3-x, 4-y)$．
3.  由 $\vec{AB} = \vec{DC}$ 得 $\begin{cases} 1 = 3 - x \\ 2 = 4 - y \end{cases}$．
4.  解得 $x = 2, y = 2$．

**方法提炼**：「设点 → 构向量 → 列方程 → 解坐标」四步 SOP．

![[06-03-02-parallelogram.png]]

### [例题 2] 坐标表示与运算
**题目**：已知 $A(1, 2), B(4, 6)$，求 $\overrightarrow{AB}$ 的坐标及 $|\overrightarrow{AB}|$．

**规范解答**：
$\overrightarrow{AB} = (4-1, 6-2) = (3, 4)$
$|\overrightarrow{AB}| = \sqrt{3^2 + 4^2} = 5$

**方法提炼**：$\overrightarrow{AB} = (x_B - x_A, y_B - y_A)$，模长 $|\overrightarrow{AB}| = \sqrt{(x_B-x_A)^2 + (y_B-y_A)^2}$．

## 101星思维挑战

## 七、101星思维挑战

### 1. 坐标平移的不变性探究
**挑战问题**：已知向量 $\vec{a} = (x, y)$，若将坐标轴沿向量 $\vec{v} = (h, k)$ 进行平移，新坐标系下的向量 $\vec{a}'$ 的坐标是否会发生变化？
**思考引导**：向量坐标代表的是「相对位移」而非「绝对位置」．

### 2. 定比分点的代数推导
**挑战问题**：利用坐标表示证明 $\vec{AP} = \lambda \vec{PB}$ 的充要条件是 $x = \frac{x_1 + \lambda x_2}{1 + \lambda}, y = \frac{y_1 + \lambda y_2}{1 + \lambda}$．
**思考引导**：这是定比分点公式的向量推导，体现坐标表示在离散几何中的精密控制力．
