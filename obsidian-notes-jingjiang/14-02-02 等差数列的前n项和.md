# 等差数列的前n项和
**分类**: 选择性必修第二册

## 核心概念界定

## 一、核心概念界定

### 1. 前 $n$ 项和的定义
* $S_n = a_1 + a_2 + \dots + a_n$

### 2. 等差数列前 $n$ 项和公式
* **末项式**：已知首项 $a_1$ 和末项 $a_n$：$$S_n = \frac{n(a_1 + a_n)}{2}$$
* **公差式**：已知首项 $a_1$ 和公差 $d$：$$S_n = na_1 + \frac{n(n-1)}{2}d$$

### 3. 数值特征映射
* **平均数性质**：$\frac{S_n}{n} = \frac{a_1 + a_n}{2}$，前 $n$ 项的平均数等于首末两项的算术平均。
* **二次函数结构**：当 $d \neq 0$ 时，$S_n = An^2 + Bn$（其中 $A = \frac{d}{2}, B = a_1 - \frac{d}{2}$）。

## 解题策略与方法论

## 二、倒序相加法 SOP

1. **正序排列**：$S_n = a_1 + a_2 + \dots + a_n$。
2. **倒序排列**：$S_n = a_n + a_{n-1} + \dots + a_1$。
3. **垂直对冲**：两式对应项相加，$a_1+a_n = a_2+a_{n-1} = \dots$ 恒为常数。
4. **算子化简**：$2S_n = n(a_1 + a_n)$ → $S_n = \frac{n(a_1 + a_n)}{2}$。

### $S_n$ 最值的判定路径
* **路径 A（项号临界法）**：若 $a_1 > 0, d < 0$，求出满足 $a_n \ge 0$ 的最大正整数 $n_0$，$S_{n_0}$ 为最大值。
* **路径 B（函数对称轴法）**：$S_n$ 看作关于 $n$ 的二次函数，最值在离对称轴最近的整数处取得。

## 易错点与风险规避

## 三、易错点与风险规避

### 1. $a_n$ 与 $S_n$ 转换中的"$n=1$ 孤岛"
* **陷阱描述**：利用 $a_n = S_n - S_{n-1}$ 计算通项时忽略 $n=1$ 的特殊性。
* **避坑策略**：强制分段校验：先算 $a_1 = S_1$，再算 $n \ge 2$ 的通用式，最后验证 $n=1$ 是否符合。

### 2. 忽略 $d=0$ 的退化情形
* **陷阱描述**：默认 $d \neq 0$，导致分母为零或逻辑遗漏。
* **避坑策略**：公差含参时优先讨论常数列。

### 3. 二次函数对称轴的非整数性
* **陷阱描述**：误认为 $S_n$ 的最值一定在对称轴处取得，忽略 $n \in \mathbb{N}^*$。
* **避坑策略**：对称轴为 5.5 时 $n=5,6$ 同取最值；为 5.1 时仅 $n=5$ 取最值。

## 多维原理解码

## 四、多维原理解码

![[14-02-02-arithmetic-sum.png]]

* **代数/逻辑视阈**：等差求和是**"离散积分"**的一种表现。"倒序对冲"将线性增长的瞬时值转化为总量，使 $n$ 次加法坍缩为一次乘法。
* **几何/直观视阈**：$S_n = \frac{n(a_1+a_n)}{2}$ 与**梯形面积公式** $S = \frac{(a+b)h}{2}$ 完全同构。等差数列的项是分布在直线上的离散点，$S_n$ 对应"离散梯形"的总高度。
* **物理/现实视阈**：对应**初速度不为零的匀变速直线运动的位移**。$x = v_0 t + \frac{1}{2}at^2$ 与 $S_n = a_1 n + \frac{d}{2}n(n-1)$ 在结构上完美契合。

## 经典例题精讲

## 五、经典例题精讲

### [例题 1] 含有 $S_n$ 约束的基本量求解
**题目**：已知等差数列前 10 项和为 310，前 20 项和为 1220。求 $a_1$ 和 $d$。

**规范解答**：
$S_{10}: 10a_1 + 45d = 310$；$S_{20}: 20a_1 + 190d = 1220$。
$(1)\times2$：$20a_1 + 90d = 620$。相减：$100d = 600$ → $d = 6$。
代入：$10a_1 + 270 = 310$ → $a_1 = 4$。

**方法提炼**：知二求二 → 列 $S_n$ 方程组 → 消元解 $a_1, d$。

### [例题 2] $S_n$ 最值问题
**题目**：等差数列 $a_1 = 25, d = -4$，求 $S_n$ 的最大值。

**规范解答**：
$a_n = 25 - 4(n-1) = 29 - 4n$。令 $a_n \ge 0$ → $n \le 7.25$。
$n=7$ 时 $a_7 = 1 > 0$，$n=8$ 时 $a_8 = -3 < 0$。
$\therefore S_7$ 最大。$S_7 = \frac{7(25+1)}{2} = 91$。

**方法提炼**：$a_1>0, d<0$ → 找最后一个非负项 $n_0$ → $S_{n_0}$ 最大。

## 101星思维挑战

## 七、101星思维挑战

### 1. $S_n$ 结构的"算术平均"特征
**挑战问题**：证明若 $\{a_n\}$ 是等差数列，则 $\{ \frac{S_n}{n} \}$ 也是等差数列，并求出其公差。
**思考引导**：$\frac{S_n}{n} = a_1 + \frac{n-1}{2}d = (a_1 - \frac{d}{2}) + \frac{d}{2}n$，这是关于 $n$ 的一次函数 → 公差为 $\frac{d}{2}$。

### 2. 奇偶项求和的对称平衡
**挑战问题**：等差数列项数为 $2n+1$（奇数项），证明奇数项和与偶数项和之比为 $\frac{n+1}{n}$。
**思考引导**：中间项 $a_{n+1}$ 在奇数项中出现 1 次（共 $n+1$ 个奇数项），在偶数项中出现 0 次（共 $n$ 个偶数项）。
