# 平面向量的加法运算
**分类**: 高一数学-第二册-平面向量及其应用

## 核心概念界定

## 一、核心概念界定

### 1. 向量加法的定义
求两个向量和的运算，叫做向量的加法．它通过对物理学中位移的合成或力的合成进行数学抽象而得．对于零向量与任意向量 $\vec{a}$，规定 $\vec{a} + \vec{0} = \vec{0} + \vec{a} = \vec{a}$．

### 2. 向量加法的运算法则
*   **三角形法则**：已知非零向量 $\vec{a}, \vec{b}$，在平面内取任意一点 $A$，作 $\vec{AB} = \vec{a}, \vec{BC} = \vec{b}$，则 $\vec{AC}$ 叫做 $\vec{a}$ 与 $\vec{b}$ 的和，记作 $\vec{a} + \vec{b} = \vec{AC}$．核心是「首尾相接」．
*   **平行四边形法则**：以同一点 $O$ 为起点的两个已知向量 $\vec{a}, \vec{b}$，以 $OA, OB$ 为邻边作平行四边形，则以 $O$ 为起点的对角线向量即为 $\vec{a} + \vec{b}$．核心是「共起点」．

### 3. 运算律与三角不等式
*   **交换律**：$\vec{a} + \vec{b} = \vec{b} + \vec{a}$
*   **结合律**：$(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$
*   **三角不等式**：$|\vec{a} + \vec{b}| \le |\vec{a}| + |\vec{b}|$，当且仅当方向相同时等号成立．

## 解题策略与方法论

## 二、解题策略与方法论

### 1. 几何求和 SOP
1.  **法则匹配**：若向量「首尾相接」→ 三角形法则；若「共起点」→ 平行四边形法则．
2.  **平移降维**：若不相接也不共起点，利用自由平移性转化为符合法则的位置．
3.  **结果合成**：多个向量求和时，重复三角形法则串联，结果为起点指向最终终点的向量．

### 2. 实际应用决策路径（速度合成）
*   **步骤一**：将各分速度转化为向量表示．
*   **步骤二**：在直角三角形中利用勾股定理计算合速度大小，三角函数确定方向．
*   **步骤三**：检查合速度方向是否符合物理直觉．

## 易错点与风险规避

## 三、易错点与风险规避

### 1. 混淆「首尾相接」与「共起点」
*   **陷阱描述**：在应用三角形法则时，错误地将两个向量的起点连接．
*   **避坑策略**：加法首尾接，结果起指终；减法共起点，结果后指前．

### 2. 忽略共线向量的特殊性
*   **陷阱描述**：盲目尝试画平行四边形处理共线向量．
*   **避坑策略**：共线向量加法退化为数轴上的标量加减，直接在直线上按方向叠加长度．

### 3. 模长等号判别
*   **陷阱描述**：认为 $|\vec{a} + \vec{b}| = |\vec{a}| + |\vec{b}|$ 恒成立．
*   **避坑策略**：只有方向相同时（$\theta = 0^\circ$）等号才成立．

## 多维原理解码

## 四、多维原理解码

![[06-02-01-vector-chain.png]]

*   **代数/逻辑视阈**：向量加法定义了一套不同于实数的运算协议．它将「大小」和「方向」两个维度的变化同时封装在一个算子中．交换律和结合律保证了向量空间在线性变换下的逻辑稳定性．
*   **几何/直观视阈**：加法是「路径的连续性」．三角形法则是位移的直接写照——从 A 经 B 到 C，总位移只取决于始末位置．
*   **物理/现实视阈**：它是「效应合成」的数学表达．船在流水中的实际速度、物体受力的平衡分析，都代表了多个物理场对同一对象作用的最终叠加结果．

## 经典例题精讲

## 五、经典例题精讲

### [例题 1] 船只跨河的实际速度计算
**题目**：一艘船从南岸出发，垂直于对岸航行，航行速度 $v_1 = 15 \text{ km/h}$，江水向东流速 $v_2 = 6 \text{ km/h}$．求船实际航行速度的大小与方向．

**深度分析**：船速与水速相互垂直，构成直角三角形的两条直角边．合速度为斜边向量，符合平行四边形法则．

**规范解答**：
1.  设 $\vec{AB}$ 表示水速，$\vec{AD}$ 表示船速．
2.  以 $AB, AD$ 为邻边作矩形 $ABCD$，则对角线 $\vec{AC}$ 为合速度．
3.  在 $Rt\triangle ABC$ 中：
    $$ |\vec{AC}| = \sqrt{6^2 + 15^2} = \sqrt{261} \approx 16.2 \text{ km/h} $$
4.  设合速度与水流方向夹角为 $\theta$，$\tan \theta = \frac{15}{6} = 2.5$，$\theta \approx 68^\circ$．

**方法提炼**：将物理运动分解为正交向量，利用几何运算还原整体．

### [例题 2] 向量减法
**题目**：已知 $\overrightarrow{OA} = \vec{a}, \overrightarrow{OB} = \vec{b}$，用 $\vec{a}, \vec{b}$ 表示 $\overrightarrow{BA}$．

**规范解答**：
$$\overrightarrow{BA} = \overrightarrow{OA} - \overrightarrow{OB} = \vec{a} - \vec{b}$$

**方法提炼**：向量减法口诀——「终点减起点」：$\overrightarrow{MN} = \overrightarrow{ON} - \overrightarrow{OM}$．减去的向量指向被减向量的起点．

## 101星思维挑战

## 七、101星思维挑战

### 1. 多边形法则的推广
**挑战问题**：证明在任意 $n$ 边形 $A_1A_2...A_n$ 中，恒有 $\vec{A_1A_2} + \vec{A_2A_3} + \dots + \vec{A_{n-1}A_n} + \vec{A_nA_1} = \vec{0}$．
**思考引导**：利用三角形法则的迭代过程．当终点回到起点时，位移的物理意义为总位移为零．

### 2. 向量和的最大值与最小值
**挑战问题**：已知 $|\vec{a}| = 2, |\vec{b}| = 3$，求 $|\vec{a} + \vec{b}|$ 的取值范围，并描述取得最值时的几何位置．
**思考引导**：结合三角不等式 $||\vec{a}| - |\vec{b}|| \le |\vec{a} + \vec{b}| \le |\vec{a}| + |\vec{b}|$．
