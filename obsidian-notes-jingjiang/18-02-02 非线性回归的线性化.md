# 非线性回归的线性化
**分类**: 选择性必修第三册

## 核心概念界定

## 一、 核心概念界定

### 1. 非线性相关关系
* **数学描述**：如果两个变量具有相关性，但散点图中的点分布在某条曲线（对数曲线、指数曲线、幂函数曲线等）附近，则称为**非线性相关** [12:333, 367]。
* **逻辑特征**：变量间的趋势具有"弯曲度"或"加速/减速"特征，一元线性模型无法捕捉 [12:366, 367]。

### 2. 线性化变换
* **定义**：通过**变量代换**（换元法），将非线性模型转化为一元线性回归模型 [12:367, 368]。
* **核心算子**：对数变换（$\ln y$ 或 $\ln x$）、倒数变换（$1/x$）或平方根变换 [12:367]。

### 3. 决定系数 $R^2$
* **代数表达式**：$R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$ [12:370, 371]。
* **统计意义**：$R^2$ 越大（越接近 1），残差平方和越小，模型的拟合效果越好 [12:371]。

## 解题策略与方法论

## 二、 解题策略与方法论

### 非线性回归建模的 SOP [12:367, 370]
1.  **形态识别**：绘制散点图，若呈"下凸"、"上凸"或"指数爆炸"则判定为非线性 [12:366, 367]。
2.  **模型选型**：
    *   指数型 $y = c e^{kx}$ → $\ln y = \ln c + kx$ [12:367]
    *   对数型 $y = c_1 + c_2 \ln x$ → 令 $t = \ln x$ [12:367]
    *   幂函数型 $y = ax^b$ → $\ln y = \ln a + b \ln x$ [12:367]
3.  **变量代换**：定义中间变量（$z = \ln y$ 或 $t = \ln x$）[12:368]。
4.  **线性回归**：对新数据执行最小二乘法 [12:368]。
5.  **还原与评价**：代回原变量得到非线性方程，用 $R^2$ 比较拟合效果 [12:369, 371]。

## 易错点与风险规避

## 三、 易错点与风险规避

### 1. "化曲为直"后的定义域遗失
* **陷阱描述**：进行对数变换（$x = \ln t$）时，忽略 $t > 0$ 的限制。
* **具体反例**：百米纪录研究中令 $x = \ln(t-1895)$，必须确保所有年份 $t > 1895$ [12:367]。
* **避坑策略**：代换后立即写出新变量的取值范围。

### 2. $R^2$ 的"盲目崇拜"
* **陷阱描述**：只看 $R^2$ 大小，忽略模型在样本范围外的物理合理性。
* **具体反例**：样本内 $R^2 = 0.99$，但外推预测出现"身高为负"等荒谬结论 [12:373]。
* **避坑策略**：执行"外推风险检查" [12:373]。

### 3. 残差分布的"规律性"残留
* **陷阱描述**：线性化后未检查残差图，模型仍包含未被提取的非线性信息 [12:366]。
* **避坑策略**：若残差图仍呈抛物线或函数形状，需更换模型 [12:361, 367]。

## 多维原理解码

## 四、 多维原理解码

![[18-02-02-nonlinear-regression.png]]

* **代数/逻辑视阈**：线性化是**"算子同构"的体现** [12:368]。通过对数等算子，将乘法结构转化为加法结构，将指数增长转化为线性增长。复杂系统的演化规律在特定尺度（对数尺度）下依然遵循最简单的线性平衡 [12:368]。
* **几何/直观视阈**：体现了**坐标网格的非均匀拉伸** [12:368]。在对数坐标系中，原本弯曲的指数曲线被拉直。好比用广角镜头观察世界，通过改变观察的"透视规则"让隐藏在弯曲轨迹下的线性本质浮现 [12:367, 368]。
* **物理/现实视阈**：这是**"复杂规律"向"简明预测"的坍缩** [12:371, 378]。如摩尔定律或短跑世界纪录，其极限受制于生物物理或材料物理的边界。线性化回归通过捕获"减速"趋势，比直线模型更能精准预判系统接近饱和的时刻 [12:372]。

## 经典例题精讲

## 五、 经典例题精讲

### [例题 1] 百米纪录的非线性预测 [12:366]
**题目**：已知男子百米世界纪录数据。线性模型 $\hat{y}_1 = -0.0203t + 49.77$。对数模型 $\hat{y}_2 = -0.4264\ln(t-1895) + 11.80$。评价两模型优劣 [12:366, 369]。

**规范解答**：
1.  **残差观测**：线性模型残差两端为正、中间为负，呈函数规律 → 拟合不佳 [12:366]。
2.  **$R^2$ 对比**：线性 $R_1^2 \approx 0.7325$，对数 $R_2^2 \approx 0.9983$ [12:371]。
3.  **结论**：$R_2^2$ 极接近 1，对数模型能解释 99.83% 的数据变异 [12:371]。
4.  **外推验证**：代入 2009 年，对数模型预测值更接近博尔特的 9.58s [12:372]。

**方法提炼**：散点有弧度时，"化曲为直"是提升预测精度的唯一路径。

## 七、 101星思维挑战

### 1. 决定系数的边界悖论
**挑战问题**：如果增加更多的解释变量，$R^2$ 一定会增大吗？ [12:414, 416]
**思考引导**：调研"调整的决定系数"（Adjusted $R^2$），思考模型复杂度的增加是否总是带来"解释力"的真实提升 [12:414]。

### 2. 变换后的偏差"权重"
**挑战问题**：对 $y = c e^{kx}$ 取对数得 $\ln y = \ln c + kx$，最小二乘法最小化的是 $(\ln y_i - \ln \hat{y}_i)^2$。这与最小化原始误差 $(y_i - \hat{y}_i)^2$ 在逻辑上完全等价吗？
**思考引导**：思考对数变换如何改变了不同量级数据点对误差平方和的贡献权重。
