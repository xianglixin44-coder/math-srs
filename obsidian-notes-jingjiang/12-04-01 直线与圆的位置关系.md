# 直线与圆的位置关系
**分类**: 选择性必修第一册

## 核心概念界定

## 一、核心概念界定

### 三种位置关系
根据直线与圆的公共点个数分为：
* **相交**：有两个公共点。
* **相切**：只有一个公共点（该直线称为圆的切线）。
* **相离**：没有公共点。

## 解题策略与方法论

## 二、位置关系判定的双轨 SOP

### 1. 几何法 —— 推荐：运算量小
* **动作**：计算圆心 $(a, b)$ 到直线 $Ax+By+C=0$ 的距离 $d = \frac{|Aa+Bb+C|}{\sqrt{A^2+B^2}}$。
* **判定**：$d < r \iff$ 相交；$d = r \iff$ 相切；$d > r \iff$ 相离。
* **弦长计算**：若相交，弦长 $L = 2\sqrt{r^2 - d^2}$。

### 2. 代数法 —— 普适性强
* **动作**：联立方程组，消元得一元二次方程。
* **判定**：$\Delta > 0 \iff$ 相交；$\Delta = 0 \iff$ 相切；$\Delta < 0 \iff$ 相离。

## 易错点与风险规避

## 三、易错点与风险规避

### 1. 切线斜率不存在的"静默"丢解
* **陷阱描述**：求过圆外一点的切线时，若设点斜式仅解出一个 $k$ 值。
* **避坑策略**：圆外点引切线必有两条。若只得其一，说明另一条斜率不存在（垂直于 $x$ 轴），必须手动补全 $x=x_0$。

### 2. 距离公式中的"标准方程"前置
* **陷阱描述**：直接从一般方程中读取半径。
* **避坑策略**：必须先配方化为标准式，或严格执行 $r = \frac{1}{2}\sqrt{D^2+E^2-4F}$。

## 经典例题精讲

## 五、经典例题精讲

### [例题 1] 弦长计算的几何优化
**题目**：已知直线 $l: 3x+y-6=0$ 与圆 $C: x^2+y^2-2y-4=0$，求直线被圆截得的弦长。

**规范解答**：
化标准式：圆 $x^2+(y-1)^2=5$，圆心 $(0,1)$，半径 $r=\sqrt{5}$。
$d = \frac{|3 \times 0 + 1 - 6|}{\sqrt{10}} = \frac{5}{\sqrt{10}} = \frac{\sqrt{10}}{2}$。
$d < r$ → 相交。弦长 $L = 2\sqrt{r^2-d^2} = 2\sqrt{5 - \frac{10}{4}} = \sqrt{10}$。

**方法提炼**：弦长 = 几何法（$d$ 与 $r$） > 代数法（联立+弦长公式），运算量少一半。

### [例题 2] 求圆的切线方程
**题目**：求过点 $P(4,0)$ 且与圆 $(x-1)^2 + y^2 = 4$ 相切的直线方程。

**规范解答**：
设切线 $y = k(x-4)$。化为一般式 $kx - y - 4k = 0$。
圆心 $(1,0)$ 到切线距离 $d = \frac{|k-4k|}{\sqrt{k^2+1}} = \frac{3|k|}{\sqrt{k^2+1}} = r = 2$。
平方得 $\frac{9k^2}{k^2+1} = 4$ → $9k^2 = 4k^2+4$ → $k^2 = \frac{4}{5}$ → $k = \pm\frac{2\sqrt{5}}{5}$。
$\therefore$ 切线为 $y = \pm\frac{2\sqrt{5}}{5}(x-4)$。

**方法提炼**：设切线→化为一般式→圆心到切线距离 = 半径→解 $k$。

### 1. 动态直线的恒过定点
**挑战问题**：已知直线 $l: (2m+1)x + (m+1)y - 7m - 4 = 0$。证明无论 $m$ 取何值，直线恒过圆 $C: (x-1)^2+(y-2)^2=25$ 内部的一个定点，并思考这对弦长最值的意义。
**思考引导**：分离参数 $m$ 构造直线系方程组，解出定点。利用"过圆内一点，最短弦垂直于直径"的几何直观。
