# 基本不等式
**分类**: 高一数学-第一册-一元二次函数、方程和不等式

## 核心概念界定

## 一、核心概念界定

### 1. 重要不等式
对于任意实数 $a, b \in \mathbb{R}$，恒有 $a^2 + b^2 \ge 2ab$，当且仅当 $a = b$ 时等号成立．

### 2. 基本不等式
若 $a > 0$，$b > 0$，则 $\sqrt{ab} \le \frac{a+b}{2}$．
*   **算术平均数**：$\frac{a+b}{2}$；**几何平均数**：$\sqrt{ab}$．
*   **本质**：两个正数的算术平均数不小于它们的几何平均数．

## 解题策略与方法论

## 二、解题策略与方法论

### 1. 求最值的「一正、二定、三相等」SOP
1.  **一正**：确认参与运算的变量均为正数。
2.  **二定**：
    *   **积定和最小**：若积 $xy = P$（定值），则和 $x+y \ge 2\sqrt{P}$。
    *   **和定积最大**：若和 $x+y = S$（定值），则积 $xy \le \frac{S^2}{4}$。
3.  **三相等**：核查等号成立的条件 $x = y$ 是否在变量的定义域内。

### 2. 构造定值的技巧
*   **配项法**：如求 $x + \frac{1}{x-1}$ ($x>1$) 的最小值，需配凑为 $(x-1) + \frac{1}{x-1} + 1$。
*   **常数代换（「1」的妙用）**：若已知 $ax+by=1$，求 $\frac{1}{x} + \frac{1}{y}$ 的最值，可将原式乘以 $(ax+by)$ 展开。

## 易错点与风险规避

## 三、易错点与风险规避

### 1. 忽视正数前提
*   **陷阱描述**：在变量可能为负的情况下直接套用公式。
*   **具体反例**：求 $x + \frac{1}{x}$ 的最小值时，若 $x < 0$，结果并非 $2$。
*   **避坑策略**：看到 $\le$ 或 $\ge$ 前，先检查自变量是否 $> 0$。

### 2. 「等号孤岛」陷阱
*   **陷阱描述**：多次连续使用基本不等式，但各步等号成立的条件互不相容。
*   **避坑策略**：凡是多次使用基本不等式，必须强制检查所有等号能否**同时取到**。

## 多维原理解码

## 四、多维原理解码

### 几何/直观视阈
在单位圆中，半弦长（几何平均数 $\sqrt{ab}$）不大于半径（算术平均数 $\frac{a+b}{2}$）。直观展示了圆的几何性质如何约束代数数值。

![[02-02-01-circle.png]]

### 代数/逻辑视阈
基本不等式体现了「和」与「积」两种运算维度的转换。当系统内部元素趋于全等（$a=b$）时，系统往往处于极值状态（能量最低或效益最高）。

### 物理/现实视阈
最优化设计的底层协议。周长固定时，围成矩形菜园面积最大的方案必然是正方形，反映自然界对空间效率的终极追求。

## 经典例题精讲

## 五、经典例题精讲

### [例题 1] 和定积最大
**题目**：已知 $x > 0, y > 0$，且 $x + y = 4$，求 $xy$ 的最大值．

**规范解答**：
由基本不等式 $\sqrt{xy} \le \frac{x + y}{2} = \frac{4}{2} = 2$
$\implies xy \le 4$
当且仅当 $x = y = 2$ 时等号成立．
$\therefore$ $xy$ 的最大值为 $4$．

**方法提炼**：和定积最大，直接用 $\sqrt{ab} \le \frac{a+b}{2}$，关键在验证取等条件．

### [例题 2] 积定和最小 + 1 的代换
**题目**：已知 $x > 0, y > 0$，且 $\frac{1}{x} + \frac{4}{y} = 1$，求 $x + y$ 的最小值．

**规范解答**：
$$x + y = (x + y) \cdot 1 = (x + y)(\frac{1}{x} + \frac{4}{y}) = 1 + \frac{4x}{y} + \frac{y}{x} + 4$$
$$= 5 + \frac{4x}{y} + \frac{y}{x} \ge 5 + 2\sqrt{\frac{4x}{y} \cdot \frac{y}{x}} = 5 + 4 = 9$$
当且仅当 $\frac{4x}{y} = \frac{y}{x}$ 即 $y = 2x$ 时等号成立，结合 $\frac{1}{x} + \frac{4}{y} = 1$ 解得 $x = 3, y = 6$．
$\therefore x + y$ 最小值为 $9$．

**方法提炼**：「1 的代换」是处理分子为常数的分式条件的核心技巧，将约束条件嵌入目标函数是构造法的精髓．

## 101星思维挑战

## 七、101星思维挑战

### 🧩 原题
（1）已知 $a, b > 0$ 且 $a + b = 1$，求 $\frac{1}{a} + \frac{4}{b}$ 的最小值；
（2）已知 $a, b, c > 0$ 且 $a + b + c = 1$，求证 $\frac{1}{a} + \frac{1}{b} + \frac{1}{c} \ge 9$；
（3）已知 $x > 0, y > 0$ 且 $\frac{1}{x} + \frac{9}{y} = 1$，求 $x + y$ 的最小值．

### 🪜 思维脚手架

> **🔍 关键信号识别**
> - 「和定求积/和的最值」→ 基本不等式标准题型
> - 「$a + b = 1$」→ **常数代换**（即"1的代换"）是最强技巧
> - 第(3)问 $\frac{1}{x} + \frac{9}{y} = 1$ 不是和定，是**倒数和的定值**→ 同样可用1的代换

> **🧰 方法选择**
> - **方法A（1的代换）**：$\frac{1}{a} + \frac{4}{b} = (\frac{1}{a} + \frac{4}{b}) \cdot 1 = (\frac{1}{a} + \frac{4}{b})(a + b) = 1 + \frac{b}{a} + \frac{4a}{b} + 4$
>   然后用基本不等式 $\frac{b}{a} + \frac{4a}{b} \ge 2\sqrt{4} = 4$
> - **方法B（直接放缩）**：第(2)问用三元均值或凑项 $\frac{1}{a} + a \ge 2$（不推荐，因为需要 $a+b+c=1$ 消去 $a+b+c$）

> **🔑 核心转化**
> 1的代换本质是**将约束条件嵌入目标函数**：
> $$\frac{1}{a} + \frac{4}{b} = \frac{a+b}{a} + \frac{4(a+b)}{b} = 1 + \frac{b}{a} + \frac{4a}{b} + 4$$
> 交叉项 $\frac{b}{a} + \frac{4a}{b}$ 恰好能用均值不等式，这就是**构造法**的精髓——通过代数变形创造可用不等式的结构．
> 
> 第(3)问反向操作：$x + y = (x + y) \cdot 1 = (x + y)(\frac{1}{x} + \frac{9}{y})$，展开后 $1 + \frac{9x}{y} + \frac{y}{x} + 9 \ge 10 + 6 = 16$．

### ⚠️ 常见死胡同
- **死路1**：直接 $\frac{1}{a} + \frac{4}{b} \ge 2\sqrt{\frac{4}{ab}}$ 然后找 $ab$ 的最值 → 绕远且容易取等条件冲突
- **死路2**：「1的代换」时忘了把1替换为条件表达式 → 漏掉关键步骤
- **死路3**：取等条件验证不严谨 — 必须同时满足所有用到的均值不等式的等号

### 💡 变式拓展
**变式1**（三元推广）：$a,b,c>0, a+b+c=1$，求 $\frac{1}{a+b} + \frac{1}{b+c} + \frac{1}{c+a}$ 的最小值．
> 提示：$a+b = 1-c$，转化后放缩

**变式2**（竞赛进阶）：$a,b,c>0, ab+bc+ca=1$，求 $\frac{1}{a+b} + \frac{1}{b+c} + \frac{1}{c+a}$ 的最小值．
> 提示：$(a+b+c)^2 \ge 3(ab+bc+ca) = 3$
