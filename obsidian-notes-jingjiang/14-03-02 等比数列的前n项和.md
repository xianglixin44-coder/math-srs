# 等比数列的前n项和
**分类**: 选择性必修第二册

## 核心概念界定

## 一、核心概念界定

### 1. 前 $n$ 项和的代数定义
* $S_n = a_1 + a_2 + a_3 + \dots + a_n = \sum_{i=1}^{n} a_1 q^{i-1}$

### 2. 等比数列求和公式
* **当 $q \neq 1$ 时**：$$S_n = \frac{a_1(1 - q^n)}{1 - q}$$
* **变通形式**：$$S_n = \frac{a_1 - a_n q}{1 - q}$$
* **当 $q = 1$ 时**：$$S_n = n a_1$$

## 解题策略与方法论

## 二、错位相减法 SOP

1. **正序罗列**：$S_n = a_1 + a_1 q + a_1 q^2 + \dots + a_1 q^{n-1}$
2. **公比扩倍**：$q S_n = a_1 q + a_1 q^2 + \dots + a_1 q^{n-1} + a_1 q^n$
3. **对位平移**：将 $q S_n$ 的项向右平移一位，使相同幂次的项上下对齐。
4. **相减脱壳**：$(1-q)S_n = a_1 - a_1 q^n$。除首尾两项外，中间项全部对冲消去。
5. **分类系数**：若 $q \neq 1$，除以 $(1-q)$ 得公式；若 $q=1$，$S_n = n a_1$。

### 参数锁定的路径决策
* 已知 $S_n$ 形式为 $S_n = A q^n + B$ → 等比数列充要条件是 $A + B = 0$。

## 易错点与风险规避

## 三、易错点与风险规避

### 1. 忽略 $q=1$ 的分类讨论
* **陷阱描述**：直接套用分式公式，忽略公比可能为 1。
* **避坑策略**：公式执行前，第一步永远是询问"公比 $q$ 是否可能等于 $1$？"

### 2. 幂次 $n$ 与 $n-1$ 的位差误区
* **陷阱描述**：误将通项公式中的 $n-1$ 记为求和公式中的幂次。
* **避坑策略**：求和公式中的 $n$ 代表**项数**。从 $a_1$ 到 $a_n$ 共有 $n$ 项，故分子为 $q^n$。

### 3. $S_n$ 转 $a_n$ 的端点孤岛
* **陷阱描述**：利用 $a_n = S_n - S_{n-1}$ 求解通项时忽略 $n=1$ 的校验。
* **避坑策略**：强制分段：先算 $a_1 = S_1$，再算 $n \ge 2$，最后验证一致性。

## 多维原理解码

## 四、多维原理解码

![[14-03-02-geometric-sum.png]]

* **代数/逻辑视阈**：等比求和是**"结构坍缩"**的体现。错位相减法通过引入平移算子 $q$，构造两个高度相似的序列，利用"相位差"消除中间所有动态增长项，使总量仅取决于初始态和终止态。
* **几何/直观视阈**：它反映了**自相似形的面积累积**。如分形几何中每一级面积都是前一级的固定倍数，$S_n$ 对应递归结构的总覆盖面积。
* **物理/现实视阈**：对应**能量或物质的翻倍效应**。"棋盘放麦粒"问题揭示了等比累加产生的"指数爆炸"。

## 经典例题精讲

## 五、经典例题精讲

### [例题 1] 含有比例关系的公比求解
**题目**：等比数列首项 $-1$，$\frac{S_{10}}{S_5} = \frac{31}{32}$，求 $q$。

**规范解答**：
$q=1$ 时 $\frac{S_{10}}{S_5}=2 \neq \frac{31}{32}$，故 $q \neq 1$。
$\frac{S_{10}}{S_5} = \frac{1-q^{10}}{1-q^5} = \frac{(1-q^5)(1+q^5)}{1-q^5} = 1+q^5 = \frac{31}{32}$。
$q^5 = -\frac{1}{32}$ → $q = -\frac{1}{2}$。

**方法提炼**：$S_{2n}/S_n = 1+q^n$——平方差公式降维。

### [例题 2] 无穷递缩等比数列
**题目**：求首项 $a_1=8$，公比 $q=\frac{1}{2}$ 的无穷等比数列所有项的和。

**规范解答**：
$|q|=\frac{1}{2}<1$，可求所有项和。$S = \frac{a_1}{1-q} = \frac{8}{1-\frac{1}{2}} = 16$。

**方法提炼**：$|q|<1$ 时 $S_\infty = \frac{a_1}{1-q}$，$n \to \infty$ 时 $q^n \to 0$。

## 101星思维挑战

## 七、101星思维挑战

### 1. 结构的分段对称性
**挑战问题**：证明若 $\{a_n\}$ 是公比为 $q$ 的等比数列，则 $S_n, S_{2n}-S_n, S_{3n}-S_{2n}$ 仍构成等比数列，并求公比。
**思考引导**：$S_{kn}-S_{(k-1)n} = a_1 q^{(k-1)n} \cdot \frac{1-q^n}{1-q}$，与 $k$ 的关系是指数关系 → 公比为 $q^n$。

### 2. 无穷递缩的收敛值
**挑战问题**：若每次取正方形中点构造新正方形，总面积为何趋近于 $2a_1$？
**思考引导**：$|q|<1$ 时 $q^n \to 0$，$S_n \to \frac{a_1}{1-q}$。"万世不竭"的棰在数学总量上是有限的。
